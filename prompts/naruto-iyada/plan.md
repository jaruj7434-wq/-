# こんな忍者はまじでやだ(「こんなナルトは嫌だ」パロディ)

## 全体の構成
- 縦型 9:16、4〜5ネタで1本、テンポ重視(全体 30〜40秒)
- 冒頭: 曲調のジングル「こんな忍者は〜 まじでやだ〜♪」(約2.5秒)
- 各ネタ: 回答テロップ → 実写コント(5〜7秒)→ オチ → 短い効果音・ジングルで次へ
- 主役: AI で作る架空の若い男性の忍者(金髪ツンツン、オレンジの忍者服、額当てのマークはラーメンの「なると」の渦巻き)。木ノ葉マーク・公式デザインは使わない
- 投稿時の表記: パロディ/AI生成/公式とは無関係

## ネタ1: 影分身が全員ドパガキ
ドパガキ = スマホをずっと見ている若者(最近の流行語)

| 秒 | 映像 | 音 |
|---|---|---|
| 0.0–0.3 | テロップ「影分身が全員ドパガキ」 | ジャン!|
| 0.3–1.3 | 屋上(または森)で忍者が印を結び「影分身の術!」 | 気合の声 |
| 1.3–1.8 | ボフン!と煙、横一列に分身が8人 | 煙の効果音 |
| 1.8–4.5 | 分身たちが一斉にスマホを取り出す。縦スワイプでリール動画、横持ちで親指連打のゲーム、イヤホンで笑う、寝転がる、自撮り。顔が画面の青白い光に照らされる | 通知音・リール動画の音・ゲーム音が重なる |
| 4.5–5.5 | 本体「おい! 戦うぞ!」→ 分身は誰も顔を上げず、1人だけ「今いいとこだから」 | セリフ |
| 5.5–6.5 | オチ: 本体のスマホも「ピコン」と鳴り、本体も見始める | 通知音 → ジングルの頭 |

### 制作の流れ(案)
1. 主役の人物画像(全身、正面)を作る → 以降の参照に使う
2. 開始画像: 印を結ぶ本体
3. 分身がスマホを見ている画像(終了画像またはオチ用)
4. 動画化(開始・終了画像を指定)
5. テロップ・効果音・セリフは編集で重ねる
