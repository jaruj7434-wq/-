# Suno で替え歌を作るための素材

Higgs Field には Suno がないため、ユーザーが Suno(suno.com / アプリ)で直接作る。

## 手順(Cover 機能)
1. Suno で「Create」→「Upload Audio」で、`assets/output/naruto-iyada/audio/karaoke-with-guide.mp3`(元の歌が薄く入った伴奏、約22秒)をアップロード
   - メロディとリズムを拾わせたいので、歌が入っている方を使う。伴奏だけの方が良ければ `karaoke-inst-only.mp3`
2. アップロードした曲で「Cover」を選ぶ
3. Lyrics に下の歌詞、Styles に下のスタイルを入れて作成
4. できた曲(mp3)を Higgs Field にアップロード → こちらで映像・テロップと合わせる

## Lyrics
```
[Verse]
こんなナルトは まじでやだ〜
ぶんしん ぜんいん ドパガキ〜
こんなナルトは まじでやだ〜
ラーメン きらいで パスタ くう〜
こんなナルトは まじでやだ〜
いどうは はしらず ヘイ タクシー
```
※「は」は「わ」と発音してほしいので、崩れる場合は「こんなナルトわ」と書く

## Styles
```
late-80s Japanese girl band pop, 89 BPM, bouncy jangly guitar cutting, simple drums and bass, clear cute female vocal, deadpan half-talking delivery, list song
```

## 注意
- 元の曲を Suno にアップロードするので、取得した許可に「AI サービスへの音源アップロードと加工」も含まれているか確認する(Suno の規約でも、権利のない音源のアップロードは禁止)
