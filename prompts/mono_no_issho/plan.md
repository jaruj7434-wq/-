# 企画書：モノの一生（セッション開始用）


## コンセプト
身近なモノが「生まれてから消えるまで」を、ドキュメンタリー風に追いかける教養シリーズ。
例：1円玉、ペットボトル、落とし物の傘、新聞紙、レシート、新幹線の切符。

## 狙い
- 「当たり前すぎて考えたことがない」ことへの好奇心でクリックさせる
- 最後に「えっ、そうなるの？」という意外な結末を置く
- 教養系なので長尺（8〜12分）に向く。ショートは名場面の切り出し

## 動画の型（長尺）
1. フック（0〜15秒）：結末の一部を先に見せる（例：「この1円玉、最後は溶かされます」）
2. 誕生：どこで・どう作られるか
3. 旅：人の手から手へ渡る道のり（地図アニメで移動を見せる）
4. 意外な事実：数字で驚かせる（例：1円玉を作るのに1円以上かかる）
5. 最期：回収・リサイクル・廃棄
6. 締め：次回予告

### 誕生：造幣局での製造工程
1. **溶解**：材料を電気炉で溶かし、金属の塊（鋳塊）を作る
2. **圧延**：決まった厚さの板に延ばす
3. **圧穿（あっせん）**：硬貨の形に打ち抜く（この段階を「円形（えんけい）」と呼ぶ）
4. **圧縁・焼鈍**：縁を盛り上げ、熱を加えて柔らかくする
5. **圧印**：プレス機で表裏の模様を刻む
6. **検査 → 計数・袋詰め** → 日本銀行へ納入 → 金融機関 → 世の中へ

- 出典：[財務省 貨幣に関する懇談会 資料（造幣局提出、2026年8月）](https://www.mof.go.jp/about_mof/councils/meeting_of_coin/20260819_1.pdf)、[週刊女性PRIME 造幣局見学記事](https://www.jprime.jp/articles/-/17397)
- 通常貨幣は主に**大阪本局と広島支局**で製造（同 JPrime 記事）★

### 旅：自販機に入れない理由
- ダイドードリンコ担当者：技術的には可能だが、**1円・5円を保管するスペースが要る**ため（本体を大きくするか商品を減らすことになる）→「省スペースのため」
- 出典：[ねとらぼ](https://nlab.itmedia.co.jp/cont/articles/3246107/)、[ASCII](https://weekly.ascii.jp/elem/000/001/599/1599305/2/) ★メーカー1社の見解として紹介する

### 最期：回収・溶解
- 日本銀行は「磨損などで流通に適さなくなった貨幣」を引き換えの対象にしている → [日本銀行 損傷現金の引換え](https://www.boj.or.jp/about/services/bn/hikikae.htm)
- 財務大臣が回収を指示し、回収貨幣（地金）を造幣局に交付 → 造幣局で**鋳つぶし**（[財務省 行政事業レビュー資料](https://www.mof.go.jp/about_mof/mof_budget/review/2022/2022zaimu210023logic_model.pdf)）
- 造幣局は回収貨幣を溶かして新しい貨幣に生まれ変わらせる循環も担う（[coki](https://coki.jp/article/news/60224/)）
  - ★「回収した1円玉が溶かされて**また1円玉になる**」と言い切れるかは要確認（アルミの用途の一次資料なし）。台本では「溶かされて、次の硬貨の材料になる」程度に留める
- 一般人が硬貨を溶かす・傷つけるのは**貨幣損傷等取締法で禁止**（1年以下の拘禁刑または20万円以下の罰金）→ [ファイナンシャルフィールド](https://financial-field.com/living/entry-485656)

## 第3話リサーチ：「ペットボトルは何に生まれ変わる？」（2026-11-13）

★＝公開前に一次資料（PDF本体）で確認。今回はクラウド環境から各サイトを直接開けず、検索結果の抜粋ベース。

### 誕生：日本のペットボトルの歴史
- 1977年：醤油の容器として日本で初採用（500ml）。1978年に1Lサイズ ★（キッコーマン ニュースリリース https://www.kikkoman.com/jp/news/2024/img/news_24039.pdf）
- 1982年：食品衛生法の改正で清涼飲料への使用が認められる。ただし業界は散乱ごみ問題から小型ボトルを自主規制（nippon.com https://www.nippon.com/ja/japan-data/h00401/）
- 1996年：小型ペットボトルの自主規制を撤廃 → 500mlが一気に普及（同上）
- 出荷本数：2017年度 約227億本 ★（nippon.com、推進協議会データ）

### 量とリサイクル率（PETボトルリサイクル推進協議会 年次報告書2025＝2024年度実績）
- 指定PETボトル販売量：652千トン（2024年度）。2023年度は636千トン
- リサイクル率 85.1%（2024年度、2023年度は85.0%）＝再資源化量555千トン／販売量652千トン
  - 内訳：国内再資源化 445千トン、海外再資源化 110千トン
- 有効利用率（熱回収含む）98.6%
- 軽量化率 28.1%（2024年度、2023年度28.4%）
- ボトルtoボトル比率 37.7%（2024年度、2023年度33.7%から上昇）。ボトルtoボトル量 246千トン（前年度比14.7%増）
- 清涼飲料業界の目標：2030年度に水平リサイクル比率50% ★（日本食糧新聞 https://news.nissyoku.co.jp/?p=1242163）
- 出典：https://www.petbottle-rec.gr.jp/nenji/2025/2025_p06_11.pdf ／ https://www.petbottle-rec.gr.jp/nenji/2025/2025_p12.pdf ／ 報告書本体 https://www.petbottle-rec.gr.jp/nenji/2025/2025.pdf

### 生まれ変わり先（国内向け再生PET樹脂の用途、2024年度）★
- ボトル（ボトルtoボトル）246.0千トン＝57.7%
- シート（卵パック・食品トレーなど）108.5千トン＝25.5%
- 成形品 28.9千トン＝6.8%

- 2023年度：ボトル214.6千トン、シート120.1千トン、繊維28.6千トン（年次報告書2024）

### 工程（メカニカルリサイクル）
- 分別収集 → 選別（異物除去）→ 圧縮梱包「ベール」→ 粉砕・洗浄「フレーク」→ 溶かして粒状「ペレット」→ 成形
- ケミカルリサイクル：化学的に分解して原料（モノマー）まで戻してから再びPET樹脂に。エネルギー・コストが課題
- 出典：容器包装リサイクル協会 https://www.jcpra.or.jp/law/goals/pla-bottle.html ／ プラスチック循環利用協会 https://www.pwmi.jp/

### 意外な事実
- 自販機横のリサイクルボックスには、空容器以外のごみ（異物）が約3割（全国清涼飲料連合会調査、平成30年／福岡市資料）
- 大阪府の2022年度実証：従来型ボックスの異物比率 平均26.6%
- 2022年秋から、投入口を見えにくい角度・高さにした「新機能型」ボックスを業界統一仕様として順次導入
- 「ペットボトル何本で服1着」は出典が取れず台本では使わない
