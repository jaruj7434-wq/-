# 企画書：モノの一生（セッション開始用）


## コンセプト
身近なモノが「生まれてから消えるまで」を、ドキュメンタリー風に追いかける教養シリーズ。
例：1円玉、ペットボトル、落とし物の傘、新聞紙、レシート、新幹線の切符。

## 狙い
- 「当たり前すぎて考えたことがない」ことへの好奇心でクリックさせる
- 最後に「えっ、そうなるの？」という意外な結末を置く
- 教養系なので長尺（8〜12分）に向く。ショートは名場面の切り出し

## 動画の型（長尺）
1. フック（0〜15秒）：結末の一部を先に見せる（例：「この1円玉、最後は溶かされます」）
2. 誕生：どこで・どう作られるか
3. 旅：人の手から手へ渡る道のり（地図アニメで移動を見せる）
4. 意外な事実：数字で驚かせる（例：1円玉を作るのに1円以上かかる）
5. 最期：回収・リサイクル・廃棄
6. 締め：次回予告

### 誕生：造幣局での製造工程
1. **溶解**：材料を電気炉で溶かし、金属の塊（鋳塊）を作る
2. **圧延**：決まった厚さの板に延ばす
3. **圧穿（あっせん）**：硬貨の形に打ち抜く（この段階を「円形（えんけい）」と呼ぶ）
4. **圧縁・焼鈍**：縁を盛り上げ、熱を加えて柔らかくする
5. **圧印**：プレス機で表裏の模様を刻む
6. **検査 → 計数・袋詰め** → 日本銀行へ納入 → 金融機関 → 世の中へ

- 出典：[財務省 貨幣に関する懇談会 資料（造幣局提出、2026年8月）](https://www.mof.go.jp/about_mof/councils/meeting_of_coin/20260819_1.pdf)、[週刊女性PRIME 造幣局見学記事](https://www.jprime.jp/articles/-/17397)
- 通常貨幣は主に**大阪本局と広島支局**で製造（同 JPrime 記事）★

### 旅：自販機に入れない理由
- ダイドードリンコ担当者：技術的には可能だが、**1円・5円を保管するスペースが要る**ため（本体を大きくするか商品を減らすことになる）→「省スペースのため」
- 出典：[ねとらぼ](https://nlab.itmedia.co.jp/cont/articles/3246107/)、[ASCII](https://weekly.ascii.jp/elem/000/001/599/1599305/2/) ★メーカー1社の見解として紹介する

### 最期：回収・溶解
- 日本銀行は「磨損などで流通に適さなくなった貨幣」を引き換えの対象にしている → [日本銀行 損傷現金の引換え](https://www.boj.or.jp/about/services/bn/hikikae.htm)
- 財務大臣が回収を指示し、回収貨幣（地金）を造幣局に交付 → 造幣局で**鋳つぶし**（[財務省 行政事業レビュー資料](https://www.mof.go.jp/about_mof/mof_budget/review/2022/2022zaimu210023logic_model.pdf)）
- 造幣局は回収貨幣を溶かして新しい貨幣に生まれ変わらせる循環も担う（[coki](https://coki.jp/article/news/60224/)）
  - ★「回収した1円玉が溶かされて**また1円玉になる**」と言い切れるかは要確認（アルミの用途の一次資料なし）。台本では「溶かされて、次の硬貨の材料になる」程度に留める
- 一般人が硬貨を溶かす・傷つけるのは**貨幣損傷等取締法で禁止**（1年以下の拘禁刑または20万円以下の罰金）→ [ファイナンシャルフィールド](https://financial-field.com/living/entry-485656)
