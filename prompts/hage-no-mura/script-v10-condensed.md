# ハゲの村 台本 v10(セリフ優先の凝縮版・約77秒)

方針: **登場人物のセリフはすべて残し、セリフのないカット(風景・作業・間)を中心に削る。**
焚き火シーンは v8 のセリフをすべて残す。

- 男性は全員ハゲ。映像・演技は大真面目、ふざけているのはセリフだけ
