# ハゲの村 〜Hage Village〜 台本(第6稿)

恋愛リアリティーショーの予告編(『あいの里』系)のオマージュ。
ハゲの男性たちと、ハゲを心から愛する女性たちが暮らす村に、
**ただ一人、髪がフサフサの男・慶太**がやってくる。

## コンセプト

- **映像・音楽・演技・物語は、大真面目な恋愛リアリティーショーの予告編そのもの。**
  映像的なギャグやコミカルな効果音は入れない。
- **ふざけているのはセリフだけ。** ハゲいじりと、ハゲに本気でときめく女性たちのズレた愛情表現を、
  全員が涙ぐむほど本気のトーンで言う。この落差で笑わせる。
- この村では**髪があることがコンプレックス**。フサフサの慶太が「持っている者の苦しみ」を抱えながら、
  それでも純愛を貫く逆転の物語にする。
- 出演者はすべて AI 生成の架空の人物、または本人同意済みの登録キャラクター(全員成人)。
  実在の番組名・ロゴには似せない。

## 演出ルール

| 項目 | ルール |
|---|---|
| 映像 | 柔らかい自然光、浅い被写界深度、スローモーション多め。本家同様の静かでエモい画作り |
| 色 | 落ち着いた暖色系。夜は焚き火のオレンジ、夕方は黄金色、月夜は青白い光 |
| 音楽 | ピアノ+ストリングスの切ないバラード。後半のカップル成立で最高潮に |
| 演技 | 全員が本気で恋をしている表情。笑い顔の芝居はしない |
| テロップ | 白の明朝体、控えめ。ナレーション風テロップはすべて真面目な文言 |
| 効果音 | 使わない(焚き火、風、雨、虫の声などの環境音のみ) |

## 物語の流れ

1. **異物**: フサフサの慶太が村に来る。女性たちは髪に戸惑い、慶太は生まれて初めて髪を恥じる
2. **恋の始まり**: 慶太はさくらに惹かれるが、さくらは光の頭に夢中
3. **それぞれの恋**: 4組の恋が静かに育っていく
4. **葛藤**: 晴彦の言葉を受け、慶太は「愛のために頭を剃るか」で揺れる。光と衝突
5. **雨の告白**: さくらが慶太を止める。剃らなくていい、と
6. **告白・成立**: 夕暮れ、5組が次々に結ばれる。光は身を引き、慶太の背中を押す
7. **ポストクレジット**: 数日後の朝、慶太の枕に1本の抜け毛

## メモ

- 日本語のセリフ・テロップは、生成後に字幕(`subtitles` ワークフロー)か編集で入れる想定。
  セリフを口パクで話させる場合は、音声付き動画モデルの利用を別途検討する。
- 生成は、ワークフロー確認 → Elements 登録 → 各カット動画の順で行い、
  **各段階で内容とコストを提示して許可を得てから**実行する。
