# ゴッドマザー 台本 v1(映画予告編風・16:9・約55秒)

- 原作の名シーン・名台詞の「型」を借り、中身を町内会(婦人会)の日常に置き換える
- 映像・演技・音楽は大真面目なマフィア映画。ふざけているのはセリフと小道具だけ
- 主人公マイケル役 = 慶太(堅気の息子 → 最後に「ゴッドマザー」を継ぐ。男なのにマザー、がオチ)
- 原作のテーマ曲は使わない。BGMは「哀愁のあるマンドリンのワルツ(オリジナル)」と指定する
