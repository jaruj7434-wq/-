# 番組 第1弾「明日のお天気」中継 ― 放送事故(2026-11-24)

## 企画
- 昭和のテレビの天気予報。商店街からの生中継で、お天気キャスターが笑顔で明日の天気を伝えている
- その後ろで、夫婦が口げんかを始め、だんだんエスカレート。キャスターは笑顔で続けようとするが、最後は中継が大混乱 → 「しばらくお待ちください」で放送事故のように終わる
- 天気の言葉と、後ろのけんかが重なるのがオチ(「にわか雨」→ 奥さまがバケツの水をかける/「雷」→ 奥さまの怒鳴り声)

## 形式
- Wan 3.0 で28秒を1本(セリフもプロンプトで)、0秒からすぐキャスターがしゃべり始めるように切る
- 番組なので商品カット・社名カードはなし。最後は手元で作る「カラーバー+しばらくお待ちください」画面(ピーという試験音つき)で終わる
- 縦型の上の題字は「昭和のまぼろし映像」
- 画面の文字:左上に「明日のお天気」、下に「中継 ひだまり町 商店街」(昭和のテレビのスーパー風)
