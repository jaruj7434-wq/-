# 第1話「ユメミ 電気洗濯乾燥機 おてんき号」CM台本(2026-11-16 組み直し/架空機能を追加)

参考:`docs/research/2026-11-showa-cm.md`

## 方針
- **昭和30年代前半(1955〜58年ごろ)に本当に放送されていたテレビCM**のように作る
  (昭和初期にはテレビCMがないため。昭和初期版は末尾の別案を参照)
- 現代のドラム式洗濯乾燥機が、当時の新製品として大まじめに売られている
- テンポ:30秒・11カット(1カット約2.5〜3秒)。記録映像風の洗濯板の場面で始まり、社名で終わる
- 映像:白黒、4:3、モノラル。スタジオの書き割りセット、正面からの固定カメラ、明るくフラットな照明
- 商品名・会社名は架空:**夢見ヶ丘電機(ユメミ)/電気洗濯乾燥機「おてんき号」**
  (「お天気に左右されない」という売り文句と、オチの雨の場面につながる名前)

## 架空の面白ポイント:「ポケット点検機能」(2026-11-16 追加)
- 洗う前にポケットの中身を自動で取り出し、前面の小さな引き出し「おとどけ箱」にチーンと返してくれる
- ビー玉やメンコなら便利な機能。ところが最後に、ご主人の「へそくり」まで奥さまに届けてしまう
- 「ポケットに物を入れたまま洗ってしまう」という誰もが経験するあるあると、昭和CMらしい夫婦の掛け合いを組み合わせる
- CMはこの機能を「家計もすっきり」と、あくまで便利な機能として大まじめに宣伝する

## 冒頭の作り(2026-11-16 変更)
- 最初の3秒は、CMではなく当時の記録映像(ニュース映画)のように見せる。BGMも字幕もなし
- そこへCMガールが割りこんで「まだそんなので洗ってらっしゃるの?」と言い、一気にCMのテンポに切り替える
- 記録映像風の場面だけ、少し手持ちでゆらし、粒子を強めにして、スタジオ場面との差をつける

## 当時らしさを出すための演出
- **カメラ**:ほぼ正面の固定。寄りは商品(カット5)だけ。カットはパッパッと切り替える(フェードは最初と最後だけ)
- **芝居**:全員、少し大げさな身ぶりと満面の笑み。CMガールはカメラ目線
- **字幕スーパー**:白い太ゴシックで手書き風、少し傾けたり跳ねさせたりする。毎カット1つ
- **音**:ナレーションは明るく早口。ジングル・ジャジャーン・キラーンなどの効果音をはっきり入れる。BGMは軽快なオリジナルのマーチ風(実在のCMソングには似せない)
- **質感**:白黒、粒子、ちらつき、少しのゆれ。当時のテレビ画面のように少しにじませる

## 洗濯機のデザイン(決定:昭和風に寄せる)
「昭和30年代に本当に売っていたドラム式」に見えるよう、形はドラム式のまま、細部を当時の家電に寄せる。
- 本体:角を大きく丸めた箱型。クリーム色のホーロー仕上げ(白黒では明るい灰色に映る)
- 丸窓:船の窓のような、太いクロームの縁取り。ガラスは少し厚く、ゆがんで見える
- 操作部:正面上部に、大きなダイヤル式のつまみ2つ(「洗い」「乾燥」)と、ピアノの鍵盤のような押しボタン3つ
- 脚:短い4本のクロームの脚で、床から少し浮いている
- 飾り:側面にクロームの帯を1本。正面の銘板(「ユメミ」「おてんき号」)は編集で入れる
- おとどけ箱:正面下の小さな引き出し。クロームの取っ手、開くとチーンと鳴る
- 文字・ロゴは AI に書かせない(銘板は無地で作り、後から文字を入れる)

## CMソング(オリジナル)
曲調:昭和30年代のテレビCMソング風の明るいマーチ。テンポ 120 前後。金管・木琴・小太鼓の小編成。
女性3人のコーラスが、はっきりした発音で歌う。実在のCMソングには似せない。

```
[頭のジングル]
ユメミ ユメミ ユーメーミー!

[本編]
まわる まわるよ ユメミのドラム
ぐるぐる ぐるりん お洗濯
雨でも晴れでも おてんき号
ポケットの中まで おとどけします

[しめ]
ゆめみがおか でんきー!
```

使い方:
- カット4(洗濯機の登場):頭のジングル
- カット5〜10:同じ曲の歌なし版を BGM として小さく流す(ナレーションと重ならないように)
- カット11(社名カード):「まわる まわるよ ユメミのドラム」→「ゆめみがおか でんきー!」
- 生成後、フィルム加工ツールで帯域を絞り、当時のテレビの音にする
