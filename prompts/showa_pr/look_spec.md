# 映像の質感指定(昭和16mm PR映画風)

方針:**AIには「時代の美術・衣装・照明」だけを作らせ、フィルムの傷みはすべて手元の加工で足す。**
カットごとに質感がバラつかず、どの回も同じ「シリーズの顔」になる。
加工は `tools/showa_film/film.py` が行う(数値は `DEFAULT_LOOK`。EDL の `look` で回ごとに上書き可)。

## 画角・コマ
| 項目 | 指定 |
|---|---|
| 画面比 | 4:3(本編 1440×1080)。作業は 720×540 で行い拡大 → 16mmらしい甘さが出る |
| SNS用 | 1080×1920 の中央に 4:3 を置き、上帯にシリーズ名、下帯に字幕、最下部に「架空・AI制作」表記 |
| コマ数 | 24fps |
| カメラ | 三脚固定が基本。動かすのはゆっくりしたパンと寄りだけ。手持ち・ドローン風は使わない |
| 構図 | 正面・水平・人物は全身〜膝上(PR映画の「説明する画」)。浅い被写界深度は使わない |
| 照明 | 窓からの自然光+フラットな補助光。影は薄め |

## 色(色あせたカラーフィルム)
- 彩度 62%、黒を浮かせる(R 0.075 / G 0.06 / B 0.08)
- 白の上限を抑え、青を強めに落とす(R 0.97 / G 0.91 / B 0.80)→ 年月で青緑が抜けた赤紫〜飴色寄り
- 明部に赤みのあるにじみ(ハレーション 0.18)
- 白黒回をやる場合は `"mode": "mono"`(やや暖かい銀塩調)

## フィルムの傷み
| 要素 | 値 | 内容 |
|---|---|---|
| 粒子 | 0.075/粒の大きさ1.6 | 中間調で強く、暗部・明部で弱い。主に明るさの粒、少しだけ色の粒 |
| ちらつき | 3.5% | ゆっくりした明暗+コマごとの細かい明暗 |
| ゆれ | 1.4px(縦は1.3倍) | 映写機のゲートでフィルムが上下左右にゆれる |
| ゴミ | 平均1.3個/コマ | 黒い点が7割、白い点が3割 |
| 毛 | 1.2%/コマ | 2〜5コマだけ映る細い毛 |
| 縦傷 | 2%/コマで発生 | 白い細線が数秒、少しずつ左右に動き、ときどき途切れる |
| 周辺減光 | 0.38 | 四隅が暗い+映写窓の丸い角 |
| レンズの甘さ | ぼかし 0.55 | |
| 最後 | 0.4秒の白コマ | フィルムが切れて終わる |

## テロップ・書体(どちらも SIL Open Font License、`fetch_fonts.sh` で取得)
| 用途 | 書体 | 指定 |
|---|---|---|
| シリーズ名・社名 | **Dela Gothic One** | 昭和の看板風の極太ゴシック。字間広め |
| 画面内テロップ・字幕・小見出し | **しっぽり明朝 B1**(ExtraBold) | 古い活字・映画字幕風。クリーム色(#F8EED6)+黒の縁取りと影 |
| 注記 | しっぽり明朝 B1(Regular) | 小さく、くすんだ色 |
- タイトル/エンドカード:濃紺に近い黒地+クリーム色の二重線の枠、中央揃え、架空の社章(二重丸に日の出)
- 画面内テロップはフィルム加工の**前**に焼き込む → 文字も一緒にゆれ・粒子が乗り、当時の光学合成っぽくなる
- 縦型の上下帯の文字はフィルム加工の**後**に載せる(スマホで読みやすさを優先)

## 音(モノラル)
- ナレーション:200Hz〜3.6kHz に帯域を絞り、1.6kHz を持ち上げ、圧縮して軽く歪ませる。
  ゆっくりした音程ゆれ(0.7Hz)と細かいゆれ(9Hz)を足す
- BGM:同様に帯域を絞り、ゆれを少し強めに
- 映写機:24Hz のカタカタ+ヒスノイズ+プチプチを下に敷く
- 最後に 22kHz に落としてから戻し、高音のこもった光学録音の感じにする。音量は -15 LUFS
