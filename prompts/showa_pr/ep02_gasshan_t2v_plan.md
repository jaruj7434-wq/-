# 第2話「ガッシャン号」作り直し方針:プロンプトだけで動画化(2026-11-17)

## 前の版の問題
- 1カット4秒前後の短い動画を14本つないだので、ちゃぶ台返しの動きが途中で切れ、コマ送りのように見えた
- 先に作った声を参考に渡しても、口の動きとセリフがほとんど合わなかった

## 新しい作り方
- 最初のコマ(画像)から動かすのをやめ、**文章のプロンプトだけで動画を作る**
- **セリフもプロンプトに書いて、動画と一緒に声を作る**(声を先に作らない。口と声は同じモデルが同時に作るので合いやすい)
- 短いカットを並べるのではなく、**8〜10秒の「場面」を4本**作る。1本の中で、カメラの切り替えや動きもプロンプトで指示する(動きが途切れない)
- 声質は場面ごとに少し変わる可能性がある(声の見本を使わないため)
- 画質:プロンプトで「1968年の16mmカラーフィルムのテレビCM」と指定し、仕上げで昭和のテレビ風の加工と音をかける
