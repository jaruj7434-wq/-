# 昭和の企業PR映像風「夢の未来機械」シリーズ設定(2026-11-16)

> **2026-11-16 方針変更**:企業PR映画・ナレーション形式から、「昭和の普通の家庭の日常の中で現代の道具が当たり前に使われている」会話劇に変更。最新の台本は `ep01_v2_script.md`。以下の内容は旧方針のもの(ネタ候補・案件化の考え方は引き続き参考)。

## コンセプト
現代のありふれたガジェットを、昭和の企業PR映画(16mmフィルム)の語り口で
「夢の未来機械」として大真面目に紹介する。
- 売り:「最新AIで作っているのに、映像は超アナログ」というズレ
- 笑いの作り方:映像と語りは100%本気。ふざけるのは「対象が今ではふつうの物」という一点だけ
- 最終目標:企業から「うちの商品もレトロPR風で」と依頼が来る状態にする
  → 毎回「このまま広告として成立する品質」で作る(悪ふざけ・下品なネタはやらない)

## 守ること
- 最初の10〜15本は、架空の商品か一般名詞だけ。実在ブランドのロゴ・製品名・形が分かるデザインは出さない
- 本物の昔のCM・PR映画・キャッチコピー・社名・音楽は真似しない。「〜風」に留める
- 提供会社は架空:**夢見ヶ丘電機工業(ゆめみがおか でんき こうぎょう)**
  - 社章も自作の簡単な図形(丸に稲妻など、実在の社章と似ないもの)
  - 起用前に、同名・類似名の実在企業がないか検索して確認する
- 毎回エンドカードに「この映画は 人工知能 によって作られました」を入れる(オチ兼AI表示)
- 昭和の価値観をそのまま再現しない(「奥様の仕事」など性別役割の決めつけは避け、家族全員を出す)

## シリーズ名(候補)
1. **夢見ヶ丘電機PR映画「あしたの暮らし」**(推し:社名がそのまま案件化の見本になる)
2. 「未来ハ来タレリ」
3. 「科学の夢 だより」

## 毎回の型(30〜60秒、標準45秒)
| 区間 | 内容 |
|---|---|
| 0〜3秒 | フック:機械が動いている一番ふしぎな絵 + 「ご覧ください」 |
| 3〜6秒 | タイトルカード「夢見ヶ丘電機 提供/あしたの暮らし 第N回『◯◯』」 |
| 6〜30秒 | 家庭で驚く家族 → 研究所の技術者 → 機能を大げさな言葉で説明 |
| 30〜40秒 | 小さなオチ(猫が乗る、父が機械にお辞儀する等) |
| 40〜45秒 | エンドカード(社名・標語・「人工知能によって作られました」) |

## ナレーションの言葉づかい
- 「〜であります」「〜なのです」「なんと」「まさに」「ご覧ください」
- 現代の機能を昭和の言葉に言い換えるのが笑いどころ
  - センサー → 電子の目/AI → 電子頭脳/Bluetooth → 見えない電波の糸
  - 充電 → 電気のごはん/アプリ → 手のひらの指令盤/クラウド → 空の上の記憶庫
