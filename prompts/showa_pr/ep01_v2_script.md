# 第1話(改訂版)「うちの円盤」台本構成(2026-11-16)

## 方針の変更点(初稿 ep01_osouji_enban_script.md から)
- 企業PR映画・ナレーション形式は**やめる**
- 昭和30〜40年代の服装・髪型をした日本人の、**ごく普通の家庭の日常**を撮った映像にする
- その中で、現代のもの(ロボット掃除機)が**当たり前の家財道具として**使われている
- 誰も驚かない・説明もしない。昭和の暮らし方や家族の会話のまま現代の道具に接する「ズレ」で笑わせる
- 映像の質感(16mm風・4:3・色あせ・モノラル)は従来どおり

## 基本情報
- 尺:約42秒/会話劇(ナレーションなし)。セリフは字幕も付ける
- 舞台:団地の茶の間(畳・ちゃぶ台・ふすま・黒電話・脚付きテレビ)と縁側
- 時間帯:日曜の朝 → 夕方

## 音
- 会話は昭和のホームドラマ風の口調(「〜なさい」「〜だろう」「〜ねえ」)。大げさな芝居はしない
- BGM:のんびりした昭和のホームドラマ風のオリジナル曲(実在の曲・番組の主題歌には似せない)
- 生活音:茶碗の音、新聞をめくる音、縁側の風鈴。円盤の動作音は控えめに
