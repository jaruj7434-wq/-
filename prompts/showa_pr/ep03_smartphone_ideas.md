# 第3話 案:昭和43年の「最新型スマホ」CM(2026-11-17)

## コンセプト
- 昭和43年(1968年)には、スマホがもう当たり前にある、という設定
- そのうえで出た「最新機種」の、昭和ならではの変な機能・面白機能を、大まじめに宣伝するカラーCM
- 商品:**ユメミフォン 43年型**(架空。実在のスマホのデザイン・ロゴには似せない。クリーム色の本体に、クロームの縁取り)
- 作り方は第2話と同じ:CMガールの問いかけで始め、Wan 3.0 で約28秒を1本で作り、仕上げでカラーの昭和テレビ風にする

## 面白機能の候補
| # | 機能 | 中身・笑いどころ |
|---|---|---|
| 1 | **十円玉投入口** | 電話をかけると「十円玉を入れてください」。本体の横の投入口に十円玉を入れると、チャリン!と通話がつながる。長電話の娘が十円玉を山積みにしている |
| 2 | **電話交換手アシスタント** | 話しかけると、画面に小さな交換手のお姉さんが現れて「何番におつなぎしますか?」 |
| 3 | **写真館モード(自撮り)** | 自撮りすると「はい、動かないでー」と声。家族全員がカチコチのポーズで固まり、最後にボンッ!とマグネシウムのフラッシュが光って煙だらけ |
| 4 | **ハンコ機能** | 回覧板に、スマホの画面をそのまま押しつけるとハンコが押せる |
| 5 | **雷おやじ通知** | お父さんの機嫌が悪くなると、家族のスマホが一斉にブルブル震えて知らせる |
| 6 | **ダイヤル式入力** | 画面に黒電話のダイヤルが出て、番号を指でジーコジーコ回す。0 を回すのが一番遅い |
| 7 | **お見合いアプリ** | 見合い写真を左右にめくる。決まると仲人さんが画面から出てくる |

## おすすめの組み合わせ(30秒に3機能)
1. 冒頭(0–3秒):CMガール「まだ、黒電話の前で順番待ちしていますか?」
2. 登場(3–6秒):「ユメミの最新型、ユメミフォン!」
3. 機能①写真館モード(6–13秒):家族で自撮り →「はい、動かないでー」→ 全員カチコチ → ボンッ!と煙
4. 機能②十円玉投入口(13–20秒):娘が長電話 →「十円玉を入れてください」→ 横の投入口に十円玉をチャリンチャリン。机には十円玉の山
5. 機能③ハンコ機能(20–26秒):回覧板が回ってくる → おばあちゃんがスマホの画面をポンと押しつける → 紙にハンコ。CMガール「ハンコにも、なります」
6. 社名カード(26–28秒+編集)
