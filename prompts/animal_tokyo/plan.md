# 企画書：動物目線の東京（セッション開始用）

> 配置: `prompts/animal_tokyo/plan.md`（既存シリーズに合わせて prompts/ 配下に置いた）
> CLAUDE.md のルール（日本語で返答／Higgsfield生成前に必ず許可を取る）に従って進めること。

## コンセプト
東京で暮らす動物の視点（POV）で、街の24時間を見せるシリーズ。
例：渋谷のカラス、築地の猫、皇居のお堀のカメ、新宿のドブネズミ、上野のハト、多摩川のタヌキ。

## 狙い
- 人間には見えない「低い目線・空からの目線」の東京で、見慣れた街を新鮮に見せる
- 動物の習性（エサ場、縄張り、天敵）を実際の生態に沿って紹介し、教養要素も入れる
- 時刻テロップ（例：AM 4:12）で「密着感」を出す

## 動画の型
- ショート（30〜60秒）：1シーン完結。「渋谷のカラスがゴミの日を知っている理由」など
- 長尺（8〜10分）：1匹の24時間を時刻ごとに追う

## リアルさを出すポイント
- カメラは動物の目線の高さ・動き（低い位置、小刻みな揺れ、空撮の滑空）
- 環境音（車、電車、雨、人の話し声）をしっかり入れる
- 動物に人間の言葉はしゃべらせない（ナレーションは観察者目線）

## 制作の分担
| 要素 | 作り方 |

目安：Claude Code 4割／Higgsfield 6割（映像の比重が大きい企画）

## 第1話の候補
- 「渋谷のカラスの24時間」（夜明けのゴミ漁り → 縄張り争い → 夕方のねぐら）
- 「築地の猫の朝」（市場の朝 → 魚のおこぼれ → 昼寝）

## 最初にやること
1. 第1話の動物と街を決める
2. その動物の生態（行動時間・エサ・ねぐら）を調べて `plan.md` にまとめる
3. 時刻ごとのカット割り表を作る
4. Higgsfieldで作るカット一覧（プロンプト案・本数・クレジット目安）を提示して、許可をもらう

## 生態リサーチ：東京のハシブトガラス
台本に使うときは「出典あり」の行だけを断定口調にする。

| 項目 | 内容 | 確度 | 出典 |
|---|---|---|---|
| 種類 | 大都市ではハシブトガラスが多く、郊外・農地ではハシボソガラスが多い | 出典あり | 日本鳥学会誌 53巻2号 |
| ねぐら | 都心のカラスは夜、大きな緑地で休む。自然教育園（白金台）や明治神宮が使われている | 出典あり | 自然教育園報告 32号、中央区 |
| 明治神宮 | 内苑は約72ha、そのうち約60haが森。夜間は人が入れない | 出典あり | 自然教育園報告 32号 |
| 代々木公園 | 芝生が多く、夜も人が入れるため、ねぐらとしてはあまり使われていないらしい（中央区の資料は「代々木公園など」と書いており、記述が分かれる） | 要注意 | 自然教育園報告 32号／中央区 |
| 朝の始動 | 日の出の30分以上前、まだほぼ暗いうちから鳴き始める（冬はさらに早い）。※仙台での観察で、鳴き始め＝出発とは限らない | 出典あり（地域注意） | Strix 10 |
| 夕方 | ねぐらに入る前、集合地にいったん集まってから戻る | 出典あり | 日本鳥学会誌 53巻2号 |
| エサ | 雑食。都市で増えた最大の要因は人が出す大量の生ごみ | 出典あり | 東京都環境局 |
| ゴミ対策 | 生ごみを袋の奥に入れる（中身が見えないように）、防鳥ネットで覆う | 出典あり | 目黒区、中央区 |
| 収集時間 | 「収集日当日の朝8時までに出す」と案内する区がある（葛飾区）。**渋谷区の時間は未確認** | 要確認 | 葛飾区 |
| 繁殖期 | 3〜7月ごろ。巣の周り半径20〜100mを縄張りにする | 出典あり | 中央区 |
| 個体数 | 2001年度は都内で3万〜3万5千羽と推計。令和6年度までに約80%減った | 出典あり | 東京都環境局 |

### 台本上の注意
- 11月は繁殖期の外なので、秋冬の回で「巣を守る縄張り争い」を山場にすると生態とずれる。縄張り争いは春〜初夏の回に回す
- 「カラスはゴミの日を覚えている」は広く言われるが、今回は出典が見つかっていない。使うなら「〜と言われる」にとどめる
- 時刻テロップは演出用の目安。11月中旬の東京の日の出は6時過ぎごろ
