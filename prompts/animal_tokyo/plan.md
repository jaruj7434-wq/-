# 企画書：動物目線の東京（セッション開始用）

> 配置: `prompts/animal_tokyo/plan.md`（既存シリーズに合わせて prompts/ 配下に置いた）
> CLAUDE.md のルール（日本語で返答／Higgsfield生成前に必ず許可を取る）に従って進めること。

## コンセプト
東京で暮らす動物の視点（POV）で、街の24時間を見せるシリーズ。
例：渋谷のカラス、築地の猫、皇居のお堀のカメ、新宿のドブネズミ、上野のハト、多摩川のタヌキ。

## 狙い
- 人間には見えない「低い目線・空からの目線」の東京で、見慣れた街を新鮮に見せる
- 動物の習性（エサ場、縄張り、天敵）を実際の生態に沿って紹介し、教養要素も入れる
- 時刻テロップ（例：AM 4:12）で「密着感」を出す

## 動画の型
- ショート（30〜60秒）：1シーン完結。「渋谷のカラスがゴミの日を知っている理由」など
- 長尺（8〜10分）：1匹の24時間を時刻ごとに追う

## リアルさを出すポイント
- カメラは動物の目線の高さ・動き（低い位置、小刻みな揺れ、空撮の滑空）
- 環境音（車、電車、雨、人の話し声）をしっかり入れる
- 動物に人間の言葉はしゃべらせない（ナレーションは観察者目線）

## 制作の分担
| 要素 | 作り方 |
|---|---|
| 台本・生態の事実確認 | Claude Code（Web検索で出典を確認） |
| POV映像・動物のカット | Higgsfield（**生成前に必ず許可を取る**） |
| 時刻テロップ・地図・生態の図解 | Claude Code |
| 環境音の合成・BGM・字幕・編集 | Claude Code |

目安：Claude Code 4割／Higgsfield 6割（映像の比重が大きい企画）

## 第1話の候補
- 「渋谷のカラスの24時間」（夜明けのゴミ漁り → 縄張り争い → 夕方のねぐら）
- 「築地の猫の朝」（市場の朝 → 魚のおこぼれ → 昼寝）

## 最初にやること
1. 第1話の動物と街を決める
2. その動物の生態（行動時間・エサ・ねぐら）を調べて `plan.md` にまとめる
3. 時刻ごとのカット割り表を作る
4. Higgsfieldで作るカット一覧（プロンプト案・本数・クレジット目安）を提示して、許可をもらう
