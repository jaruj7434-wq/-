# 第2話（作り直し）「スクイーズを揉んだときの"脳汁"の正体」

- 映像: **Blender（無料）でローカル制作**。Higgsfield は使わない（クレジット0）
- 前の版（ep02_squishy.md、Higgsfield生成）は、ユーザーの意図と違う作り方だったため不採用
- 型は第1話と同じ: 0秒で揉む → 巻き戻し → スロー → 一時停止で問いかけ → 中をのぞく → 意外なオチ → 次の一瞬をコメント募集

## 仕組み（出典付き）

| # | 事実 | 出典 |
|---|---|---|
| 1 | 指先の触覚の信号は、約0.02秒で脳に届く（手首刺激→体性感覚野の反応 約18ms） | N20 正常値研究 1986 [^n20] |
| 2 | 気持ちいい感触（ベルベットなど）は、ただ触れたときより「眼窩前頭皮質」（ごほうび・快に関わる場所）を強く動かす | Francis, Rolls ら 1999 / Rolls ら 2003 [^rolls] |
| 3 | ドーパミンを出す神経（脳の奥の中脳）は、予想より良いごほうびのときに強く反応する | Schultz, Dayan & Montague 1997, *Science* [^sch] |
| 4 | ドーパミンは「快感そのもの」というより「もっとほしい（wanting）」を生む。快感（liking）は別のしくみ（オピオイドの"ホットスポット"）が担う | Berridge ラボ [^ber] |

**言い方の注意**
- スクイーズそのものでドーパミンを測った研究は見つけられていない → 「〜と考えられています」「一般的な脳のしくみ」として話す。説明欄にも明記
- 「ストレスが減る」は言わない（ストレスボールの試験で効果なし、JAMA Dermatology 2018）
- 「脳汁」は俗語として使い、正体＝ドーパミンなどの脳内物質、と説明する

## 制作手順（クレジット不使用）
1. `pip install bpy`（Blender 5.3 を Python モジュールとして使う。EEVEE は GPU がないため不可 → Cycles CPU）
2. `python3 scripts/science_0001/blender/ep02_scenes.py {squishy|nerve|reward|dopamine}` — 540x960・15fps でレンダリング
3. `python3 scripts/science_0001/ep02b_explainer.py --clips` — 30fps に補間・1080x1920 に拡大・光のにじみ
4. `python3 scripts/science_0001/ep02b_explainer.py` → `python3 scripts/science_0001/ep02b_mix.py` → `assets/output/science_0001/ep02b.mp4`（約50秒）

## Blender のシーン
- squishy: ミント色のまんじゅう形スクイーズを、上から丸い指が押す。シェイプキーでつぶれ→ゆっくり戻る
- nerve: 神経の管を光の粒が通って脳へ届き、脳の上部が光る
- reward: 脳の前側の下（眼窩前頭皮質のあたり）が暖色に光る
- dopamine: 脳を半透明にし、脳の奥（中脳のあたり）から金色の粒が湧き出す
- 脳は様式化したモデル（しわは Marble テクスチャの凹凸）。位置は「あたり」の表現で、解剖学的に厳密ではない
