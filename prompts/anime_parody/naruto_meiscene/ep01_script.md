## カット表

### カット1「影分身の術」(約10秒)
- **場所**: 朝の通勤ラッシュの駅前
- **映像**: オレンジの忍が人混みの中で両手の指を十字に組み、真剣な顔で叫ぶ → 足元から白い煙がモクモク → 煙が晴れても、本人が1人立っているだけ。周りのサラリーマンが無言で避けて通る。
- **テロップ**: 「影分身の術だってばよ!!」→(煙が晴れて)「……」→ 小さく「※実写だと煙はただの発煙筒です」
- **SE**: ボンッ → 沈黙 → 駅の雑踏音

### カット2「忍者走り」(約10秒)
- **場所**: 駅の構内、階段の手前
- **映像**: オレンジの忍が両腕を真後ろに伸ばし、前傾姿勢で全力ダッシュ(いわゆる忍者走り)→ 改札前で駅員さんに手で制止され、ピタッと止まって頭を下げる。
- **テロップ**: 「遅刻するってばよ!!」→ 駅員「駆け込みはおやめください」→ 「……すみません」
- **SE**: シュタタタ → ピピーッ(笛)

### カット3「ラーメン屋の先生」(約10秒)
- **場所**: 夜の商店街の小さなラーメン屋台
- **映像**: 3人がカウンターに並ぶ。銀髪の先生がついにマスクを下ろそうとする → 2人が身を乗り出して凝視 → その瞬間、ラーメンの湯気で画面が真っ白になる → 湯気が晴れると先生はもうマスク姿で「ごちそうさま」。
- **テロップ**: 「ついに先生の素顔が……!」→(湯気)→ 先生「ごちそうさま」→ 2人「早っ!!」
- **SE**: ズルズル → シュワーッ(湯気)→ ガーン

### カット4「谷の決戦」(約12秒)
- **場所**: 近所の公園、小さな噴水の前(滝のつもり)
- **映像**: オレンジの忍と黒髪の忍が噴水を挟んで向かい合い、風に吹かれて見つめ合う → 同時に駆け寄り、それぞれ手のひらを突き出して叫ぶ → エフェクトは一切出ず、手のひら同士がペチッとぶつかる → 2人とも手を押さえて痛がる → 背後から公園の管理人のおじさんが「噴水に入らないでくださーい」。
- **テロップ**: 「らせ…なんとか丸!!」「ち…なんとか鳥!!」(技名はぼかす)→ ペチッ →「いってぇ…」→ 管理人「噴水に入らないでくださーい」
- **SE**: ビュオオ(風)→ ペチッ → 鳥の鳴き声

### カット5「オチ」(約8秒)
- **場所**: 夕焼けの河川敷
- **映像**: 3人が並んで座り、夕日を見ている。オレンジの忍がしみじみ語る → 先生が文庫本から目を離さずにひと言。
- **テロップ**: オレンジ「実写化って……難しいってばよ」→ 先生「だから言ったでしょ」→ 締めテロップ「次回、修行編(たぶん)」
- **SE**: カラスの鳴き声 → 軽いオチの効果音

## 制作メモ

- 3人を全カットで同じ顔にするため、最初にキャラクター参照(`/character-sheet` または Elements)を作るのがおすすめ。
- 動画化はキービジュアル確定後に image-to-video で行う。1カットあたり5〜10秒想定。
- テロップ・SEは最後に編集(`/editing-room`・`/subtitles`)で入れる。
- **画像・動画の生成は、すべてユーザーの許可を得てから実行する。**
