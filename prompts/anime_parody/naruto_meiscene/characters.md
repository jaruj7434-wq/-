# 登場キャラクター設定(キャスト案 v2)

- 作り方: Higgs Field `/character-sheet` ワークフロー(スタイル: **Realism / 実写**)
- 手順: ①顔(`soul_2`, 3:4)→ ユーザー確認 → ②衣装フラットレイ(`seedream_5_5`, 3:4, 2K)→ ③3面シート(正面・背面・顔アップ)(`gpt_image_2_6`, 16:9, 2K)
- 方針: 顔はすべて**オリジナルの架空人物**(実在俳優・原作キャラの顔の再現はしない)。原作らしさは髪型・衣装・小物で出す。
- 概算コスト(2026-11-27 見積もり): 1人あたり 顔 約0.12 + 衣装 1.5 + シート 1.25 ≒ **約2.9クレジット**
  - 無制限枠は現在使えないため、通常クレジットを消費する

## 1. オレンジの忍(主人公役)

- 役割: 主人公 / underdog(周りに笑われても本気で忍術を信じている、応援したくなるおバカ)
- 年齢: 22歳 / 男性 / 日本人
- 肌: 健康的なやや日焼けした肌 / 目: 濃い茶色(明るい表情)
- 髪: 明るい金髪(ブリーチ)、短めでツンツンに立てたスタイル
- ひげ: なし
- 体型: 細マッチョ、身長やや低め
- 特徴: 両頬にうっすら3本線のフェイスペイント
- 衣装: 着古したオレンジ×黒のジャージ上下、青い布の額当て(無地の金属プレート)、黒いサンダル風スニーカー

## 2. 黒髪の忍(ライバル役)

- 役割: 主人公側 / ally(クールぶっているが、実はノリノリで付き合う相棒)
- 年齢: 22歳 / 男性 / 日本人
- 肌: 色白 / 目: 黒に近い濃い茶色(切れ長、冷めた目つき)
- 髪: 黒髪、前髪長め、後ろ髪がはねたスタイル
- ひげ: なし
- 体型: 細身で長身
- 衣装: 紺のハイネック半袖シャツ、白いアームカバー、白っぽいハーフパンツ、青い額当て

## 3. 銀髪の先生(先生役)

- 役割: 主人公側 / ally(やる気がなさそうで、真顔で一番ひどいツッコミを入れる先生)
- 年齢: 32歳 / 男性 / 日本人
- 肌: 標準的な肌色 / 目: 眠たげな半目、濃い茶色
- 髪: 銀髪(ブリーチ)、斜めに逆立ったボリュームのあるスタイル
- ひげ: なし(マスクで口元は見えない)
- 体型: 長身で引き締まった体
- 衣装: 口元を覆う紺のマスク、額当てを片目に斜めがけ、紺の長袖シャツの上に緑のベスト、手には文庫本

## 4. オカン(主人公の母)

- 役割: 主人公側 / ally(弁当を届けに神出鬼没で現れる、パワフルな大阪のおばちゃん)
- 年齢: 54歳 / 女性 / 日本人
- 肌: 標準的な肌色 / 目: 濃い茶色(よく笑う目元)
- 髪: 茶色に染めたショートパーマ
- 体型: ふくよか、小柄
- 衣装: ヒョウ柄のカットソーにエプロン、つっかけサンダル、手に風呂敷包みのお弁当

## 5. 白装束のラスボス(十尾の人柱力・オビト役)

- 役割: 敵役 / oppressor(神のような力を手にしたつもりの最強ラスボス。ただし実写だと装備がすべて手作り感満載)
- 年齢: 30歳 / 男性 / 日本人
- 肌: 色白(ほぼ血の気がない白さのメイク) / 目: 左目が赤、右目が淡い紫の波紋模様のカラーコンタクト(左右で色違い)
- 髪: 白髪(ブリーチ)、ボサボサに逆立った短めのスタイル
- ひげ: なし
- 体型: 中背で筋肉質
- 特徴: 顔の右半分に、ひび割れたような古い傷跡の特殊メイク
- 衣装: 白い着物風のロングローブ(襟元に黒い勾玉模様6つ)、黒い錫杖風の長い棒、裸足
- パロディ要素: 背後に浮かぶはずの黒い球体9つが、実写では**黒いバランスボールを紐でくくって背負っているだけ**(ボケの小道具として使う)
