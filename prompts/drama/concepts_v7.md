# 面白い赤ちゃん動画の台本構成案(2026-11-11)

## 共通の「面白さの型」
1. **あるある**:親なら必ず見たことがある赤ちゃんの行動(ティッシュ全部出す、リモコンを狙う、寝たふり、変顔)→ コメント・シェアが増える
2. **3回くり返し+エスカレーション**:同じ型を3回、毎回少し大きく → 3回目で裏切る
3. **スケールのギャップ**:赤ちゃんにとっての大事件を、映画の大作のように撮る
4. **ループ**:最後のカットが最初のカットにつながる → 何度も見られて再生時間が伸びる
5. **冒頭1秒**:いちばん変な瞬間(顔・状況)から始める

## 案1:だるまさんがころんだ(おすすめ)
ママが見ていない時だけ動く赤ちゃん。ママが振り向くと、ピタッと止まって天使の顔。
| 秒 | 内容 |
|---|---|
| 0–2 | (フック)ティッシュまみれでにっこりする赤ちゃんのアップ → 「…10秒前」ではなく、そのまま時間を戻す巻き戻し演出 |
| 2–8 | ①ママが洗濯物をたたんでいる。背中を向けた瞬間、赤ちゃんが高速ハイハイでティッシュ箱へ。ママが振り向く → 床に寝転んで天使の寝顔(ピタッ) |
| 8–16 | ②ママが背を向ける → ティッシュを1枚シュッ。振り向く → ティッシュを頭にのせたまま、まじめな顔でおすわり |
| 16–26 | ③ママが背を向ける → 全力で連続シュシュシュ!部屋中がティッシュの雪景色。振り向く → ティッシュの山から顔だけ出して、満面の笑み |
| 26–32 | オチ:ママが笑ってスマホで撮影 → 赤ちゃんがカメラ目線でもう1枚シュッ(ループ:冒頭の顔へ) |
- セリフなし。音は効果音と、ピタッと止まる時の無音だけで笑わせる
- シリーズ化:リモコン、スマホ、冷蔵庫の扉、ママの化粧品、パパのメガネ…「狙うもの」を変えるだけで量産できる

## 案2:リビング大冒険
ハイハイでリビングを横断するだけの話を、冒険映画のように撮る。
| 秒 | 内容 |
|---|---|
| 0–3 | 超ローアングル、壮大な音楽。ソファの上のクッキーを見上げる赤ちゃん |
| 3–10 | ①じゅうたんの大草原を進む(足元すれすれのカメラ、遠くにそびえるソファ) |
| 10–17 | ②眠るネコ(ドラゴン)の横を、息を殺して通過。しっぽがピクッ → 固まる |
| 17–25 | ③ソファの山を登る。クッションが崩れ落ちる → ギリギリでつかまる(スロー) |
| 25–32 | 頂上でクッキーをつかむ → 勝利のポーズ → その場でコテンと寝落ち(大きな手が毛布をかける) |
- 赤ちゃん目線のカメラと「大げさな音楽」が面白さの核。3Dプリビズの強みがいちばん生きる

## 案3:赤ちゃん vs ○○(3本勝負)
ロボット掃除機、鏡の中の自分、ネコ、扇風機、など毎回の対戦相手と3ラウンド戦う。
- 例「赤ちゃん vs ロボット掃除機」:①近づいてきて逃げる ②乗ってみる(ぐるぐる回る)③最後は上で寝ている

## 案4:ヒーロー(改)— がんばるけど赤ちゃん
ヒーローに変身するが、毎回どこか赤ちゃん(変身の途中で眠くなる、マントが逆、ミルクの時間で中断)。でも結果的に助かる。
- 前回までのヒーロー案の「真面目なかっこよさ」をやめ、ズッコケと偶然の成功で笑わせる
