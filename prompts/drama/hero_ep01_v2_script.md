# ヒーローベイビー 第1話 v2『3つのお助け』— 監督コンテ(約40秒・20カット)

## 演出方針(プロの映画監督として)
- **テンポ**:1カット1.5〜2.5秒。動きの途中でカットを割る(カット・オン・アクション)。生成は4〜5秒、編集でいちばん良い瞬間だけ使う
- **画角の使い分け**:超アップ(ミルク瓶・手元・目)/アップ(感情)/ミドル(芝居)/引き(位置関係)を毎シーンで切り替える
- **レンズとカメラ**:ヒーローは24mm相当のローアングルで大きく、感情は85mm相当のアップで背景をぼかす。動きはドリーイン、回り込み、クレーン、手持ちの追い、スローモーション
- **画面の向き**:くるんの進行方向は常に左→右(迷子にならない)
- **光**:お昼の青空 → 3つ目のお助けで夕方 → ラストは夕日(時間経過で1日の物語に)
- **表情**:毎カット、表情を具体的に指示(目の大きさ、口の形、眉、ほっぺ)
- **変身**:毎回同じ「シグネチャー」。①空を見上げてキラーン ②おなかのポケットから仮面を取り出す ③顔にパチッとはめる ④くるっと回転して服が変わる ⑤決めポーズ「ばぶっ!」
- テロップはセリフ字幕のみ、小さく控えめに

## 衣装の追加
- 普段着の水色のロンパースに、おなかの前ポケット(カンガルーポケット)を付ける。仮面はふだんそこに入っている
