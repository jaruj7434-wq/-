# ばぶばぶ愛ランド — シリーズ設計(v5:ほっこり昼ドラ)

## 方針(ユーザー指示 2026-11-11)
- 昼ドラの「感情の山」の作りで、赤ちゃんの日常の**良い行い**と、核心を突く**ひとこと(ばぶ名言)**を描く、ほっこり動画
- リサーチ(docs/research/2026-11-viral-baby-ai-animation.md)の勝ちパターンを使う:
  - 冒頭1〜3秒で一番ドラマチックな瞬間を見せる
  - 1分以内に「困った→迷う→優しさ→救われる」と感情を大きく動かす(AI猫の昼ドラ型)。言葉が分からなくても表情と音楽で伝わる
  - 見た目と中身のギャップ:赤ちゃんなのに、大人がハッとする一言
  - 毎回同じ締め:「今日のばぶ名言」カード(保存・シェアされやすい)
- セリフは名言のひとこと+短い赤ちゃん語だけ。声は動画生成時に「かわいい赤ちゃんの声」と指示する
- カットは8前後に絞り、1カットの芝居をじっくり見せる。BGMはピアノと弦の昼ドラ調→最後はあたたかく
- 映像は3Dプリビズで配置とカメラを決めてから作る

## 1話の型(約50秒)
| 秒 | パート | 内容 |
|---|---|---|
| 0–3 | フック | いちばん悲しい瞬間(落ちる、泣く、ひとりぼっち)をスローで |
| 3–15 | 困りごと | 何が起きたかを1〜2カットで見せる |
| 15–22 | 葛藤 | 主人公が迷う(目のアップ、ドラマ調の音楽) |
| 22–38 | 優しさ | 赤ちゃんらしいやり方で助ける → 名言のひとこと |
| 38–45 | ごほうび | 小さなお返しで、全員が笑顔に |
| 45–50 | 締め | 「今日のばぶ名言」カード+次回タイトル |

| 先生 | 手とエプロンだけ。いつも見守っている |
