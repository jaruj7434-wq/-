# ばぶばぶ愛ランド — シリーズ設計(v3:セリフなしで分かる赤ちゃんバトル)

## v3 の方針(ユーザー指示 2026-11-11)
- **音声を先に作らない**:声は動画生成のプロンプトで「かわいい赤ちゃんの声で◯◯と言う」と指示するだけにする(Seedance の音声生成機能)
- **実況(MCバブ)はなし**
- **セリフがなくても分かる**:赤ちゃんならではの「ひとつしかない物の取り合い」を、映像だけで伝える
- セリフは赤ちゃん語の短い一言だけ(「ぷりん!」「ぼくの!」「だめぇ〜」「やー!」)。声は全員かわいい赤ちゃん声

## 1話の型(約60秒)
| 秒 | パート | 内容 |
|---|---|---|
| 0–3 | フック | 取り合いのクライマックス(空中で手を伸ばすスロー静止など)。取り合う物が必ず画面に入っている |
| 3–10 | 発端 | 「ひとつしかない物」が登場 → 全員の目がロックオン(よだれ、キラキラの目) |
| 10–35 | 争奪戦 | キャラごとの得意技で1人ずつ挑戦 → ドタバタ → 全員同時に飛びかかる |
| 35–50 | どんでん返し | 寝ているねんねちゃんが、寝たまま横取り |
| 50–60 | 赤ちゃんらしいオチ+引き | 泣く → 先生の手が解決 → 超かわいい笑顔。最後にねんねちゃんの小さな「次の悪だくみ」 |

### 分かりやすくするルール
1. 取り合う物は1話に1つだけ。大きく、明るい色で、いつも画面のどこかに映す
2. 誰が何をしたか、は「手」と「目線」のアップで見せる
3. 1カット1アクション。カメラは寄り→引きで状況を見せる
4. テロップは最小限(タイトルと「つづく」/次回タイトル程度)
