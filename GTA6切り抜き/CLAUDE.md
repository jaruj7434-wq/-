# CLAUDE.md — GTA6切り抜きチャンネル

このフォルダは、新作ゲーム「GTA6」の**切り抜き動画チャンネル**を運用するためのプロジェクトです。
Claude Code はこのフォルダで作業する際、以下のルールに必ず従うこと。

## 基本ルール

- **返答はすべて日本語**で行う。
- **Higgsfield(`mcp__higgs_field__*`)で動画・画像を生成する場合は、必ず事前にユーザーの許可を取ってから**生成に入る。
  (サムネイル生成・アップスケール・リフレーム等も含む。無断でクレジットを消費しない。可能なら `use_unlim: true` を優先)
- **動画が完成したら、動画タイトルと紹介文(概要欄)を必ずセットで出す**。ハッシュタグも添える。

## プロジェクト内容

- YouTube で「クリエイティブ・コモンズ」フィルタをかけて出てくる、再利用可能な GTA6 プレイ動画を素材にする。
- 元動画から最も盛り上がる場面(カーチェイス、爆発、銃撃戦、面白い会話、事故・ハプニング等)を探して切り抜き、編集まで行う。
- 出力フォーマット:
  - **縦型**(ショート/リール/TikTok向け): 1080x1920
  - **横型**(YouTube通常動画向け): 1920x1080

## 素材のルール(使用前に必ず確認)

元動画を使う前に、以下を**すべて**確認し、結果を `sources.md` に記録する。1つでも満たさない/判断できない場合は使用せず、ユーザーに報告する。

1. **ライセンス**: 概要欄の一番下の「ライセンス」が**クリエイティブ・コモンズ(表示)**になっていること。
   - yt-dlp のメタデータ(`license` フィールド)でも確認し、両方の結果を記録する。
2. **投稿者本人のプレイ映像**であること(無断転載・他人の動画の再アップでないこと)。
   - チャンネルの他の動画、ウォーターマーク、配信アーカイブかどうか等から判断する。
3. **発売日(2026/11/19)以降に公開された本物の GTA6 映像**であること。
   - 公開日が発売日より前 → 流出映像の可能性があるので使わない。
   - GTA5 の MOD、AI 生成フェイク、トレーラーの再編集は使わない。
4. **ゲーム内ラジオ曲**(実在楽曲)が流れている部分は避けるか、音を差し替える(Content ID 対策)。
   - 差し替える場合は著作権フリー音源、または元のゲーム効果音のみにする。
5. **クレジット**: 概要欄に元動画の URL と投稿者名を必ず入れる。
6. 使った動画とライセンスは **`sources.md`** に記録する。

## フォルダ構成

| フォルダ / ファイル | 用途 |
|---|---|
| `01_download/` | yt-dlp でダウンロードした元動画・メタデータ(info.json) |
| `02_clips/` | ffmpeg で切り出した素の切り抜きクリップ |
| `03_edit/` | 編集途中のファイル(字幕ファイル、テロップ、中間書き出し等) |
| `04_output/` | 完成動画(縦型・横型) |
| `05_meta/` | 文字起こし、盛り上がり候補リスト、タイトル・概要欄・ハッシュタグ |
| `sources.md` | 使用素材とライセンスの記録 |

動画・音声などのバイナリは git にコミットしない(`.gitignore` 済み)。テキスト(メタ情報・台本・記録)のみコミットする。

### ファイル命名規則

- 元動画: `01_download/<動画ID>.<ext>`
- クリップ: `02_clips/<動画ID>_<開始秒>-<終了秒>.mp4`
- 完成品: `04_output/<YYYYMMDD>_<短い内容名>_vertical.mp4` / `_horizontal.mp4`
- メタ: `05_meta/<YYYYMMDD>_<短い内容名>.md`(タイトル・概要欄・ハッシュタグ)

## 作業フロー

### 1. ダウンロード
- `yt-dlp` で元動画をダウンロードする(未インストールなら `pip install -U yt-dlp` でインストール)。
- `--write-info-json` でメタデータも保存し、ライセンス・公開日・投稿者名を確認する。
- 例: `yt-dlp -f "bv*[height<=1080]+ba/b" --merge-output-format mp4 --write-info-json -o "01_download/%(id)s.%(ext)s" <URL>`

### 2. 盛り上がり場面の候補出し
- **Whisper** で文字起こし(日本語/英語自動判定)。結果は `05_meta/` に保存。
- **ffmpeg** で音量(RMS / ラウドネス)のピークを解析する。
- 文字起こし(叫び声・笑い・会話のキーワード)と音量ピーク(爆発・衝突・銃声)を組み合わせ、
  **盛り上がり場面の候補をタイムスタンプ付きで一覧にしてユーザーに提示**する。
  - 各候補に: 開始〜終了時刻、内容の要約、盛り上がりの根拠(音量ピーク値・セリフ)、ラジオ曲の有無 を書く。
- **ユーザーが選ぶまで切り出し・編集には進まない。**

### 3. 切り出し
- ユーザーが選んだ場面を ffmpeg で切り出す(フレーム精度のため再エンコードで切る)。

### 4. 編集
- **冒頭1〜2秒に強いフック**(一番の見せ場を先頭に持ってくる/煽りテロップ)。
- **テロップは太字+縁取り**(例: 白文字+黒縁、Noto Sans CJK JP Bold / Black)。
- **不要な間のカット**(無音・移動だけの区間を詰める)。
- **縦型は主役(プレイヤーキャラ・車両)を中央にクロップ**。動きが大きい場合はクロップ位置を区間ごとに調整する。
- **音量は -14 LUFS に正規化**(ffmpeg `loudnorm=I=-14:TP=-1:LRA=11`、2パス推奨)。
- ラジオ曲区間はカットするかミュート/差し替え。

### 5. 書き出し・納品
- 縦型 1080x1920 / 横型 1920x1080、H.264 + AAC、30fps または元のfps、`-movflags +faststart`。
- 納品時は以下を**必ずセット**で提示し、`05_meta/` にも保存する:
  - 動画タイトル(縦型/横型それぞれ)
  - 紹介文(概要欄) — **元動画の URL と投稿者名のクレジット、ライセンス表記を必ず含める**
  - ハッシュタグ
- `sources.md` を更新する。

## 使用ツール

- `yt-dlp` — ダウンロード
- `openai-whisper`(または `faster-whisper`)— 文字起こし
- `ffmpeg` / `ffprobe` — 音量解析、切り出し、クロップ、テロップ焼き込み、ラウドネス正規化
- Higgsfield — サムネイル生成・リフレーム等が必要な場合のみ(**事前許可必須**)
