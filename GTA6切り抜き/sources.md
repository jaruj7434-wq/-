# 使用素材の記録(sources.md)

元動画を使用する前に、以下のチェックをすべて満たしたものだけを記録・使用する。

| # | 元動画タイトル | URL | 投稿者名(チャンネル) | 公開日 | ライセンス | 投稿者本人のプレイ映像か | 発売日(2026/11/19)以降の本物のGTA6か | ラジオ曲区間 | 使用した区間 | 出力ファイル | 確認日 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | |

## 記入メモ
- ライセンス欄は概要欄最下部の表記をそのまま転記する(例:「クリエイティブ・コモンズ 表示ライセンス(再利用を許可する)」)
- 「本物のGTA6か」は判断根拠も簡単に書く(公開日・UI・投稿者の過去動画など)
- ラジオ曲区間は「避けた/音差し替え」など対応も書く
