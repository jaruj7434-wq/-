# ディープインパクト リサーチメモ

出典: Wikipedia「ディープインパクト (競走馬)」(ja, 2026-10-28 取得)。各記述の一次出典は同記事の脚注 (JBIS, netkeiba, スポニチ等)。

| 項目 | 内容 |
|---|---|
| 生年月日 | 2002年3月25日 (父サンデーサイレンスと同じ誕生日) |
| 生産 | ノーザンファーム (北海道勇払郡早来町、現・安平町) |
| 血統 | 父サンデーサイレンス / 母ウインドインハーヘア (母父 Alzao) |
| 毛色 | 鹿毛。写真では黒っぽい鹿毛、たてがみ・尾・脚は黒、両後肢に白 |
| セリ | 0歳のセレクトセールで金子真人氏が7000万円で落札。馬体が薄く、上場されたサンデーサイレンス産駒14頭中9番目の価格 |
| 馬体 | レース時436〜452kgの小柄な馬。皐月賞・菊花賞などで出走馬中最軽量 |
| 鞍上 | 武豊 (全レース) |
| 皐月賞 2005 | スタート直後に躓き落馬寸前、最後方から優勝。武豊「走っていると言うより飛んでいる感じ」 |
| 日本ダービー 2005 | 5馬身差。2分23秒3のレースレコードタイ。単勝1.1倍 |
| 菊花賞 2005 | 単勝1.0倍 (100円元返し)。シンボリルドルフ以来21年ぶり史上2頭目の無敗三冠 |
| 有馬記念 2005 | ハーツクライの2着。初黒星 (連勝は7で止まる) |
| 天皇賞(春) 2006 | 3分13秒4 (芝3200m 世界レコード)、3馬身半差 |
| 宝塚記念 2006 | 京都開催、4馬身差 |
| 凱旋門賞 2006 | 3位入線。のちに禁止薬物イプラトロピウム検出で失格 (11月16日通告) |
| ジャパンカップ 2006 | 2馬身差で優勝 |
| 有馬記念 2006 (引退レース) | 3馬身差で優勝。GI7勝 (当時最多タイ) |
| 通算成績 | 14戦12勝 (国内13戦12勝、仏1戦0勝) |
| 種牡馬 | 2012〜2022年 11年連続リーディングサイアー。日英仏愛の4カ国でダービー馬 |
| 代表産駒 | コントレイル (2020 無敗三冠、父子2代の無敗三冠は世界初)、ジェンティルドンナ、キズナ、スノーフォール、オーギュストロダン (最終世代、2023英ダービー) |
| 死亡 | 2019年7月30日、頸椎骨折により安楽死。17歳 |
