## 構成 (5つの段)
1. **ひとりきり (0–15秒)**: 残される側が、ひとりで静かに止まっている。セリフなし。長い
2. **再会 (15–30秒)**: 去っていく側が横に並び、ひと言「おい、別れの言葉は無しか？」。言葉は少なく、笑顔の切り返しで見せる
3. **心の声 (30–40秒)**: 残る側の独白。前を向いたまま、相手を見ずに語る
4. **並んで走る (40–60秒)**: 一緒に走り出す。走り出しは速いカット、並走は流れるように。最後に「いつまでも俺の兄弟だ」
5. **別れ (60–83秒)**: 真上からの空撮で分かれ道。去る側をカメラが追い、空・光へ。セリフなし

## 演出の特徴
- **セリフは6つだけ、合計15秒ほど**。83秒のうち約7割は音楽と映像だけ
- 「おい、別れの言葉は無しか？」は**去っていく側 (ブライアン) が言う**。残る側は微笑んで応える
- 残る側の独白は**相手を見ないで前を向いたまま**話す (心の声)
- 色: 全体が金色〜オレンジの夕方の色。強い逆光、レンズフレア、白っぽく柔らかい空気
- カメラ:
  - 真上からの空撮 (はじめ・並走・分かれ道) で「2台の位置関係」を見せる
  - 車内は**ガラス越し・肩越し**で、表情を少しだけ見せる
  - タイヤ・路面のローアングルで「走り出し」を強調
  - 最後は**カメラが上がり続けて空へ** (天に昇るイメージ)
- テンポ: 前半はゆっくり (1カット5〜10秒)、走り出しで一気に短く (0.3〜1秒)、最後はまた長く
- 音: 音楽が主役。セリフの間は音楽を下げ、走り出しと分かれ道で上げる。車の音はほぼ聞こえない

## 馬版にするときの対応 (ディープ × ドウデュース × 武豊騎手)
| 映画 | 馬版 |
|---|---|
| 残る側: ドム (銀の車) | ドウデュースに乗る騎手 (武豊騎手のイメージ、顔は出さない) |
| 去る側: ブライアン (白い車) | ディープインパクト (光の中から現れる) |
| STOP の交差点で止まっている | 夕方の競馬場 (東京の直線のスタート地点) / 誰もいないコース |
| 横に並んで「おい、別れの言葉は無しか？」 | 映画では去る側が言う。馬は話せないので**騎手がディープに言う**形 (急にいなくなったディープへの言葉として成り立つ) |
| 笑顔の切り返し | ディープが騎手を見る・頷く ↔ 騎手の横顔 (ゴーグル) |

## 縦型 (9:16) にするときの注意
- 横長の「2台並び」は縦では入りにくい → 真上からの空撮は縦長の道と相性が良い。横並びは正面か後ろから撮る
- 尺は約50〜60秒に縮める (前半のひとりの場面を短く)
