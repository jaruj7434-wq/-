# ディープインパクト 誕生から最期まで (1本完結・縦型ショート)

- 尺の目安: 約85〜90秒 / 縦 9:16 / ナレーション: 谷上 (少し早口: speech_rate +25)
- 形式: 東海テイオー編と同じ (馬の映像が中心、谷上が本を読みながら話すカットが3回)

## 視聴維持の工夫
1. **冒頭0〜3秒のフック**: 「100円賭けても100円しか返ってこない」という意外な事実から入る (菊花賞の単勝1.0倍)
2. **答えを後回しにする**: 3カット目で「最後に、この馬の唯一の汚点も話す」と予告し、凱旋門賞の失格まで見たくなるようにする
3. **章テロップ**: 画面上部に「第1章 誕生」〜「第5章 遺したもの」を表示し、残りの長さを分かるようにする
4. **途中の引き**: 「でも本当の衝撃はここからだ」「そして、あの事件が起きる」で次の展開へつなぐ
5. **最後の行動の呼びかけ**: 「あんたにとって最強の馬は？コメントで」+「次の名馬はフォローして待ってて」(コメント・フォロー・プロフィールへの誘導)
