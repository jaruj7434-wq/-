# 賭け金別 馬券が外れた時の反応 (v1)

参考: 「年収別 娘の彼氏が挨拶に来た時(地方版)」(docs/research/reference-zuba-jiji-nenshubetsu.md)
出演・声: 谷上 / 縦 9:16 / 約28秒

- 全カット同じスタート画像(谷上がハズレ馬券を手に座る正面固定ショット)から始め、セリフと表情だけが変わる。
- 上部固定ヘッダー「賭け金別」「馬券が外れた時の反応」、中段に黒い角丸の金額ラベル、その下に白い極太のセリフ。
- 同じセリフが続く金額は1カット内で2回言い、2回目の頭で金額ラベルを切り替える。
