# ゆびさき屋台通り(Roblox 版)はじめての手順書

ソフトクリームとたこ焼きの屋台が並ぶ通りで、お客さんの注文に応えてお金を稼ぎ、
お店を強化していくゲームです。友だちと同じサーバーで一緒に遊べます。

> 画面のボタン名は、Roblox の更新で少し変わることがあります。違っていたら近い名前のものを選んでください。
> 迷ったら、その画面のスクリーンショットを Claude に送ってください。

---

## ステップ1:ロブロックスのアカウントを作る
1. https://www.roblox.com を開き、「サインアップ(登録)」
2. 誕生日・ユーザー名・パスワードを入力
   - ユーザー名は、あとで作品の作者名として表示されます(例:`yubisaki_kobo`)
   - **収益化(Robux を現金にする DevEx)には 13歳以上・メール確認などの条件があります**
3. 登録したメールアドレスに届く確認メールで、メールを認証しておく

## ステップ2:Roblox Studio を入れる(無料)
1. https://create.roblox.com を開いてログイン
2. 「作成を開始(Start Creating)」→ Roblox Studio のダウンロード
3. ダウンロードしたファイルを開いてインストール → 起動してログイン

## ステップ3:新しいゲームを作る
1. Roblox Studio で **「新規(New)」→「Baseplate(ベースプレート)」** を選ぶ
   - 灰色の広い床だけがある、まっさらな場所が開きます

## ステップ4:プログラムを2つ貼り付ける
画面の右側にある **「エクスプローラー(Explorer)」** を使います。
見当たらない場合は、上のメニューの「表示(View)」→「エクスプローラー」「プロパティ」を押して表示します。

### 4-1. サーバー側のプログラム
1. エクスプローラーの **「ServerScriptService」** にマウスを乗せ、右に出る **「+」** を押す
2. 一覧から **「Script」** を選ぶ(新しい Script ができ、中身の画面が開きます)
3. 中に最初から書いてある `print("Hello world!")` を**全部消す**
4. `src/server/YataiServer.server.lua` の中身を**まるごとコピーして貼り付け**
5. 分かりやすいように、Script の名前を `YataiServer` に変える(右クリック →「名前の変更」)

### 4-2. 画面側のプログラム
1. エクスプローラーの **「StarterPlayer」** の左の「>」を押して開く
2. 中の **「StarterPlayerScripts」** にマウスを乗せ、**「+」** を押す
3. 一覧から **「LocalScript」** を選ぶ(Script ではなく **Local**Script です)
4. 最初の `print("Hello world!")` を全部消して、
   `src/client/YataiClient.client.lua` の中身を**まるごと貼り付け**
5. 名前を `YataiClient` に変える

## ステップ5:遊んでみる(テスト)
1. 上のメニューの **「テスト(Test)」→「プレイ(Play)」**(または F5 キー)
2. 少し待つと、屋台通りができて、自分のキャラクターが現れます
3. 左右どちらかの屋台に歩いて近づき、**「お店に立つ」**が出たら押す(パソコンは E キー)
   - **ソフトクリーム**:「長押しで しぼる」を押し続けて、注文の高さ(緑の帯)で離し、「できあがり」
   - **たこ焼き**:丸のふちがきつね色になったらタップ → もう一回タップでお皿へ
4. 左下の **「お店の強化」** で、稼いだお金を使ってお店を強化
5. 止めるときは、上のメニューの **「停止(Stop)」**(Shift + F5)

### うまく動かないとき
- 上のメニュー「表示」→ **「出力(Output)」** を開くと、エラーの文章が赤字で出ます
- **その赤字をコピーして Claude に送ってください**(すぐ直します)
- 「セーブ機能が使えません」という黄色の注意は、ステップ7まで気にしなくて大丈夫です

## ステップ6:ゲームを公開する
1. 上のメニューの **「ファイル」→「Robloxに公開(Publish to Roblox)」**
2. 名前:`ゆびさき屋台通り`、説明文、ジャンルを入れて公開
3. 最初は **非公開(Private)** のままで OK。準備ができたら「公開(Public)」にする

## ステップ7:セーブ機能を有効にする(公開したあと)
1. 「ファイル」→「ゲーム設定(Game Settings)」→「セキュリティ(Security)」
2. **「API サービスへの Studio アクセスを有効にする(Enable Studio Access to API Services)」** をオン
3. 保存 → これで、お金と強化がセーブされるようになります

## ステップ8:収益化(あとで、遊ぶ人が増えてきてから)
- **ゲームパス「売上2倍」** や **「お金の袋」(デベロッパープロダクト)** を作り、
  その ID を `YataiServer` の先頭の `CONFIG` に書き込むと有効になります
  (作り方はそのときに Claude が案内します)
- 稼いだ Robux は、3万 Robux 以上たまると現金化(DevEx)を申請できます(条件あり)
