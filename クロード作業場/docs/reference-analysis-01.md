## パート1(0:00〜0:23.8)「SOFT 比較」— 大理石 × ゴールドのソフトボディ

### 画面
- 被写体: 大理石のパイプ(カーブした筒)→ 大理石キューブの側面にある金具付きの出口 → 金の縁取りがある大理石の円柱(受け皿)
- 落ちてくるもの: **鏡面ゴールドのカプセル**
- 背景: 青みがかったグレー〜ラベンダーのグラデーション。左上から窓越しのような柔らかい光と影(光の筋)が入る
- カメラ: **完全固定**。やや見下ろしのアングル、広角すぎない中望遠

### 展開(同じ構図でパラメータだけを変えて繰り返す)
| 時間 | テロップ | カプセルの挙動 |
|---|---|---|
| 0:00〜0:03 | 0% SOFT | 硬いまま滑り落ち、出口に引っかかる/跳ねる |
| 0:03〜0:07 | 25% SOFT | 少しつぶれながら出口を抜ける |
| 0:07〜0:12 | 50% SOFT | 曲がって出口を通過し、円柱の穴へ落ちる |
| 0:12〜0:19 | 75% SOFT | ぐにゃっと曲がって出口を抜け、円柱の上でつぶれる |
| 0:19〜0:23 | 100% SOFT | ほぼ液体のように変形し、円柱の上で溶けたように広がる |

### 文字
- 画面上部の中央に白・太字のサンセリフ(例「0% SOFT」)。影なし、アニメーションなしで切り替わる

### 音
- BGMなし。**効果音だけ**(金属が擦れる音、カラン・コツンという衝突音、ぬるっとした変形音)
- 動きと音が完全に同期しており、静かな間(無音)もある

### 高級感を生んでいる要素
- **大理石 × 鏡面ゴールド**という素材の組み合わせ(ラグジュアリーブランドの定番)
- 落ち着いた低彩度の背景、柔らかい窓明かり、浅めの被写界深度
- 物体が少なく余白が多い。カメラを動かさないので「上質な静けさ」がある

## パート2(0:23.9〜0:46.8)「Faces 比較」— ゴールドの布シミュレーション

### 画面
- 被写体: 上空の**ゴールドの布(平面)**、中央に**鏡面クロームの球2つ**(くっついた形)、下に**コンクリートの箱**(`melomesh_` の刻印)
- 背景: ダークネイビーの単色。スタジオライティングで、球には環境が映り込んでいる
- カメラ: 固定。やや見下ろし

### 展開
| 時間 | テロップ | 内容 |
|---|---|---|
| 0:24〜0:26 | 16 Faces | 粗いメッシュの布が落ち、球に引っかからずすり抜けるように滑る |
| 0:26〜0:29 | 64 Faces | 少しだけ球の形に沿う |
| 0:29〜0:35 | 256 Faces | 格子状の布が球を包み、箱の外へ落ちる |
| 0:35〜0:43 | 1024 Faces | 布らしいドレープ。球を包んで箱の縁に垂れる |
| 0:43〜0:46 | 4096 Faces | 細かい金の網が球をきれいに包み、箱に流れ込む |

- 布は「金色のワイヤーフレーム(網目)」として見え、ポリゴン数が増えるほど細かく・滑らかになるのが一目でわかる

### 文字
- 上部中央にグレーのやや細いコンデンス系サンセリフ(例「1024 Faces」)

### 音
- 布が擦れる音、シャラシャラした金属音。BGMなし

## パート3(0:46.8〜1:31.8)「色の陣取り」ボールシミュレーション

### 画面
- 真っ黒の背景に、白い細線の**円形アリーナ**(上から見た図)
- 中央の**銀色の歯車**を軸に、グレーの**S字/C字のアーム2本**が回転する
- 色付きの小さな**光沢球**(3Dレンダリングされたビー玉風)が次々に現れ、アームに弾かれて増えていく
- 中盤から歯車から**リング状の衝撃波**が出て、色の勢力図が塗り替わる

### 展開
| 時間 | 内容 |
|---|---|
| 0:47〜0:52 | 球が1〜数個。黄色が少しずつ増える(導入。静かに始まる) |
| 0:52〜1:05 | 紫・赤・青・緑などが加わり、数十個に増えて色が混ざる |
| 1:05〜1:12 | 同じ色の球がかたまりを作り始め、数百個に増える |
| 1:12〜1:27 | アリーナが球でぎっしり埋まる。約2秒ごとに衝撃波が出て、**優勢な色が入れ替わる**(緑→赤→青→黄→マゼンタ→シアン→オレンジ) |
| 1:28〜1:31 | **カメラが歯車に向かってズームイン**し、円の外枠が画面外へ。球が散らばり、最後は緑の大きなかたまりで終わる |

### 音
- 前半はポップな「ポン」という単発音
- 1:00以降は**約2.1秒間隔の規則的なパルス音**(衝撃波と同期)が、**だんだん大きく・厚く**なる(クレッシェンド)
- これが「次はどうなる?」という期待感を作り、最後まで見せる仕掛けになっている

### 特徴
- パート1・2の「ラグジュアリー質感」とは違い、**中毒性・視聴維持**を重視した映像
- 色数が多くビビッド。高級感は低めだが、TikTok で回りやすいタイプ

## 動画全体としての「伸びる理由」

1. **比較フォーマット**: 「0%→100%」「16→4096」と数値が上がり、結果を最後まで見たくなる
2. **固定カメラ+同じ構図の繰り返し**: 差分だけに集中できる
3. **物理シミュレーションの気持ちよさ**: 落ちる・つぶれる・包む・混ざる
4. **素材の高級感**(パート1・2): 大理石・ゴールド・クローム・コンクリート
5. **音の同期**: BGMを使わず、効果音で「触感」を伝える
6. **短いループ単位**: 1パラメータあたり3〜7秒でテンポが良い

## 無料での再現方法(案)

すべて **Blender(無料)だけで作れる**。Higgs Field は必須ではない。

| パート | Blender の機能 | ポイント |
|---|---|---|
| 1 ソフト比較 | Soft Body(または Cloth+圧力)、Rigid Body | パラメータ(Goal Strength / Stiffness)を段階的に変えて5回シミュ → 書き出して連結 |
| 2 Faces 比較 | Cloth シミュ+Subdivide、Wireframe モディファイア | 分割数を 16/64/256/1024/4096 面に変えるだけで同じ比較が作れる |
| 3 ボール陣取り | Rigid Body、または Geometry Nodes のシミュレーションゾーン | 回転アーム+球の生成。色の塗り替えは Geometry Nodes で実装できる |

- 素材: 大理石・コンクリート・HDRI は Poly Haven / ambientCG(CC0)で無料
- レンダリング: Cycles(高品質)/ EEVEE(高速)。PCの性能に合わせて選ぶ
- 文字・連結・効果音: DaVinci Resolve 無料版 または FFmpeg、効果音は Freesound など
- Higgs Field の使いどころ(**使う場合は必ず事前に許可を取る**):
  - キービジュアルやサムネイル(`generate_image`)
  - 大理石やゴールドのオブジェクトの3Dモデル化(`generate_3d`)
  - ※物理的に正確な比較シミュレーションは、AI動画生成より Blender のほうが確実
