# ゆびさき工房サイトの公開手順(Cloudflare Pages)

サイトのファイルは `クロード作業場/site/` にあります。Cloudflare Pages を GitHub とつなぐと、
**GitHub に新しい版が保存されるたびに、自動でサイトが更新**されます。

> 画面の名前やボタンの位置は変わることがあります。違っていたら、画面の表示に従ってください。
> 分からない画面があれば、スクリーンショットを送ってもらえれば一緒に確認します。

## 1. Cloudflare のアカウントを作る(無料)
1. https://dash.cloudflare.com/sign-up を開く
2. メールアドレスとパスワードで登録し、届いた確認メールのリンクを押す

## 2. GitHub とつないでサイトを作る
1. Cloudflare の管理画面の左メニューで **「Workers & Pages」**(「Compute」の中にある場合もあります)を開く
2. **「作成(Create)」** → **「Pages」** タブ → **「Git に接続(Connect to Git)」**
3. GitHub のアカウントを選び、Cloudflare にアクセスを許可する
   - 「すべてのリポジトリ」ではなく、**このプロジェクトのリポジトリ(`jaruj7434-wq/-`)だけ**を選ぶのがおすすめ
4. リポジトリ `jaruj7434-wq/-` を選んで「セットアップを開始」

## 3. ビルドの設定(ここだけ正確に入力)
| 項目 | 入力する内容 |
|---|---|
| プロジェクト名 | `yubisaki-kobo`(これが無料 URL `yubisaki-kobo.pages.dev` になる。使われていたら別の名前に) |
| 本番ブランチ(Production branch) | `claude/fervent-maxwell-vzoho0` |
| フレームワーク プリセット | `None`(なし) |
| ビルドコマンド | `cp -r "クロード作業場/site" public` |
| ビルド出力ディレクトリ | `public` |

※ 出力先に日本語のフォルダ名を直接入れると失敗することがあるため、ビルドコマンドで
英語名のフォルダ `public` にコピーしてから公開する形にしています。

「保存してデプロイ(Save and Deploy)」を押し、1〜2分待つと完成です。

## 4. 公開されたか確認
- 表示された `https://(プロジェクト名).pages.dev` を開く
- トップページ → 「いますぐ あそぶ」→ たこ焼き返しが動くか
- スマホでも同じ URL を開いて確認

## 5. 公開できたら Claude に伝えること
- 公開された URL(例:`https://yubisaki-kobo.pages.dev`)
  → サイトの設定(`tools/build_site.py` の `SITE_URL`)に入れて、SNS でシェアしたときの
    画像表示や、ゲームのシェア文に URL が入るようにします

## あとからやること(任意)
- **独自ドメイン**:Cloudflare の「ドメインの登録(Domain Registration)」で購入(年1,500円前後〜)し、
  Pages プロジェクトの「カスタムドメイン」に追加
- **アクセス解析**:Pages プロジェクトの「Web Analytics」を有効にする(無料・Cookie 不使用)
  → 有効にしたら、プライバシーポリシーにツール名を追記します
- **X・OFUSE**:アカウントを作ったら URL を教えてください。サイトのリンクを有効にします
