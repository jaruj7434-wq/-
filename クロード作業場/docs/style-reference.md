# スタイル参照メモ(ベースイメージ)

このドキュメントは、ユーザーが共有した参考動画から抽出した**画質・動き・幻想的な
作画スタイル**の記録です。場所(ロケーション)や色味は動画ごとに都度指定されるため、
ここには含めません。新しい幻想系動画のプロンプトを作る際は、このスタイルを
ベースにしつつ、都度指定される場所・色を組み合わせること。

## 参照元

- ユーザーがアップロードした参考動画(約14秒、5シーン)
- Higgs Field `video_analysis_create` による分析結果
  - `video_analyze_id`: `aaa71da0-f65a-47cb-81a8-b4d0df0a8de9`
  - 元動画 `media_id`: `01358997-7a49-47a7-a17c-8bf73e143e4f`

## 画質(Image Quality)

- 映画的(シネマティック)な質感。ノイズの少ないクリアな解像感
- 強い方向性のある光源による陰影(リムライト効果が被写体の輪郭に出る)
- ハイダイナミックレンジ気味の、コントラストと彩度がやや高めの仕上がり
- 被写界深度は浅すぎず、背景の世界観までしっかり見せる画角

## 動き(カメラワーク・モーション)

- **後方トラッキング**を基本とする: カメラが被写体の少し前を、同じ速度で
  後退しながら追従する構図
- **ローアングル**を要所で使用し、上方に広がる空(異常な世界観)を強調する
- 横からの**サイドトラッキング**(徒歩シーンなど、被写体と並走)も併用
- 1カット2〜3秒程度で、**移動手段や動作を切り替えながらテンポよく展開**
  (例: 走行 → 滑走 → 徒歩、のように単調にならないよう変化をつける)
- ワイドショットとミディアムショットを交互に使い、世界観の説明と被写体の
  存在感を両立させる

## 幻想的な作画(Fantastical Art Direction)

- 現実の物理法則を無視した**空間の湾曲・歪み**(地面や道が球体のように
  上方へ巻き込み、本来「空」であるべき方向に海・雲・街・森などの景色が
  「天井」のように見える)
- スケール感の狂った、非現実的なパースペクティブ
- 台詞なしで、BGM主導の夢幻的な雰囲気(環境音は最小限、音楽が場面全体を
  一貫してつなぐ)
- 静けさと開放感を感じさせる、物語の説明よりも「世界観に浸らせる」演出

## 今後のプロンプト作成時の使い方

新しい幻想系動画を作る際は、上記の「画質・動き・作画スタイル」を土台にしつつ、
以下をユーザーから都度ヒアリングして組み合わせる。

- 場所・舞台(どんな異世界/幻想的なロケーションか)
- 色味・配色(暖色系か寒色系か、特定のカラーパレットの指定など)
- 登場キャラクター(このメモには含めない。別途 `show_characters` /
  `show_reference_elements` で管理)

生成前には必ずユーザーに一言確認を取ること(CLAUDE.md の運用ルールを参照)。
