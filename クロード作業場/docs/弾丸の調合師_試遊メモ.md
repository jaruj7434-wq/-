# 弾丸の調合師 — 試遊版(v0.1)メモ

## この版でできること
- 全6ウェーブ(約5分)。1〜5ウェーブは各30秒、6ウェーブ目はボス戦
- スタート時と各ウェーブ突破時に、3枚のパーツから1枚を選んで弾の「レシピ」に組み込む
- パーツは11種類:分裂・連射・重弾・貫通・反射・追尾・冷気・炸裂・連鎖・分岐・燃焼
  (残機が少ないときは「修理」が出ることがある)
- 連続で倒すと COMBO が増え、スコア倍率が上がる(最大3倍)
- タイトル画面に、そのブラウザでの「プレイ回数・合計プレイ時間・最高到達ウェーブ・クリア回数」を表示

## 試遊してもらうときに見ること
遊んでいる様子を横で見て、終わったら聞く。

| 確認すること | 記録 |
|---|---|
| 説明なしで遊び始められたか | |
| 1回目はどこまで進んだか(WAVE / クリア) | |
| 終わった直後に「もう1回」と自分から言ったか | |
| 合計で何回・何分遊んだか(タイトル画面の記録を見る) | |
| 一番楽しかったパーツ・組み合わせは | |
| つまらない・弱いと感じたパーツは | |
| 難しすぎ/簡単すぎと感じた場面は | |
| 弾の組み合わせで「強くなった!」と感じた瞬間はあったか | |

## 判断の目安
- 「もう1回」が自然に出る、合計10分以上遊ぶ人が多い → 方向性は良い。パーツの追加とバランス調整へ
- 1回で終わる人が多い → 何が物足りないかを聞いて、コアの仕組みを見直す

## 次の候補(反応を見てから決める)
- パーツの追加と、パーツ同士の組み合わせボーナス(例:冷気+連鎖で「氷の電撃」)
- 回をまたいで新しいパーツが解放される仕組み
- ボスの種類を増やす、ステージごとの背景
- Higgsfield で絵・効果音・BGM を本番用に作る(作る前に必ず許可を取る)
