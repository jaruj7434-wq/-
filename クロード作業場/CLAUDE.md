# CLAUDE.md — クロード作業場

このファイルは、Claude Code が「クロード作業場」フォルダで作業する際のガイドです。
**返答・説明・ドキュメントはすべて日本語で行うこと。**

## プロジェクトの目的

**できるだけ無料で、リアルで見応えのある「高級感のある3D動画」を作る。**

- 目指す質感: ハイエンドCM・ラグジュアリーブランド広告のような映像
  (腕時計、香水、ジュエリー、車、高級コスメ、建築・インテリアなど)
- 重視するもの: フォトリアルな質感(金属・ガラス・液体・布)、美しいライティング、
  滑らかでシネマティックなカメラワーク、余白と静けさのある構図
- 費用方針: **無料でできることを最大限やり尽くす**。有料が必要な場面は必ず事前に相談する。

## 最重要ルール:Higgs Field の生成は必ず許可を取る

- Higgs Field(`mcp__higgs_field__*`)で **画像・動画・3D・音声を生成する前には、必ずユーザーの許可を取ること。**
  対象: `generate_image` / `generate_video` / `generate_3d` / `generate_audio` / `*_batch` /
  `scene_builder_3d_generate_*` / `execute_preset` / `upscale_*` / `ai_influencer_generate` など、
  クレジット・処理時間が発生しうるもの全て。
- 許可を取るときは次をセットで提示する:
  1. 何を作るか(プロンプト要約・使用モデル・尺・アスペクト比)
  2. 想定コスト(`estimate_*_cost` や `get_cost: true` で事前確認した値)
  3. 無料枠/無制限枠(`use_unlim: true`、無料生成回数)で実行できるかどうか
- **クレジットを消費する場合は、無料ではない旨を明示し、改めて同意を得る。** 無断でクレジットを使わない。
- 一度許可をもらっても、別の生成(設定変更・リテイク・追加カット)は再度確認する。
- 残高・プラン確認(`balance`, `show_plans_and_credits`)、モデル調査(`models_explore`)、
  プリセットやワークフローの読み込み(`get_preset_instructions`)、アップロードなど
  課金を伴わない準備作業は確認なしでよい。迷ったら確認する。

## 無料で最大限やるための基本方針

### 1. 生成の前に「設計」を無料で詰める
クレジットを使う前に、テキストと無料ツールでできることを全部済ませる。
- 絵コンテ(カット割り・秒数・カメラの動き・ライティング・色)を `prompts/` に書く
- プロンプトを推敲し、1回の生成で当たりを引ける確率を上げる
- 参考映像のトーン(例: 黒背景+リムライト、ゴールドの反射、スローモーション)を言語化する

### 2. 無料の3Dツールを主力にする
フォトリアルな3D映像は、無料ソフトだけでも十分に作れる。
| ツール | 用途 | 費用 |
|---|---|---|
| **Blender**(Cycles / EEVEE) | モデリング・マテリアル・ライティング・カメラアニメ・レンダリング | 無料 |
| Poly Haven | HDRI、PBRテクスチャ、3Dモデル(CC0) | 無料 |
| ambientCG | PBRマテリアル(CC0) | 無料 |
| Sketchfab(CC ライセンス分) | 3Dモデル素材 ※ライセンス要確認 | 無料枠あり |
| DaVinci Resolve(無料版) | 編集・カラーグレーディング | 無料 |
| FFmpeg | 連番→動画化、圧縮、尺調整、9:16変換 | 無料 |
| Pixabay / Freesound 等 | BGM・効果音 ※ライセンス要確認 | 無料 |

- Blender のシーンは Python スクリプト(`scripts/`)として残し、再現可能にする。
- 素材のライセンス(CC0 / CC BY 等)は `docs/licenses.md` に必ず記録する。

### 3. Higgs Field は「無料枠」を優先し、ここぞという場面に使う
- 実行時は可能な限り `use_unlim: true` や無料生成枠を使う(使えるかは事前に確認)。
- まずは低解像度・短尺・1本でテストし、方向性が固まってから本番生成する(これも毎回許可を取る)。
- 3Dシーン・カメラアングル関連は、最初に `get_preset_instructions({ preset: "/3d-jutsu" })` を読み込む。
- 使えそうな機能(すべて生成前に要許可):
  - `generate_3d` — 画像/テキストから3Dモデル(GLB)生成 → Blender に取り込んで仕上げる
  - `scene_builder_3d_*` — 3Dシーン構築・アングル生成・動画化
  - `generate_image` — キービジュアル、ルック開発、動画の開始フレーム作成
  - `generate_video` — 画像→動画(シネマティックなカメラワーク付与)
  - `upscale_video` / `upscale_image` — 仕上げの高画質化
- 複数ステップの制作では、直接生成を叩く前にプリセット/ワークフローの指示を読み込む。

## 高級感を出すための制作ガイド

- **ライティング**: 黒〜濃いグレー背景、リムライト(輪郭光)、大きなソフトボックス1灯+反射板。
  HDRIはスタジオ系を使い、金属やガラスに美しい映り込みを作る。
- **マテリアル**: 金属は roughness 低め+わずかな傷テクスチャ、ガラスは IOR 1.45〜1.5、
  被写界深度(DOF)で手前/奥をぼかす。
- **カメラ**: ゆっくりしたドリー、オービット(周回)、マクロ寄り。急な動きは避ける。
  イージング(ease in/out)を必ずかける。
- **色**: 色数を絞る(黒+ゴールド、白+シルバー、深緑+真鍮など)。最後にカラーグレーディング。
- **演出**: スローモーション、粒子・煙・水しぶき、光の筋(ボリューメトリック)を控えめに。
- **音**: 低めのアンビエント+要所の効果音(金属音・ガラス音)。無音の間も活かす。
- **文字**: 細めのセリフ体/ワイドなサンセリフ、大きな余白、短いコピー。

## 出力形式のデフォルト

- SNS向け(Instagram Reels / TikTok / YouTube Shorts): **9:16、1080×1920、24fps または 30fps**
- 横型(YouTube・ポートフォリオ): 16:9、1920×1080
- 尺の目安: 6〜15秒のショート、もしくは 30秒の広告尺
- Higgs Field で生成する場合も `aspect_ratio` を明示する。

## 作業の進め方(毎回の流れ)

1. 企画のヒアリング(題材・用途・尺・雰囲気・参考)
2. 絵コンテとプロンプトを日本語で作成し、ユーザーに確認
3. 無料ツール(Blender 等)でできる部分を先に作る/手順を用意する
4. Higgs Field を使う場合は、内容・コスト・無料枠の可否を提示して **許可を得てから** 生成
5. 編集・カラー・音・書き出し(無料ツール中心)
6. 使ったプロンプト・設定・素材ライセンスを記録する

## 注意事項

- 生成した動画・画像などの大きなファイルは git 管理しない(`.gitignore` で除外)。
  プロンプト・スクリプト・設定などのテキストのみ残す。
- 実在の人物・ブランドロゴ・商標を無断で使った生成はしない。本人やブランドの同意があるものだけを対象にする。
- 素材は商用利用可能か、クレジット表記が必要かを必ず確認する。
