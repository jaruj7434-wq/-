# CLAUDE.md

このファイルは、Claude Code が「クロード作業場」フォルダで作業する際のガイドです。

## 基本ルール

- **返答はすべて日本語で行うこと。**
- このフォルダの目的は、**Higgs Field**(MCP ツール群: `mcp__higgs_field__*`)を使って
  **テンポよく画像を出し、短く見やすい動画を「作成 → 編集 → 仕上げ」まで行うこと**。
- 主な想定は Instagram Reels / TikTok / YouTube Shorts などの縦型ショート動画。

## 【最重要】生成前に必ず許可を取る

- `generate_image` / `generate_video` / `generate_audio` / `*_batch` / `execute_preset` /
  `upscale_*` / `reframe` / `outpaint_image` など、**Higgs Field で画像・動画・音声を
  作成・加工するツールを呼ぶ前には、必ずユーザーに許可を取ること。**
- 許可を取る際は、以下を短く提示してから「この内容で作成してよいですか?」と確認する。
  - 作るもの(画像 / 動画、枚数・本数)
  - 使うモデル・アスペクト比・尺
  - プロンプトの要約
  - 想定コスト(可能なら `get_cost: true` でプレフライトして提示)
- ユーザーの「OK」「お願いします」などの明確な返答があるまで生成しない。
- 一度許可を得ても、**内容が変わる次の生成ではあらためて許可を取る。**
- クレジット消費を抑えるため、可能な限り `use_unlim: true` を使う。無制限枠が使えない場合は
  「クレジットを消費しますがよいですか?」と確認してから進める。
- アップロード(`media_upload_widget`)・分析(`video_analysis_*`)・一覧表示など、
  作成を伴わない準備作業は確認なしで進めてよい。

## 制作の進め方(テンポ重視)

1. **企画を一言で固める** — テーマ・尺・雰囲気・配信先を短く確認(質問は最小限に)。
2. **画像を素早く出す** — まずはキービジュアル/各カットの静止画を数枚まとめて提案。
   バリエーションは `generate_image_batch` でまとめて出し、ユーザーに選んでもらう。
3. **選ばれた画像から動画化** — image-to-video で各カットを短く(1カット 3〜5秒目安)生成。
4. **編集・仕上げ** — カットつなぎ、字幕(`subtitles` ワークフロー)、BGM/音声、
   サムネイル(`thumbnail-generation`)まで行う。
5. **確認と微修正** — 完成版を見せ、修正点だけをピンポイントで直す。

※ 各ステップで生成が発生する場合は、上記「生成前に必ず許可を取る」に従うこと。

## 「短く見やすい動画」の基準

- 全体の尺は **15〜30秒** を基本とする(指定があればそれに従う)。
- **冒頭1〜2秒で掴む**:最初のカットに一番強い画を置く。
- 1カットは 2〜5秒程度でテンポよく切り替える。
- 字幕は短く・大きく・読みやすく。1画面1メッセージ。
- 縦型 `aspect_ratio: "9:16"` を明示する(横型が必要なときのみ `16:9`)。

## Higgs Field の使い方メモ

- 複数ステップの動画制作(UGC・広告・プロダクト動画など)を行う前は、
  `mcp__higgs_field__get_workflow_instructions` でワークフローカタログを確認してから進める。
- 既存動画の編集・差し替えは `get_workflow_instructions({ workflow: "ad-multiplier" })` を先に読む。
- モデル選びに迷ったら `models_explore(action: "recommend")` を使う。
- 複数の独立した生成は batch ツール → `jobs_wait` → `show_generation_by_ids` の流れでまとめて表示。
- 同じ人物・キャラを複数カットで使う場合は `show_reference_elements`(Elements)や
  `show_characters`(Soul)で一貫性を保つ。
- ローカルの画像・動画を使う場合は `media_upload_widget` でアップロードしてから使う。

## フォルダ構成(目安)

- `prompts/` — プロンプト・台本・構成メモ
- `assets/source/` — 素材(参照画像・動画など)
- `assets/output/` — 生成した画像・動画の書き出し先(git 管理外推奨)
- `docs/` — 企画メモなど

## 注意事項

- 実在の人物の写真を使った生成は、本人の同意があるものだけを対象とする。
- 生成物(画像・動画ファイル)そのものは基本的にコミットせず、プロンプトなど再現可能な
  テキストのみを保存する。
