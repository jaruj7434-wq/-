# CLAUDE.md

このファイルは、Claude Code がこの「クロード作業場」フォルダで作業する際のガイドです。

## プロジェクト概要

このプロジェクトは **Higgs Field**(MCP ツール群: `mcp__higgs_field__*`)を使って
**幻想系(ファンタジー系)の動画を制作する**ことを目的としています。魔法・異世界・
神話的な生き物・幻想的な風景・ファンタジーキャラクターなど、非現実的・空想的な
世界観の動画/画像を中心に扱います。主な配信先は Instagram Reels / TikTok /
YouTube Shorts などの縦型ショート動画ですが、横型・その他フォーマットの依頼にも
対応します。

**ベースとなるスタイル参照**: `docs/style-reference.md` に、ユーザー提供の参考動画
から抽出した画質・カメラワーク(動き)・幻想的な作画スタイルの方針をまとめている。
新しい動画のプロンプトを作る際は、このファイルを土台とし、そのつどユーザーから
指定される場所・色味と組み合わせること。場所や色はこのファイルには含めない。

## 作業を始める前に必ず行うこと

複数ステップの動画制作(世界観のある物語動画、キャラクター紹介、ナレーション付き
動画など「ブリーフに沿った制作」)を頼まれたら、直接 `generate_video` を叩く前に
**必ず** `mcp__higgs_field__get_workflow_instructions` を呼び、該当するワークフロー
(SKILL)をロードすること。どのワークフローが存在するかは毎回カタログで確認し、
憶測で決めない。

## このプロジェクトで想定される主な用途

幻想系動画では特に以下のような使い方が中心になる見込み。実際に使う際は必ず
`get_workflow_instructions({ workflow: "<name>" })` で詳細を読み込んでから進める。

- `character-sheet` — 幻想世界のキャラクター(魔法使い・精霊・モンスター等)の
  一貫した参照シート作成(複数アングル・表情)
- `thumbnail-generation` — 動画のサムネイル・カバー画像の制作
- `subtitles` — 完成動画へのハードサブ(焼き込み字幕・ナレーション字幕)追加
- 上記に当てはまらない単発のイメージ/動画生成は `generate_image` / `generate_video`
  を直接使う

その他のワークフローが必要になった場合も、必ずカタログを確認してから選定すること。

## 素材・キャラクターの一貫性

- 同じキャラクター(魔法使い・幻想生物など)を複数カットで使い回したい場合は
  `show_characters`(Soul)でトレーニングするか、`show_reference_elements` で
  参照エレメントとして保存する。
  - Soul: 同一人物/同一キャラクターのみ、5〜20枚の参照画像が必要、
    `soul_2` / `soul_cinematic` 専用。
  - Elements: 即時利用可能、複数キャラクター/複数被写体もOK、他の主要モデルでも
    使える。
- ローカルの画像・動画をアップロードする場合はファイルパスを直接扱わず、
  必ず `media_upload_widget` を最初に呼び出してアップロードを行う。

## 出力形式のデフォルト

- SNSショート動画向けは基本 `aspect_ratio: "9:16"`(縦型)を明示する。
  横型が必要な場合のみ `16:9` を指定する。
- 生成前にコストを確認したい場合は `get_cost: true` を付けてプレフライトする。

## リポジトリ構成

- `prompts/` — 動画・画像生成に使うプロンプトや台本(世界観設定・キャラクター設定を
  含む)
- `assets/source/` — アップロード元の参照画像・参照動画などの素材
- `assets/output/` — 生成された動画・画像の書き出し先
- `docs/` — 企画書、世界観・ビジュアルガイドラインなどのドキュメント

新しくディレクトリ構成を作る際は、実際の作業内容に合わせて上記を調整して問題ない。

## Higgs Field 生成物の運用ルール(ユーザー指定・最重要)

- **生成前に必ず一言確認する**: `generate_image` / `generate_video` / `generate_audio` /
  `*_batch` など、クレジットや処理時間が発生する生成系ツールを呼び出す前には、
  **必ず**チャットでユーザーに一言確認を取ってから実行すること。これは本プロジェクトで
  特に厳守すること。分析系(`video_analysis_*`)やアップロード
  (`media_upload_widget`)、要素登録(`show_reference_elements`)など課金を伴わない
  準備作業はこの限りではないが、疑わしい場合は確認を取る。
- **クレジットを消費しない設定を優先する**: 生成を実行する際は、可能な限り
  `use_unlim: true`(無制限/トライアル枠)を使い、通常クレジットを消費しないように
  する。ただし、無制限枠がプラン上使えない場合はツール側からその旨が返ってくるため、
  その場合は必ずユーザーに「クレジットを消費する形になるがよいか」を確認してから
  進める。無断でクレジットを消費する生成を行わない。

## 開発上の注意

- Higgs Field 側の生成物(動画・画像ファイルそのもの)は基本的に git 管理対象外とし、
  `.gitignore` で除外する。リポジトリにはプロンプト・スクリプト・設定などの
  再現可能なテキスト資産のみをコミットする。
- 実在の人物をモデルにした生成(顔・声などを使う場合)は、本人の同意が取れているもの
  だけを対象とする。幻想系キャラクターであっても実在人物の肖像を無断で使用しない。
