# CLAUDE.md(ai-human-video)

このフォルダは、Claude Code が **Higgs Field**(MCP ツール群: `mcp__higgs_field__*`)を使って
**AI による動画制作**を行うためのプロジェクトフォルダです。
このフォルダ内での作業では、ルートの `CLAUDE.md` よりもこのファイルの指示を優先します。

## 最重要ルール(必ず守ること)

1. **返答はすべて日本語で行う。** 説明・確認・報告・エラーの解説も含めて日本語で書く。
2. **Higgs Field で動画・画像を作成する前に、必ずユーザーの許可を取る。**
   - 対象: `generate_image` / `generate_video` / `generate_audio` / `*_batch` /
     `execute_preset` / `upscale_*` / `reframe` / `outpaint_image` / `motion_control` /
     `shorts_studio_create` など、生成・加工を行うすべてのツール。
   - 実行前に以下をチャットで提示し、ユーザーから「OK」「お願いします」などの
     明確な許可をもらってから実行する。許可がない限り生成ツールは呼ばない。
     - 何を作るか(動画 / 画像、本数)
     - 使用するモデル
     - プロンプト(日本語の要約 + 実際に送る英語プロンプト)
     - アスペクト比・尺・解像度
     - 想定コスト(可能なら `get_cost: true` でプレフライトした結果)
   - 一度許可をもらっても、**内容(プロンプト・モデル・本数など)を変えて再生成する場合は
     改めて許可を取る。** 「前回OKだったから」で続けて生成しない。
   - 分析・閲覧系(`models_explore`、`get_workflow_instructions`、`show_generations`、
     `video_analysis_*`、`balance` など)は許可なしで使ってよい。迷った場合は確認する。
3. **クレジットを消費しない設定を優先する。** 可能な限り `use_unlim: true` を使う。
   無制限枠が使えないとツールから返ってきた場合は、
   「クレジットを消費する形になるがよいか」を必ず確認してから進める。

## このフォルダで作る動画の種類

### A. リアルな人間の動画(メインテーマ)

本物の撮影と見分けがつかないほどリアルな、AI 生成の人物動画を作る。

- 例: 街を歩く人、カフェで話す人、カメラに向かって話す自撮り風(UGC風)動画、
  ポートレート、日常の Vlog 風カット、感情表現のアップショットなど。
- リアルさを出すためのポイント:
  - 肌の質感(毛穴・うぶ毛・自然なムラ)、髪の流れ、自然なまばたきや視線の動き
  - 自然光・実在しそうなロケーション、スマホ撮影風の手ブレや被写界深度
  - 「cinematic」「hyper-realistic」だけに頼らず、カメラ機種・レンズ・時間帯・
    光の向きなど具体的な撮影条件をプロンプトに書く
  - 指・歯・目・文字(看板など)は破綻しやすいので、生成後に必ずチェックする
- 同じ人物を複数カットで使う場合:
  - `show_characters`(Soul): 同一人物の写真 5〜20 枚でトレーニング。`soul_2` /
    `soul_cinematic` 専用。
  - `show_reference_elements`(Elements): 即時利用可能、複数人物もOK、他モデルでも使用可。
  - キャラクターシートが必要な場合は `get_workflow_instructions({ workflow: "character-sheet" })`
    を読み込んでから進める(ユーザーが明示的に頼んだ場合のみ)。

### B. AI 独特の非現実で面白い動画

現実では撮れない、AI ならではのシュールで面白い・不思議な動画を作る。

- 例: 物体が溶けたり変形したりするモーフィング、ありえないスケール感
  (巨大な動物・ミニチュアの街)、重力や物理法則を無視した動き、
  人間が別の素材(ガラス・粘土・水)に変わる、夢のような世界観、
  ミーム的なシュールなシチュエーションなど。
- ポイント:
  - 「リアルな質感 × ありえない出来事」の組み合わせが一番面白く見えやすい
  - SNS 向けは冒頭 1〜2 秒で「何これ?」と思わせるフックを入れる
  - エフェクト系は `get_presets`(`source: "viral"` やモーション系カテゴリ)で
    既存プリセットを探すのも有効。ただしプリセットの閲覧は実行の許可にはならない。

## 作業の進め方

1. ユーザーの要望を聞き、上記 A / B どちらのタイプか(または両方の組み合わせか)を整理する。
2. どのモデルが適しているか迷ったら `models_explore`(`action: "recommend"`)で確認する。
3. 複数ステップの動画制作(UGC・広告・ストーリー仕立てなど)は、生成前に
   `get_workflow_instructions` を引数なしで呼び、使えるワークフローを確認してから進める。
   ワークフロー名は憶測で決めない。
4. 企画・プロンプト案を日本語で提示し、**許可を取る**。
5. 許可が出たら生成し、結果を確認してユーザーに日本語で報告する。
   修正・再生成が必要な場合は再度 4 に戻る。

## 出力形式のデフォルト

- SNS ショート動画(Instagram Reels / TikTok / YouTube Shorts)向けは
  `aspect_ratio: "9:16"` を明示する。横型が必要な場合のみ `16:9`。
- ローカルの画像・動画を使う場合は、ファイルパスを直接扱わず、
  必ず最初に `media_upload_widget` を呼び出してアップロードする。

## フォルダ構成

```
ai-human-video/
├── CLAUDE.md          … このファイル
├── prompts/
│   ├── realistic/     … リアル人間動画のプロンプト・台本
│   └── surreal/       … 非現実系 AI 動画のプロンプト・台本
├── assets/
│   ├── source/        … 参照用の写真・動画(git 管理外)
│   └── output/        … 生成された動画・画像(git 管理外)
└── docs/              … 企画メモ・うまくいったプロンプトの記録など
```

- 生成物(動画・画像ファイル)は git にコミットしない。プロンプトや企画メモなど
  再現可能なテキストだけをコミットする。
- うまくいったプロンプトは `prompts/` に、モデル名・設定と一緒に残しておく。

## 倫理・権利に関するルール

- **実在の人物**(有名人・知人など)の顔や声を使った生成は、本人の同意が取れている場合のみ行う。
  同意が確認できない場合は架空の人物で作る。
- 実在の人物になりすます動画、誤解を招くフェイク(ニュース風の偽映像など)、
  詐欺や中傷につながる内容は作らない。
- リアルな人物動画を SNS に投稿する際は、必要に応じて「AI生成」であることを表記するよう
  ユーザーに提案する(各プラットフォームの AI コンテンツ表示ルールに従う)。
- 未成年に見える人物を、性的・不適切な文脈で生成しない。
