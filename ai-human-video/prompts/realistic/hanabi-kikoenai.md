# 「聞こえない」— 監督台本(30秒・11カット)

- シリーズ: 「覚醒」のノボル & リナ(同じキャラクター・同じ衣装)
- ジャンル: 青春ラブコメ(ファイトなし)
- 尺: 30秒 / 16:9 / 35mmフィルム、アナモルフィック
- 舞台: 夜、河川敷の花火大会。土手の芝生の斜面、遠くに屋台の灯り、川面に花火が映る
- 登場人物(参照シート):
  - ノボル: c0c66e97-34ad-4d3c-b63f-1c09628fb980(メガネあり・学ラン風)
  - リナ: d1c54dd5-2f5f-4b54-9e50-8fed50e0307e(金髪ギャル)
  - ※覚醒ノボル・チンピラは登場しない

## コンセプト

- 「勇気を出した告白が、花火の音でかき消される」という王道のすれ違いを、繰り返しのギャグで笑わせ、最後に**リナの耳打ち**で一気に胸キュンに落とす。
- 音の設計が主役。花火の「ドーン」を笑いのタイミングに使い、クライマックスの耳打ちだけ**完全な静寂**にする。
- 前作「覚醒」で最強だったノボルが、恋愛では最弱というギャップ。

## 3幕構成

| 幕 | 時間 | 狙い |
|---|---|---|
| 第1幕「決意」 | 0〜10秒 | 花火大会のワクワク感と、ポケットの小箱を握るノボルの緊張 |
| 第2幕「かき消される告白」 | 10〜22秒 | 告白 → 花火でかき消される → もう一度 → またかき消される(天丼ギャグ) |
| 第3幕「耳打ち」 | 22〜30秒 | 無音の中のリナの一言 → ノボル真っ赤 → フィナーレの花火 |

## 台本

### S#1 河川敷・花火大会(夜)

**C1|0:00〜0:03|ワイド・ローアングル、土手の階段を見上げる**
- 夜空に一発目の花火が開く。リナがノボルの袖を引っぱって、土手の階段を駆け上がる。
- リナ「早く早く! 始まっちゃう!」
- 音: 花火の「ヒュ〜…ドーン」、遠くの人々の歓声、下駄や足音

**C2|0:03〜0:06|ミディアム・2人を横から、固定**
- 土手の芝生に並んで座る2人。リナは目を輝かせて空を見上げる。ノボルは少し離れて座り、膝を抱えている。
- リナ(空に向かって)「たまや〜!」
- 演出: 花火の光が2人の顔を赤・緑・金に照らし、色が一定のリズムで変わる

**C3|0:06〜0:08|インサート・ノボルの手元のアップ**
- ノボルが学ランのポケットの中で、小さな白い箱をぎゅっと握りしめる。手がかすかに震えている。
- 音: 自分の鼓動「ドクン」が花火の音に重なる

**C4|0:08〜0:10|インサート・芝生の上の2人の手**
- ノボルの手がリナの手の方へじりじり近づく → 引っこめる → また近づく。
- 演出: 観客を「いけ!」と応援させる、もどかしい間

**C5|0:10〜0:13|ノボルの顔のアップ・ゆっくり寄る**
- メガネに花火が映り込む。意を決して深呼吸し、リナの方を向く。
- ノボル「リ、リナ…あの…ぼ、僕…」
- リナ(空を見たまま)「ん〜?」

**C6|0:13〜0:16|ノボルのバストショット・固定**
- ノボルが目をつむって、全力で叫ぶ。
- ノボル「ずっと前から——」
- その瞬間、特大の花火が真上で「ドドーン!」と炸裂。口は動いているが、声は完全にかき消される。
- 演出: 画面が花火の光で真っ白に飛ぶ

**C7|0:16〜0:18|リナのアップ・固定**
- リナが首をかしげて、きょとんと振り向く。
- リナ「え? なんて?」

**C8|0:18〜0:22|ノボル → リナの切り返し・テンポよく**
- ノボル、がくっとうなだれる。気を取り直して、もう一度大きく息を吸う。
- ノボル「だ、だから! す——」
- また「ドーン! ドドーン!」(スターマインが連発)。
- ノボル、魂が抜けたように真っ白になって固まる。
- 演出: C6と同じ構図を繰り返し、「天丼」で笑いをとる

**C9|0:22〜0:25|2人のツーショット・ゆっくり寄る**
- リナがふっといたずらっぽく笑い、ノボルの耳元にそっと顔を寄せる。
- ここで**すべての音が消える**(花火は無音で光だけが降りそそぐ)。
- リナ(ささやき声)「…知ってるよ。あたしも」
- 演出: ささやき声だけがはっきり聞こえる。作品で一番の見せ場

**C10|0:25〜0:27|ノボルの顔の超アップ・固定**
- ノボルの目が大きく見開かれ、顔がみるみる真っ赤になる。メガネがうっすら曇る。メガネのレンズに大輪の花火が映る。
- 音: 静寂のまま → 最後に「ドーン」と花火の音が戻る

**C11|0:27〜0:30|後ろからの超ワイド・ゆっくりクレーンアップ**
- 土手に座る2人の後ろ姿のシルエット。リナがノボルの肩に頭を乗せ、芝生の上で2人の手が重なる。ノボルのポケットの小箱は、まだ渡せていない(ちらっと見えている)。
- 夜空いっぱいにフィナーレのスターマインが開き、川面にも花火が映る。
- 音: 花火の連発、遠くの歓声、そして余韻

## 音の設計

| 区間 | 音 |
|---|---|
| C1〜C2 | 花火の音、歓声(にぎやか) |
| C3〜C5 | 花火は少し遠く、ノボルの鼓動が目立つ |
| C6・C8 | 花火の「ドーン」でセリフがかき消される(ギャグのタイミング) |
| C9〜C10 | **完全な無音 + リナのささやき声だけ** |
| C11 | 花火の音が一気に戻り、フィナーレ |

- BGM なし、字幕なし

## 光と色の設計

- 照明はすべて「花火の光」。カットごとに顔を照らす色を変える(赤 → 緑 → 金 → 白)。
- C6・C8 は花火の白い閃光で画面を飛ばす(コメディ的な強調)。
- C9〜C10 は、やわらかいピンクと金の光で包む(ロマンチック)。
- C11 は川面の反射を含め、画面いっぱいに色があふれる。
