# 台本 v1:スミカエル工務店「我が家、変身。」(30秒・9:16)

## 登場人物
- 母(40代):狭く暗い台所に毎日ため息
- 父(40代・長身):吊り戸棚に毎回頭をぶつける
- 娘(小学生):祖母をいつも支えている
- 祖母(70代):床の段差でよくつまずく
- 職人リーダー(50代)+職人2人:若葉グリーンの作業着、胸にカエルのワッペン。ヒーロー登場風

## 舞台
- ビフォー:昭和の戸建ての台所と居間。暗い、狭い、床に段差、吊り戸棚が低い
- アフター:明るいLDK。アイランドキッチン、段差のないフローリング、大きな窓、木と白の内装
