# CLAUDE.md (anime/)

このファイルは、`anime/` 配下で Claude Code が作業する際のガイドです。
リポジトリ共通のルールはルートの `../CLAUDE.md` を参照してください。

## プロジェクト概要

このフォルダは **Higgs Field**(MCP ツール群: `mcp__higgs_field__*`)を使って
**アニメ系動画を制作する**ことを目的としています。オリジナルのアニメ調キャラクター・
世界観による短編ストーリー、キャラクター紹介、MV風動画、アニメ調の演出を使った
広告・解説動画などを対象とします。主な配信先は Instagram Reels / TikTok /
YouTube Shorts などの縦型ショート動画です。

## 作業を始める前に必ず行うこと

ストーリー動画・キャラクター紹介・広告など「ブリーフに沿った複数ステップの動画制作」を
頼まれたら、直接 `generate_video` を叩く前に **必ず**
`mcp__higgs_field__get_workflow_instructions` を(引数なしで)呼び、該当するワークフロー
(SKILL)をロードすること。どのワークフローが存在するかは毎回カタログで確認し、
憶測で決めない。

## このプロジェクトでよく使うワークフロー

アニメ系動画制作でよく使うと想定されるのは主に以下だが、これは目安であり
実際に何が使えるかは上記の通り毎回カタログで確認する。使う際は
`get_workflow_instructions({ workflow: "<name>" })` で詳細を読み込む。

| ワークフロー名 | 用途 |
|---|---|
| `character-sheet` | 一貫したアニメキャラクターの参照シート作成(複数アングル・表情違い) |
| `thumbnail-generation` | サムネイル・カバー画像の制作 |
| `subtitles` | 完成動画へのハードサブ(焼き込み字幕)追加 |
| `ad-multiplier` | 既存動画から、キャラクターやカットを差し替えた複数バリエーションを量産 |

上記に当てはまらない単発のイメージ/動画生成(1カットのアニメ調カット、背景アート等)は
`generate_image` / `generate_video` を直接使う。ナレーション付きの短編ストーリーや
解説動画など、上表にないブリーフ型のワークフローが必要な場合も、まずカタログを
確認すること。

## 素材・キャラクターの一貫性

- アニメ系のオリジナルキャラクターを複数カット・複数シーンで使い回す場合、
  `show_characters`(Soul)は実在人物の写真(5〜20枚)を前提とするため基本的に
  不向き。まず `character-sheet` ワークフローで複数アングル・表情のキャラクター
  シートを生成し、それを `show_reference_elements` で参照エレメントとして登録して
  使い回すのが基本の流れ。
  - Soul: 同一人物の実写のみ対象、5〜20枚の写真が必要、`soul_2` / `soul_cinematic` 専用。
  - Elements: 即時利用可能、生成したアニメキャラクター/複数被写体もOK、他の主要
    モデルでも使える。
- ローカルの画像・動画をアップロードする場合はファイルパスを直接扱わず、
  必ず `media_upload_widget` を最初に呼び出してアップロードを行う。

## 出力形式のデフォルト

- SNSショート動画向けは基本 `aspect_ratio: "9:16"`(縦型)を明示する。
  横型が必要な場合のみ `16:9` を指定する。
- 生成前にコストを確認したい場合は `get_cost: true` を付けてプレフライトする。

## フォルダ構成

`anime/` 配下では以下のような構成を想定:

- `anime/prompts/` — 動画・画像生成に使うプロンプトや台本・脚本
- `anime/prompts/characters/` — キャラクター設定(character bible)・キャラクターシート用プロンプト
- `anime/assets/source/` — アップロード元の参照画像・参照動画などの素材
- `anime/assets/output/` — 生成された動画・画像の書き出し先
- `anime/docs/` — 企画書、世界観・キャラクター設定資料などのドキュメント

新しくディレクトリ構成を作る際は、実際の作業内容に合わせて上記を調整して問題ない。

## 権利まわりの注意

- 既存のアニメ・漫画・ゲーム作品のキャラクターや作風に酷似した生成(版権キャラクターの
  無断使用)は避け、オリジナルのキャラクター・世界観の制作を基本とする。
- 実在の人物の写真・声などを素材にした生成を行う場合は、本人の同意が取れているものだけを
  対象とする。
