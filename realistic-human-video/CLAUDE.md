# CLAUDE.md — リアルな人間動画プロジェクト

このフォルダ(`realistic-human-video/`)は、**Higgs Field**(MCP ツール群: `mcp__higgs_field__*`)を使って
**AIでリアルな人間の動画・画像を作成する**ための作業場所です。
このフォルダ内で作業するときは、リポジトリ直下の `CLAUDE.md` に加えて本ファイルの指示に従ってください。
内容が食い違う場合は、本ファイルの指示を優先します。

## 基本ルール

- **返答はすべて日本語で行う。**
- 目指すのは「実写と見分けがつかない自然な人間」の動画・画像。アニメ調・イラスト調・
  CG感の強い表現は、ユーザーから明示的に頼まれない限り使わない。

## 最重要:生成前に必ず許可を取る

Higgs Field で**動画や画像を作成する前には、必ずユーザーの許可を取ってから作成に入ること。**

- 対象となるツール(クレジット・処理時間が発生するもの):
  `generate_video` / `generate_image` / `generate_audio` / `*_batch` 系 /
  `execute_preset` / `motion_control` / `upscale_image` / `upscale_video` /
  `outpaint_image` / `reframe` / `remove_background` / `voice_change` / `dubbing` /
  `shorts_studio_create` / `show_characters`(Soul のトレーニング)など。
- 許可を取るときは、以下をチャットで簡潔に提示してから「実行してよいですか?」と確認する。
  1. 何を作るか(動画 / 画像、カット数・本数)
  2. 使用するモデル
  3. プロンプトの要点(人物像・シーン・動き・カメラ)
  4. アスペクト比・尺・解像度
  5. 想定コスト(可能なら `get_cost: true` でプレフライトして金額を示す)
- ユーザーが「OK」「お願いします」など明確に承認するまで生成しない。
  **一度の承認はその生成1回分(提示した内容)にのみ有効**。内容を変えて再生成・追加生成する場合は、
  改めて許可を取る。
- 課金を伴わない準備作業(`models_explore`、`get_workflow_instructions`、
  `media_upload_widget`、`show_reference_elements` の閲覧、`video_analysis_*` など)は
  許可なしで進めてよい。ただし判断に迷う場合は確認を取る。
- 生成時は可能な限り `use_unlim: true`(無制限/トライアル枠)を使う。無制限枠が使えない旨が
  返ってきた場合は、**「通常クレジットを消費する形になるがよいか」を改めて確認**してから進める。

## 制作の進め方

1. **ヒアリング**:用途(SNS縦型 / 広告 / 映像作品など)、人物像、シーン、尺、雰囲気を確認する。
2. **ワークフロー確認**:複数ステップの制作(UGC・広告・レビュー動画など)の場合は、
   生成前に必ず `get_workflow_instructions`(引数なし)でカタログを確認し、該当ワークフローを読み込む。
   存在するワークフローは毎回カタログで確認し、憶測で決めない。
3. **モデル選定**:迷ったら `models_explore(action: "recommend")` で推奨モデルを確認する。
4. **人物の一貫性の確保**(複数カットで同じ人物を使う場合):
   - Soul(`show_characters`):同一人物のみ、5〜20枚の写真が必要。`soul_2` / `soul_cinematic` 専用。
   - Elements(`show_reference_elements`):即時利用可能、複数人物OK、主要モデルで使える。
   - キャラクターシートが必要な場合は `get_workflow_instructions({ workflow: "character-sheet" })` を使う
     (ユーザーから明示的に頼まれた場合のみ作成する)。
5. **静止画で見た目を固めてから動画化**:まず人物のキービジュアル(画像)を作り、
   ユーザーの確認を経てから image-to-video で動画化すると、失敗コストを抑えやすい。
   ※ 画像・動画どちらの生成も、それぞれ事前に許可を取ること。
6. **仕上げ**:必要に応じてアップスケール、字幕(`subtitles` ワークフロー)、音声などを追加する
   (これらも生成系なので事前に許可を取る)。

## リアルに見せるためのプロンプトのコツ

- **肌・質感**:自然な肌の質感、毛穴、うぶ毛、わずかな左右非対称、自然なメイク。
  「完璧すぎる」「ツルツルの肌」は CG っぽさの原因になるので避ける。
- **ライティング**:自然光(窓からの光、夕方のゴールデンアワー等)や実在する照明環境を具体的に書く。
- **カメラ**:スマホ撮影風、手持ちの軽い揺れ、35mm / 50mm レンズ、浅い被写界深度など、
  実際の撮影条件として書く。
- **動き**:瞬き、呼吸、髪の揺れ、自然な視線移動など、小さく自然な動きを指定する。
  大きく速い動作や手指のアップは破綻しやすいので、必要な場合のみ慎重に使う。
- **環境**:生活感のある背景(カフェ、部屋、街中など)を具体的に書く。
- 1カットは短め(数秒〜十数秒)にし、必要に応じて複数カットをつなぐ。

## 出力形式のデフォルト

- SNS ショート動画向けは `aspect_ratio: "9:16"`(縦型)を明示する。横型が必要な場合のみ `16:9`。
- 用途が不明な場合は、生成前の確認時にアスペクト比もあわせて確認する。

## 倫理・権利に関するルール

- **実在の人物**の写真・動画・声を素材にする場合は、**本人の同意が取れているものだけ**を対象とする。
  同意の有無が不明な場合は作業前にユーザーに確認する。
- 有名人・政治家・公人など、実在の人物になりすます動画や、本人が言っていないことを
  言わせる動画は作成しない。
- 生成した人物を実在の人物として偽って公開する用途(詐欺・誤情報・なりすまし等)には協力しない。
- 配信先のプラットフォームで AI 生成コンテンツの表示(ラベル付け)が求められる場合は、
  それに従うようユーザーに案内する。
- 未成年に見える人物の性的・不適切な表現は一切生成しない。

## フォルダ構成(想定)

```
realistic-human-video/
├── CLAUDE.md          # 本ファイル
├── prompts/           # 人物設定・プロンプト・台本(テキスト)
├── characters/        # 人物ごとの設定メモ(外見・服装・Element/Soul の ID など)
├── assets/source/     # 参照写真・参照動画などの素材(git 管理外)
└── assets/output/     # 生成された動画・画像(git 管理外)
```

- 生成物(動画・画像ファイル)はコミットしない(リポジトリ直下の `.gitignore` で除外済み)。
- 再現できるように、使用したプロンプト・モデル・設定値・生成IDは `prompts/` や `characters/` に
  テキストで記録してコミットする。
