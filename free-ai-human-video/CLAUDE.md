# CLAUDE.md(無料ツールで作る AI リアル人物動画プロジェクト)

このファイルは、Claude Code が `free-ai-human-video/` フォルダで作業する際のガイドです。
リポジトリ直下の `CLAUDE.md` のルールも引き続き有効で、内容が重なる場合は
**このファイルのルールを優先**します。

## 基本方針

- このフォルダの目的は、**AI でリアルな人間(人物)が登場する動画**を作ること。
- 企画・素材生成・編集・書き出しまで、**無料で使えるソフト・サービスだけ**で行う。
  **お金をかけない**ことを最優先とし、有料プラン・有料素材・従量課金 API は使わない。
- ユーザーへの返答・説明・コメント・コミットメッセージは **すべて日本語** で書く。
- 主な配信先は縦型ショート動画(TikTok / Instagram Reels / YouTube Shorts)。
  特に指定がなければ **1080x1920(9:16)・30fps** で制作する。

## 【最重要】Higgsfield 利用時の許可ルール

Higgsfield(`mcp__higgs_field__*`)で動画・画像・音声を作成する場合は、
**必ず事前にユーザーの許可を取ってから** 生成に入ること。例外はない。

1. 生成の前に、次の内容をチャットで提示して許可を求める。
   - 何を作るか(動画 / 画像 / 音声、本数・枚数)
   - 使うモデルとおおよその設定(長さ、`aspect_ratio: "9:16"` など)
   - 使用するプロンプト(日本語訳を添える)
   - 費用の見込み(可能なら `get_cost: true` でプレフライトして確認)
2. ユーザーが明確に「OK」「作って」などと答えるまで、`generate_image` /
   `generate_video` / `generate_audio` / `*_batch` / `ai_influencer_generate` /
   `execute_preset` など生成・加工系ツールは **一切呼び出さない**。
3. 一度許可をもらっても、**別の生成(追加・作り直し・別カット)のたびに改めて許可を取る**。
4. お金をかけない方針のため、生成時は可能な限り無料枠を使う
   (`use_unlim: true`、無料生成回数がある場合は `use_free_gens: true` など)。
   - 無料枠が使えない・残っていない場合は、**クレジットを消費する形で進めず停止**し、
     その旨をユーザーに報告する。ユーザーが明示的に了承した場合のみ先へ進む。
   - 残高や無料枠の確認(`balance` など、課金されない参照系)は許可なしで行ってよい。
5. Higgsfield を使わずに無料ローカルツールで代替できる場合は、その選択肢も併せて提案する。

## 制作フロー

1. **企画** — 目的、尺(15〜60秒)、登場人物の設定、台本、カット割りを
   `prompts/` に Markdown で書き出し、ユーザーと内容を確認する。
2. **素材生成** — 人物の静止画・動画を生成する。
   - Higgsfield を使う場合は上記の許可ルールに従う。
   - 同じ人物を複数カットで使う場合は、参照画像(Elements など)を使い顔・服装を統一する。
3. **音声** — ナレーション・セリフを無料 TTS で作成(後述)。BGM・効果音は無料素材から選ぶ。
4. **編集** — 無料の編集ソフトまたは FFmpeg でカット編集、テロップ、BGM、色調整を行う。
5. **字幕** — Whisper で文字起こし → SRT を修正 → 焼き込み or 編集ソフトで配置。
6. **書き出し・確認** — 規定フォーマットで書き出し、音量・画質・AI表示の有無をチェックする。

## 使ってよい無料ツール

すべて無料で使えるもの。インストールが必要なものはユーザーの環境に合わせて案内する。
「無料版だが一部機能が有料」のツールは、**無料の範囲の機能だけ**を使う。

| 用途 | ツール | メモ |
|---|---|---|
| 動画編集 | **DaVinci Resolve(無料版)** | 高機能。カラー調整・字幕も可能。Studio 版(有料)の機能は使わない |
| 動画編集 | **Kdenlive** / **Shotcut** / **OpenShot** | オープンソースで完全無料 |
| 動画編集(スマホ) | CapCut 無料版 | Pro 機能・有料素材は使わない。規約変更に注意 |
| コマンド処理 | **FFmpeg** | 変換、リサイズ、結合、字幕焼き込み、音量調整を自動化 |
| 画像編集 | **GIMP** / **Krita** / Photopea(Web) | サムネイル・素材加工 |
| 3D / VFX | **Blender** | 背景・合成が必要な場合 |
| 録画・録音 | **OBS Studio** / **Audacity** | 画面収録・音声編集・ノイズ除去 |
| 文字起こし | **Whisper**(ローカル実行) | `whisper` / `faster-whisper` で SRT 生成 |
| 字幕編集 | **Subtitle Edit** / Aegisub | SRT/ASS の調整 |
| 音声合成(日本語) | **VOICEVOX** | 無料。キャラクターごとの利用規約・クレジット表記に従う |
| 音声合成(多言語) | **Piper TTS** | ローカル実行のオープンソース TTS |
| 高画質化 | **Upscayl** / Real-ESRGAN | 画像のアップスケール(ローカル) |
| 背景除去 | **rembg** | 画像の背景除去(ローカル) |
| ローカル画像/動画生成 | ComfyUI + オープンモデル | GPU が必要。モデルのライセンスを確認して使う |
| BGM・効果音 | YouTube オーディオライブラリ / DOVA-SYNDROME / 効果音ラボ / Pixabay | 各サイトの利用規約・クレジット表記に従う |
| フォント | Google Fonts(Noto Sans JP など) | 商用利用可の OFL ライセンス |

使わないもの:有料プランの機能、有料ストック素材、従量課金の API、
「無料体験」の後に自動で課金されるサービス(登録が必要な場合は事前にユーザーへ確認する)。

## FFmpeg よく使うコマンド例

```bash
# 縦型 1080x1920 に変換(はみ出しはクロップ)、30fps、H.264 + AAC
ffmpeg -i in.mp4 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920" \
  -r 30 -c:v libx264 -crf 20 -preset medium -c:a aac -b:a 192k out.mp4

# 複数クリップを結合(list.txt に "file 'clip1.mp4'" を1行ずつ記載。同じ形式のクリップ同士)
ffmpeg -f concat -safe 0 -i list.txt -c copy joined.mp4

# BGM を小さめに重ねる(元音声 + BGM 音量 20%)
ffmpeg -i video.mp4 -i bgm.mp3 -filter_complex \
  "[1:a]volume=0.2[b];[0:a][b]amix=inputs=2:duration=first[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac mixed.mp4

# SRT 字幕を焼き込み(日本語フォント指定)
ffmpeg -i in.mp4 -vf "subtitles=subs.srt:force_style='FontName=Noto Sans JP,FontSize=14'" \
  -c:a copy subbed.mp4

# SNS 向けラウドネス正規化(-14 LUFS 目安)
ffmpeg -i in.mp4 -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:v copy normalized.mp4
```

## リアルな AI 人物を扱う際のルール

- **実在の人物の顔・声を無断で使わない。** 実在人物の写真・声を素材にする場合は、
  本人の同意が取れているものだけを対象とする。有名人・他人になりすます動画は作らない。
- 架空の人物を生成する場合も、特定の実在人物に似せる指示は避ける。
- 各 SNS の規約に従い、**AI 生成コンテンツであることを表示**する
  (TikTok の「AI生成」ラベル、Instagram の「AI情報」ラベル、YouTube の改変・合成コンテンツの開示など)。
  投稿時にラベル設定が必要なことを、書き出し後にユーザーへ必ず伝える。
- 誤解を招く内容(実在の出来事の捏造、虚偽の商品効果の断言など)は作らない。

## フォルダ構成

```
free-ai-human-video/
├── CLAUDE.md          # このファイル
├── prompts/           # 企画書・台本・生成プロンプト(Markdown)
├── scripts/           # FFmpeg などの編集用スクリプト
├── assets/
│   ├── source/        # 参照画像・音声などの元素材(git 管理外)
│   ├── generated/     # AI で生成した素材(git 管理外)
│   └── output/        # 書き出した完成動画(git 管理外)
└── docs/              # 素材・BGM のライセンス/クレジット記録など
```

- 動画・画像・音声ファイルは git にコミットしない(`.gitignore` で除外済み)。
- リポジトリには、プロンプト・台本・スクリプト・ライセンス記録など**再現可能なテキストのみ**を残す。
- 使用した BGM・効果音・音声合成キャラクターは、`docs/credits.md` に出典と利用条件を記録する。
