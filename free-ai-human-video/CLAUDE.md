# CLAUDE.md(free-ai-human-video)

このフォルダは、**AIでリアルな人間の動画を作る**ための作業スペースです。
方針は **「無料ソフトだけを使い、お金をかけずにできる範囲で、動画の作成から編集・書き出しまで行う」** ことです。
このフォルダ内で作業する場合は、リポジトリ直下の `CLAUDE.md` よりもこのファイルの指示を優先してください。

## 基本方針

1. **有料ソフト・有料プラン・サブスクリプションは使わない。** 提案もしない(ユーザーから求められた場合を除く)。
2. 無料ソフトでも「無料版では透かし(ウォーターマーク)が入る」「書き出し解像度が制限される」「商用利用不可」
   といった制約があるものは、使う前に必ずその制約をユーザーに伝える。
3. ツールを選ぶ順番は次のとおり:
   1. **オープンソース / 完全無料のローカルツール**(FFmpeg、DaVinci Resolve 無料版、ComfyUI など)
   2. **クレジットを消費しない枠**のクラウドサービス(Higgs Field の無制限・無料枠など)
   3. それ以外は使わない。どうしても必要に見える場合は、理由と費用を説明してユーザーの判断を仰ぐ。
4. 返答・説明・コメントは **すべて日本語** で行う。

## Higgs Field の利用ルール(厳守)

- `generate_image` / `generate_video` / `generate_audio` / `*_batch` / `execute_preset` /
  `ai_influencer_generate` / `upscale_*` / `motion_control` など、**画像や動画を作成・加工する
  ツールを呼び出す前には、必ずチャットでユーザーの許可を取ってから実行する。**
  - 許可を求めるときは「何を作るか(内容・モデル・枚数/本数・長さ・アスペクト比)」と
    「クレジット消費の有無」を一言で伝える。
  - 1回の許可は、その1回の生成にだけ有効。内容を変えて作り直す場合も、改めて許可を取る。
- 生成時は **`use_unlim: true`(無制限 / 無料枠)を必ず指定** し、通常クレジットを消費しない。
  - 無料枠が使えないとツールから返ってきた場合は、そこで止めてユーザーに報告する。
    **クレジットを消費する生成は、この方針上原則として行わない。** ユーザーが明示的に
    「クレジットを使ってよい」と言った場合に限り実行する。
  - 事前に `get_cost: true` でコストを確認し、0 でないものは実行しない。
- 分析系(`video_analysis_*`)、アップロード(`media_upload_widget`)、残高確認(`balance`)など
  課金を伴わない準備作業は許可なしで行ってよい。迷ったら確認する。
- 複数ステップの動画制作では、生成の前に `get_workflow_instructions` でワークフローを確認する。

## 無料で使えるツール一覧

### 編集(カット・テロップ・色調整)

| ソフト | 用途・メモ |
|---|---|
| **DaVinci Resolve(無料版)** | 本格的な編集・カラーグレーディング。無料版でも 4K 書き出し可能で透かしなし。メインの編集ソフト候補 |
| **Kdenlive** | オープンソースの動画編集ソフト。軽量で Linux / Windows / Mac 対応 |
| **Shotcut** | オープンソース。シンプルなカット編集・フィルター向け |
| **FFmpeg** | コマンドラインでのカット・結合・リサイズ・縦型変換・字幕焼き込み・音声合成。自動化はこれで行う |

※ CapCut などは無料機能と有料機能が混在し、規約も変わりやすいため、使う場合は
「その機能が無料で使えるか」「透かしが入らないか」を事前に確認する。

### 画像生成・動画生成(ローカル / オープンモデル)

| ツール | 用途・メモ |
|---|---|
| **ComfyUI** | ノードベースの生成環境(無料・オープンソース)。画像・動画生成の中心 |
| オープン動画モデル(Wan 系、LTX-Video、HunyuanVideo など) | ComfyUI で使える無料の動画生成モデル。**高性能な GPU(VRAM 目安 12GB〜)が必要** |
| オープン画像モデル(FLUX.1 schnell、Stable Diffusion 系など) | リアルな人物の静止画生成。モデルごとにライセンス(商用可否)を必ず確認する |

- ローカル GPU がない場合は、無料枠のある環境(Google Colab 無料枠など)を検討するが、
  利用規約・制限を確認してから提案する。
- モデルやノードは公式配布元からのみ入手し、ライセンスを `docs/` に記録する。

### 画質向上・補間

| ツール | 用途 |
|---|---|
| **Upscayl / Real-ESRGAN** | 画像・動画フレームの高解像度化(無料・オープンソース) |
| **RIFE**(ComfyUI ノード等) | フレーム補間でなめらかにする |
| **FFmpeg** (`minterpolate` 等) | 簡易的なフレーム補間・フレームレート変換 |

### 音声・ナレーション・BGM

| ツール | 用途・メモ |
|---|---|
| **Audacity** | 録音・ノイズ除去・音量調整 |
| **Piper TTS** | オープンソースの音声合成(ローカル) |
| **VOICEVOX** | 無料の日本語音声合成。キャラクターごとにクレジット表記などの規約があるので確認する |
| BGM・効果音 | YouTube オーディオライブラリ、DOVA-SYNDROME、効果音ラボなど **無料・利用規約が明確な素材** のみ使う |

### 字幕

| ツール | 用途 |
|---|---|
| **Whisper(openai-whisper / faster-whisper)** | ローカルでの自動文字起こし → `.srt` 作成 |

| **FFmpeg** (`subtitles` フィルター) | 字幕の焼き込み |

### 画像編集・その他

- **Blender**:3D・合成・簡易な VFX(無料)

## 標準の制作フロー

1. **企画** — `docs/` に企画メモ(目的・尺・配信先・登場人物の設定)を書く。
2. **台本・プロンプト作成** — `prompts/` に台本と生成プロンプトをテキストで保存する。
3. **人物素材の作成**
   - ローカル(ComfyUI + オープンモデル)で生成する、または
   - Higgs Field の無料枠で生成する(**必ず事前にユーザーの許可を取る**)。
   - 同じ人物を複数カットで使う場合は、参照画像・シード値・プロンプトを記録して一貫性を保つ。
4. **動画化** — 画像から動画(image-to-video)を生成。1カット数秒単位で作り、後で繋ぐ。
5. **編集** — DaVinci Resolve / Kdenlive / FFmpeg でカット・結合・色調整・テロップ。
6. **音声** — ナレーション(Piper / VOICEVOX)、BGM・効果音(無料素材)を追加。
7. **字幕** — Whisper で文字起こし → 調整 → 焼き込み。
8. **書き出し** — SNS 向けは縦型 `1080x1920`(9:16)、H.264 / AAC の MP4 を基本とする。

### FFmpeg よく使うコマンド例

```bash
# 縦型 9:16(1080x1920)に変換(余白は黒で埋める)
ffmpeg -i in.mp4 -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2" -c:v libx264 -crf 18 -c:a aac out.mp4

# 複数クリップを結合(list.txt に file 'clip1.mp4' のように列挙)
ffmpeg -f concat -safe 0 -i list.txt -c copy joined.mp4

# BGM を小さめの音量で重ねる
ffmpeg -i video.mp4 -i bgm.mp3 -filter_complex "[1:a]volume=0.2[b];[0:a][b]amix=inputs=2:duration=first" -c:v copy out.mp4

# 字幕を焼き込む
ffmpeg -i video.mp4 -vf "subtitles=subs.srt" -c:a copy out_sub.mp4
```

再利用するコマンドは `scripts/` にシェルスクリプトとして保存する。

## リアルな人間の AI 動画に関するルール

- **実在の人物(有名人・知人など)に似せた動画や、本人の写真を使った動画は、本人の同意が取れているものだけ** を対象とする。
  同意がないものは作成しない。
- 他人になりすます目的、誤情報・詐欺・誹謗中傷・性的な目的の動画は作らない。
- 未成年に見える人物を、不適切な文脈で生成しない。
- SNS に投稿する際は、各プラットフォームの **AI 生成コンテンツのラベル表示**
  (TikTok / Instagram / YouTube の「AI生成」表示など)に従うよう案内する。
- 使用したモデル・素材のライセンス(商用利用可否・クレジット表記)を確認し、`docs/` に記録する。

## フォルダ構成

```
free-ai-human-video/
├── CLAUDE.md        # このファイル
├── prompts/         # 台本・生成プロンプト(テキスト)
├── scripts/         # FFmpeg などの自動化スクリプト
├── docs/            # 企画書・ライセンス記録・作業メモ
└── assets/          # 素材と書き出し(git 管理対象外)
    ├── source/      # 元素材(写真・参照動画・音声)
    └── output/      # 生成・書き出した動画や画像
```

- 動画・画像・音声などのバイナリはコミットしない(リポジトリ直下の `.gitignore` で除外済み)。
- リポジトリにはプロンプト・スクリプト・ドキュメントなど、再現できるテキストだけをコミットする。

## シリーズ「失敗したら出る物理」の制作ルール(ユーザー指定)

- **新作が完成したら、動画と一緒に投稿用テキストをチャットに送る。** YouTube / TikTok / Instagram それぞれの
  タイトル・説明文・ハッシュタグを、そのまま貼り付けて投稿できる形で書く(`prompts/<形式>/seed<N>_post.md` にも保存する)。
- **毎回、コースの形(構造)と物理の原理を変える。** 同じ形式・同じ仕組みを続けない。
  - 作る前に `docs/channel/episodes.md` を読み、過去回と被らないものを選ぶ。完成したら同ファイルに追記する。
- 成功と失敗がおよそ半々になるよう難易度を調整し、結末が本当に読めない設定にする。
  たくさん計算した中から見せる回を選ぶのはよいが、ボールの位置や結果そのものは編集しない。
- 失敗したときだけ幽霊(`scripts/common/jumpscare.py`)を出す。プレイ中は「※失敗すると…アレが出ます」を表示する。
- タイトル・ハッシュタグ・アイコン・説明文の決まりは `docs/channel/profile.md` と `docs/channel/titles_hashtags.md` に従う
  (結末のネタバレ禁止、成功回と失敗回で同じ型にする)。
- 音量は通常部分 約 -18dB、叫び声はそれより約 10dB 大きい程度にそろえる。
