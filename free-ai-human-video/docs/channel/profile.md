# アカウント設計:失敗したら出る物理

## コンセプト
- 脱出・バトル・音ハメ・レース・ブロック崩しなど、毎回ちがう形式の物理シミュレーションを投稿する。
- 成功で終わる回も、失敗で終わる回もある(設定は成功率がおよそ半々になるよう調整する)。
- **失敗したときだけ、失敗が確定した瞬間に幽霊が出る(びっくり演出)。** 成功した回では出ない。
- **成功したときは、かわいい天使がずっと現れて神々しいBGMが流れる。**
- 視聴者は「失敗するな!」と祈りながら最後まで見る。

## アカウント名
- **表示名:失敗したら出る物理 | Deru Physics**
- **ハンドル(ID):`@deru_physics`**
  - 取得できない場合の予備:`@deru.physics` / `@shippai_deru` / `@deru_butsuri`
  - 3つの SNS で同じ ID にそろえる。
- 由来:日本語の「出る」は「幽霊が出る」の意味でよく使われる。名前だけで「失敗すると何かが出る」と伝わり、
  「何が出るの?」という興味と「失敗しないで」という緊張感の両方を生む。
- 予備案:「祈れ、物理。| Pray Physics」「ユーレイ物理 | Yurei Physics」

## 運用ルール
- 「計算どおり」と書く以上、やってよいのは「たくさん計算した中から見せる回を選ぶ」ところまで。
  動画内の物理計算そのもの(ボールの位置や結果)は編集しない。
- 成功回ばかり・失敗回ばかりにならないよう混ぜる(目安:失敗は3〜4本に1本)。
- カバーやタイトルで結末をネタバレしない(「成功!」「失敗…」とは書かない)。
- 幽霊演出のルール:
  - プレイ中の画面には「※失敗すると…アレが出ます」を表示しない(ユーザー指定・9本目の作り直しから)。説明文には「びっくり注意・音量注意」を書く(苦情・通報を防ぐ)。
  - 叫び声は通常部分より約10dB大きい程度に抑える(耳に痛いほどの音量にしない)。
  - 強い点滅は最初の一瞬の1回だけ(光過敏への配慮)。
  - 血や流血などの残酷な表現は入れない。
  - YouTube では「子ども向けではない」に設定する。
  - 幽霊の絵はオリジナル(`scripts/common/jumpscare.py`)。既存の作品のキャラクターに似せない。
