# ジャンル選定:無料 × Claude Code だけで作成〜編集まで完結できるもの

- 作成日: 2026-10-23
- 前提: [2026-10-youtube-buzz.md](./2026-10-youtube-buzz.md) の調査結果

## Claude Code 環境でできること / できないこと(実際に確認済み)

| 項目 | 状態 |
|---|---|
| FFmpeg(カット・結合・字幕焼き込み・BGM 合成・書き出し) | ○ 使える |
| Python + Pillow / NumPy(1フレームずつ画像を描いて動画にする) | ○ 使える |
| Chromium(HTML/CSS/JS のアニメーションを録画して動画化) | ○ 使える |
| 日本語の音声合成(pyopenjtalk-plus、無料・ローカル) | ○ 動作確認済み(やや機械的な声) |
| 日本語フォント | △ WenQuanYi など最低限のみ。Noto Sans JP などの無料フォントは追加が必要 |
| GPU | × なし(CPU 4コア・メモリ 15GB) |
| リアルな人物・動物の AI 動画生成 | × GPU がないため不可。Higgs Field の無料枠を使う場合は必ず事前に許可を取る |

→ **「コードで描ける映像 + 合成音声 + FFmpeg 編集」で完結するジャンル**が対象。

## 選定ジャンル(おすすめ順)

### 1. 物理シミュレーション系の「見続けてしまう」ショート ★最有力
- 例:「ボールは円から脱出できる?」、ビー玉レース、国旗・色ボールのバトルロイヤル
- 根拠:2023年11月にショートでバズってジャンル化。1本 3,800万再生の例あり
  ([Know Your Meme](https://knowyourmeme.com/memes/will-the-ball-escape-ball-bouncing-brainrot))。
  ビー玉レースの Rolling Rolling は登録者 30.6万人
  ([vidIQ](https://vidiq.com/youtube-stats/channel/UCPF4eS5WL7pcmo23Lsye_SA))。
- 強み:
  - Python で物理計算から映像・衝突音まですべて作れる。
  - 言葉が不要なので世界中が視聴対象になる。
  - 毎回シミュレーション結果が変わるので「量産型の使い回し」にならない。
- 弱み:競合が多い。ルールや見た目の独自性(日本ネタ・投票企画など)が必要。

### 2. クイズ・脳トレ(文字探し、間違い探し、漢字、計算、錯視)
- 根拠:個人の手作りチャンネルでも「もじさがしクイズ」が 78万再生
  ([ユーチュラ](https://yutura.net/channel/108838/popular/))。
- 強み:
  - 図形と文字だけで作れる。カウントダウンで最後まで見てもらいやすい。
  - 問題を毎回作り直せるのでオリジナル性を保てる。
- 弱み:1本ごとの再生数にばらつきがある。シリーズ化と毎日の投稿が前提。

### 3. 数字・データ比較のアニメーション(ランキング、規模比較、推移グラフ)
- 例:「都道府県別◯◯ランキング」「世界の◯◯を大きさで比べると」
- 強み:
  - グラフ・地図・図形はコードの得意分野。データを調べるのも Claude ができる。
- 弱み:データの正確さが命。出典を必ず確認し、動画内に表示する。

### 4. 歴史・雑学ショート(文字演出 + 地図 + 図解 + ナレーション)
- 根拠:顔出しなしの歴史雑学ショートで、開設6ヶ月・2,200万再生という自己申告あり
  ([ラッコM&A](https://rakkoma.com/project/detail/23201))。
- 強み:台本の質で勝負できる。調査ではストーリー性のある動画が一番伸びていた。
- 弱み:
  - 実写や AI 画像のショートと比べて映像が地味になる。
  - 合成音声の質が視聴を続けてもらえるかに直結する。

### 5. オリジナルの短編ストーリー・怖い話(文字演出 + 環境音)
- 強み:調査で一番伸びていたのは「続きが見たくなる台本」のストーリー物。
- 弱み:
  - 映像がないぶん、文字演出と音で没入感を出す必要がある。
  - 静止画にナレーションを付けただけだと、収益化審査で「中身の薄い量産」と判断される恐れがある。

## 対抗が難しいジャンル(Claude Code だけでは不可)
- AI のリアルな人物・動物・映画風の動画(MYTHRA、@clipboom.aivideo、AI 猫など)
  → GPU か Higgs Field の無料枠が必要。今後、許可を取って部分的に組み合わせる候補。

## 収益化停止を避けるためのルール
- 台本・問題・データは毎回オリジナルにする。テンプレートの使い回しだけで量産しない。
- 合成音声・AI 生成である旨を説明欄に記載し、必要に応じて AI 生成ラベルを付ける。
- 特定の文化・人種を装う内容、性的な内容は扱わない。
