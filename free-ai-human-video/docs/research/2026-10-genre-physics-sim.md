# ジャンル詳細:物理シミュレーション系ショート

- 作成日: 2026-10-23
- 関連: [2026-10-genre-selection.md](./2026-10-genre-selection.md)

## 概要
円や図形の中でボールが跳ね回る様子をプログラムで計算して映像にするショート動画。
ボールが跳ねるたびに色が変わったり、メロディの音が1音ずつ鳴ったりする。
「ボールは脱出できる?」「どれが最後まで残る?」という結末を見届けたくて、最後まで見てしまうのが特徴。
2023年11月に YouTube ショートでバズってジャンル化し、2026年も TikTok などで投稿が続いている。

実績(第三者サイトの値・未検証):
- satisfying.ba11s:1本で約3,800万再生(跳ねるたびに曲の音が鳴る形式)
- CodeCraftedPhysics:「Will the ball escape?」系の動画で400万再生超
- Rolling Rolling(ビー玉レース):登録者 30.6万人・総再生 1.45億回(2025年6月時点)
- TikTok:50秒で脱出できるか、という動画で約180万いいね

## 主なフォーマット
| 型 | 内容 | 見どころ |
|---|---|---|
| 脱出系 | 回転するリングのすき間からボールが外に出られるか。リングが何重にもなる「100重リング」版もある | 脱出の瞬間 |
| 成長系 | 跳ねるたびにボールが大きくなり、最後は円を埋め尽くす | どこまで大きくなるか |
| 増殖系 | 跳ねるたびにボールが増える | 画面がボールで埋まっていく爽快感 |
| バトル・レース系 | 国旗やチームのボールが戦う・競争する。最後の1つが勝ち | 誰が勝つか予想してコメントしたくなる |
| 音楽系 | 跳ねるたびにメロディが1音ずつ進む | 曲が完成していく気持ちよさ |
| その他 | ビー玉の坂転がし、玉が釘に当たって落ちていくピンボール台風の仕掛け、ドミノ | 見続けてしまう心地よさ |

## 伸びる理由
1. 結末が気になるので最後まで見られる(視聴維持率が高い)。
2. 終わりと始まりをつなげてループさせやすく、繰り返し再生される。
3. 言葉が不要なので世界中が視聴対象になる。
4. 「赤が勝つ」などの予想コメントが付きやすく、YouTube のおすすめに載りやすい。

## Claude Code での制作手順(すべて無料)
1. 企画:ルール・参加ボール・尺(15〜45秒)を決める。
2. 計算:Python で物理計算をする(自作、または無料ライブラリの pymunk)。
3. **結末の選別**:描画する前に乱数の種(シード)を変えて数百〜数千回計算だけ回し、
   「残り1秒で脱出」「最後に逆転」など盛り上がる結果のシードを選ぶ。←ここが一番の武器
4. 描画:Pillow などで 1080x1920・60fps のコマ画像を描き、そのまま FFmpeg に流して動画にする。
   CPU だけで30秒の動画なら数分程度の見込み。
5. 音:衝突したタイミングに合わせ、NumPy で効果音やメロディの音を合成する。
6. 仕上げ:FFmpeg で映像と音を合わせ、冒頭の問いかけ文字と結果表示を入れて書き出す。
7. 同じシードと設定を残しておけば、同じ動画を何度でも作り直せる。

## 差別化アイデア(日本向け)
- 47都道府県バトル、干支バトル、戦国武将バトル。
- 視聴者がコメントで予想し、次回の参加者もコメントから選ぶ。
- トーナメント形式のシリーズにして、続きを見るためにチャンネル登録してもらう。
- 著作権の切れた童謡やクラシックのメロディを、自分で音を合成して使う。

## 注意点
- **飽和気味**:定番の形だけでは埋もれる。テーマやルールで独自性を出す。
- **使い回し判定**:YouTube は「繰り返しの多いコンテンツ」の収益化を厳しく見ている。
  毎回ルール・見た目・結末を変える。
- **音楽の著作権**:人気曲のメロディは使わない。著作権の切れた曲(エリーゼのために、歓喜の歌など)か自作曲を、自分で音を合成して使う。
- **点滅**:激しい色の点滅は光過敏の人に配慮して控えめにする。
- **国旗**:政治的・差別的に見える演出は避ける。
- **収益**:ショートの広告収益は1再生あたりの単価が低い。登録者を増やしてから長尺動画やシリーズにつなげる前提で考える。
