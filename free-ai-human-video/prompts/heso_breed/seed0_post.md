# 投稿用テキスト:heso_breed_0.mp4(ヘソに入った玉がぶつかると増える・成功パターン)

- 動画: assets/output/heso_breed_0.mp4(1080x1920 / 60fps / 38.5秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/heso_breed/heso_breed.py render --seed 0`
- 結末: 成功(打った玉105発・ヘソ10回・ぶつかって増えた玉462個)。3.0秒で初めてヘソ → 15.4秒で25% → 20.1秒で50% → 25.0秒で75% → 30.3秒で90% →
  31.7秒(残り7.8秒)に天井までパンパン!! → 大当たり演出
- 音量: 通常部分 約 -14dB
- ルール: 上はパチンコの盤面(釘150本)。左のレールから銀のパチンコ玉が0.3秒ごとに1発ずつ打ちこまれ、重力で釘に当たりながら落ちる。
  打ちこむ強さは毎回 ±7% だけばらつく(ハンドルのぶれ。シードで変わるのはここだけ)。ねらい・補正なし。
  下のまん中のヘソ(入賞口・はば30px)に入った玉だけが、短いパイプを通って下のへやに落ち、虹色の玉(半径16px)になる。外れた玉は両はしのアウト口へ消える。
  へや(角の丸い長方形)の中の玉どうしが勢いよく(ぶつかる速さ120px/秒以上)ぶつかると、ぶつかった所に新しい玉がポンと生まれる(小さく生まれて0.25秒でふくらむ)。
  増やした玉は0.4秒休む。へやの中は重力ありでふつうに跳ね返る(物理エンジン pymunk・はねかえり係数0.97。少しずつ勢いがなくなって積もる)。
  39.5秒以内に玉が472個(へやの面積の82%=天井までパンパン)になったら成功(大当たり演出)、ならなければ失敗(幽霊 → 暗くなって「Failed...」)
- 難易度: 80 回中 40 回成功(50%)。ヘソに入る確率は打った玉の約8%
- 音: パチンコ玉を打ちこむ「カシャ」、釘に当たる「チン」、ヘソに入った「キュイン!」、増えた「ポン」(数が多いほど音階が上がる)。BGMなし。
  成功は どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打+鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の文字は最小限(上に「パンパンにできる？」・パンパン度%・残り秒数、ヘソの上に小さく「ヘソ」)。フォントは Zen Kaku Gothic New、「失敗したら…」は怖い筆文字 Yuji Syuku、
  最後の「Congratulations!!」「COMPLETE」「Failed...」は Playfair Display Italic(すべて SIL OFL)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
- シードの選び方: シード0から順に計算し、最初の成功(0)と最初の失敗(1)をそのまま使用(結果は編集していない)
