# 投稿用テキスト:maze_spin_0.mp4(回る迷路からボール20個にげられる?・失敗パターン)

- 動画: assets/output/maze_spin_0.mp4(1080x1920 / 60fps / 30.2秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/maze_spin/maze_spin.py render --seed 0`
- 結末: 失敗(シード0をそのまま使用・選んでいない)。6.4秒に1個目 → 11.0秒で5個 → 12秒から回転スピードアップ → 19.7秒で10個 →
  24.6秒に13個目、そのまま時間切れ → 幽霊 → しょんぼりBGM
- 音量: 通常部分 約 -13dB
- ルール: 正方形の迷路(9×9マス・シードごとに形がちがう)の中に、ボールが40個。重力はいつも画面の下向きで、迷路が90°ずつ回る(=迷路から見ると重力の向きが変わる)。
  はじめはまん中の部屋にしきりがあり、1秒でしきりが消えてスタート。迷路は2.4秒止まる → 0.6秒で90°回る、をくり返し、12秒からは止まる時間が1.3秒に短くなる(回転スピードアップ)。
  出口は、ななめ向かいの2つのすみ。ボールが迷路の外に出たら「脱出」。ボールの動きは物理計算のまま(ねらい・補正なし)。
  24.7秒以内に20個脱出できたら成功(大当たり演出)、できなければ失敗(幽霊)
- 難易度: 80 回中 40 回成功(50%)
- 音: スタートの「ピロン」、ボールが壁に当たる「コッ」、迷路が回る「ゴゴゴ…ガチャン」、脱出するたびに1音ずつ高くなる「ピロン」、スピードアップの合図。BGMなし。
  成功は どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打+鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の下の「失敗したら・・・」は、血がしたたる怖い筆文字(Yuji Boku・SIL OFL)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
