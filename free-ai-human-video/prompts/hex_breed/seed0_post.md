# 投稿用テキスト:hex_breed_0.mp4(ぶつかると1個増えるボール・回る六角形・300個・成功パターン)

- 動画: assets/output/hex_breed_0.mp4(1080x1920 / 60fps / 39.4秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/hex_breed/hex_breed.py render --seed 0`
- 結末: 成功(シード0をそのまま使用・選んでいない)。1.0秒で3個になるが、そこからなかなか出会えず 20.6秒でやっと10個 → 28.0秒で50個 →
  30.0秒で100個 → 31.7秒で200個 → 32.7秒(残り0.3秒)に300個!! → 全部のボールが虹色に光って大当たり演出
- 音量: 通常部分 約 -13dB
- ルール: ゆっくり回る六角形のわくの中を、はじめは2個のボールが動く。重力・摩擦なし、ボールはいつも同じ速さで跳ね返る(ねらい・補正なし)。
  ボールとボールがぶつかると、そのあいだのすぐ横の空いている所に1個生まれる。生まれて0.6秒は増やさない・1個生んだ2個は0.8秒休む(生まれた瞬間に次々増える連鎖はしない)。
  33秒以内に300個になれば成功(大当たり演出)、ならなければ失敗(幽霊)
- 難易度: 80 回中 44 回成功(55%)
- 音: ぶつかって生まれる「コロン」(マリンバとベルを混ぜたやわらかい音・ペンタトニックの音階で、数が増えるほど高い音が出やすい・ひびきつき)。BGMなし。
  成功は どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打+鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の下の「失敗したら・・・」は、血がしたたる怖い筆文字(Yuji Boku・SIL OFL)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
