# 投稿用テキスト:saw_pendulum_1.mp4(鉄球の振り子で虹のブロックを全部けずる・失敗パターン)

- 動画: assets/output/saw_pendulum_1.mp4(1080x1920 / 60fps / 67.5秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/saw_pendulum/saw_pendulum.py render --seed 1`
- 結末: 失敗(シード0から順に見て最初の失敗=シード1をそのまま使用。はなす角度62°)。12.1秒で25% → 24.7秒で50% → 38.2秒で75% → 46.3秒で90%まで行くが、
  ゆれが小さくなって両はしの下のほうまでとどかず、96.7%で時間切れ → 幽霊 → 画面が暗くなって「Failed...」+しょんぼりBGM
- 音量: 通常部分 約 -15dB
- 参考動画: ユーザー提供の「振り子で虹色のブロックをけずる」動画の形を参考に、映像と音を一から作った
- ルール: 固定した点から1本の紐でたれた重い鉄球が、ふつうの振り子として左右に大きくゆれる(つり下げ点は動かない)。重力は弱め(ゆっくりゆれる)。
  はじめは紐をななめにもち上げてからはなす(はなす角度は50〜88°・左右はシードごとにちがう)。動きは振り子の式どおり(紐がのびるときの式 θ''=-(g/L)sinθ-2(L'/L)θ')。ねらい・補正なし。
  クレーンが一定の速さで紐を少しずつのばしていくので、鉄球はだんだん低い所をとおるようになる。
  鉄球がとおった所の虹色のブロックがくだける。下のほうをくだいたときは、その上にあった所もいっしょにくずれる(上から順にけずれていく)。
  くだくたびにほんの少しだけ遅くなる(ゆれがだんだん小さくなる)。ゆれが小さくなりすぎると、両はしまでとどかなくなる。
  62秒以内にブロックを全部(100%)けずれたら成功(大当たり演出)、けずれなければ失敗(幽霊 → 暗くなって「Failed...」)
- 難易度: 80 回中 40 回成功(50%)。はなす角度が大きいほど成功しやすい
- 音: けずる「ジャリジャリ」(けずる量が多いほど大きく高く)。BGMなし。
  成功は どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打+鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の文字は最小限(上に「全部けずれる？」・けずれた%・残り秒数)。フォントは Zen Kaku Gothic New、「失敗したら…」は怖い筆文字 Yuji Syuku、
  最後の「Congratulations!!」「COMPLETE」「Failed...」は Playfair Display Italic(すべて SIL OFL)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
