# 投稿用テキスト:saw_pendulum_3.mp4(ノコギリの振り子で虹のブロックを全部けずる・失敗パターン)

- 動画: assets/output/saw_pendulum_3.mp4(1080x1920 / 60fps / 42.7秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/saw_pendulum/saw_pendulum.py render --seed 3`
- 結末: 失敗(シード0から順に見て最初の失敗=シード3をそのまま使用)。8.0秒で25% → 10.4秒で50% → 15.1秒で75% → 24.3秒で90% → 34.8秒で99%まで行くが、
  残りのかけら(99.7%)がけずれないまま時間切れ → 幽霊 → 画面が暗くなって「Failed...」+しょんぼりBGM
- 音量: 通常部分 約 -15dB
- 参考動画: ユーザー提供の「ノコギリの多重振り子で虹色のブロックをけずる」動画の形を参考に、映像と音を一から作った
- ルール: 上からつるした3本の棒の振り子(多重振り子)の先に、回るノコギリがついている。重力あり、棒どうしは自由に回るピンでつながっていて、
  はじめはほぼ横にもち上げてからはなす(向きはシードごとに少しちがう)。振り子は物理どおりにでたらめに(カオス的に)ゆれる。ねらい・補正なし。
  ノコギリが通った所の虹色のブロックがけずれる。けずるたびに少しブレーキがかかり、回る刃がブロックをけって横へ進む(モーターの力)。
  下の床(ブロックの底)とつながっていない破片は、支えがないので落ちる。つり下げ点は、残っているブロックの上のほうに合わせてゆっくり下がる。
  37.2秒以内にブロックを全部(100%)けずれたら成功(大当たり演出)、けずれなければ失敗(幽霊 → 暗くなって「Failed...」)
- 難易度: 80 回中 39 回成功(49%)
- 音: けずる「ジャリジャリ」(けずる量が多いほど大きく高く)。BGMなし。
  成功は どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打+鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の文字は最小限(上に「全部けずれる？」・けずれた%・残り秒数)。フォントは Zen Kaku Gothic New、「失敗したら…」は怖い筆文字 Yuji Syuku、
  最後の「Congratulations!!」「COMPLETE」「Failed...」は Playfair Display Italic(すべて SIL OFL)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
