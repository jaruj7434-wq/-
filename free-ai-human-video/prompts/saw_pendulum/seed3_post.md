# 投稿用テキスト:saw_pendulum_3.mp4(関節4本のカクカク鉄球振り子で虹のブロックを全部けずる・失敗パターン)

- 動画: assets/output/saw_pendulum_3.mp4(1080x1920 / 60fps / 58.5秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/saw_pendulum/saw_pendulum.py render --seed 3`
- 結末: 失敗(はなす角度 66°/78°/84°/99°)。1.1秒で25% → 9.8秒で50% → 22.2秒で75% → 29.0秒で90% →
  53秒の時間切れで 97.0%(宙に残ったかけらにとどかなかった)→ 幽霊 → 「Failed...」
- 音量: 通常部分 約 -14dB
- 参考動画: ユーザー提供の「振り子で虹色のブロックをけずる」動画の形を参考に、映像と音を一から作った
- ルール: 固定した点(横には動かない)から、4本の棒が3つの関節でつながった「カクカクの紐」(多重振り子)がたれていて、先に重い大きな鉄球(半径85px)がついている
  (棒の長さ 150/135/125/110px、関節のおもり 1・1・1、鉄球 3)。
  はじめは全部の棒をななめにもち上げてからはなす(1本目50〜88°、先の棒ほど少しずつ大きく・左右はシードごとにちがう)。
  動きは多重振り子の運動方程式(ラグランジュの式)どおり、RK4で計算。関節がクネクネ折れ曲がるので、毎回ちがうカオスな動きになる。ねらい・補正なし。
  つり下げ点はまっすぐ下へ一定の速さ(15px/秒)で下がり(ブロックの上から1/2くらいの高さまで)、鉄球はだんだん低い所をとおるようになる。重力は強め。
  鉄球が当たった所(鉄球の円と重なった所)の虹色のブロックだけがくだける。下のほうに当たっても、その上の所はくずれずに残る(切りはなされた所も落ちずにそのまま残るので、鉄球で当てて全部くだく必要がある)。
  くだくたびにほんの少しだけ遅くなる(当たっても速くはならない)。
  53秒以内にブロックを全部(100%)けずれたら成功(大当たり演出)、けずれなければ失敗(幽霊 → 暗くなって「Failed...」)
- 難易度: 80 回中 38 回成功(48%)
- 音: けずる「ジャリジャリ」(けずる量が多いほど大きく高く)。BGMなし。
  成功は どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打+鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の文字は最小限(上に「全部けずれる？」・けずれた%・残り秒数)。フォントは Zen Kaku Gothic New、「失敗したら…」は怖い筆文字 Yuji Syuku
  (鉄球が下まで来たときは重ならないようにうすく消える)、最後の「Congratulations!!」「COMPLETE」「Failed...」は Playfair Display Italic(すべて SIL OFL)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
- シードの選び方: シード0から順に計算し、最初の成功(0)と最初の失敗(3)をそのまま使用(結果は編集していない)
