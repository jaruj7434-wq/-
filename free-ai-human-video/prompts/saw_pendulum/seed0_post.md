# 投稿用テキスト:saw_pendulum_0.mp4(カクカク紐の鉄球振り子で虹のブロックを全部けずる・失敗パターン)

- 動画: assets/output/saw_pendulum_0.mp4(1080x1920 / 60fps / 67.5秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/saw_pendulum/saw_pendulum.py render --seed 0`
- 結末: 失敗(はなす角度 85° / 120°)。2.0秒で25% → 23.1秒で50% → 36.9秒で75% → 46.7秒で90% →
  62秒の時間切れで 97.8%(両はしが少し残った)→ 幽霊 → 「Failed...」
- 音量: 通常部分 約 -14dB
- 参考動画: ユーザー提供の「振り子で虹色のブロックをけずる」動画の形を参考に、映像と音を一から作った
- ルール: 固定した点(横には動かない)から、2本の棒がピンでつながった「カクカクの紐」(二重振り子)がたれていて、先に重い鉄球がついている。
  はじめは2本ともななめにもち上げてからはなす(1本目50〜88°、2本目はそれより10〜60°大きく・左右はシードごとにちがう)。
  動きは二重振り子の運動方程式どおり(RK4で計算)。関節で折れ曲がるので、ゆれ方が毎回ちがい読めない。ねらい・補正なし。
  つり下げ点はまっすぐ下へ一定の速さ(10px/秒)でゆっくり下がり、鉄球はだんだん低い所をとおるようになる。
  鉄球がとおった所の虹色のブロックがくだける。下のほうをくだいたときは、その上にあった所もいっしょにくずれる(上から順にけずれていく)。
  くだくたびにほんの少しだけ遅くなる(当たっても速くはならない)。
  62秒以内にブロックを全部(100%)けずれたら成功(大当たり演出)、けずれなければ失敗(幽霊 → 暗くなって「Failed...」)
- 難易度: 80 回中 39 回成功(49%)
- 音: けずる「ジャリジャリ」(けずる量が多いほど大きく高く)。BGMなし。
  成功は どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打+鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の文字は最小限(上に「全部けずれる？」・けずれた%・残り秒数)。フォントは Zen Kaku Gothic New、「失敗したら…」は怖い筆文字 Yuji Syuku、
  最後の「Congratulations!!」「COMPLETE」「Failed...」は Playfair Display Italic(すべて SIL OFL)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
- シードの選び方: シード0から順に計算し、最初の成功(1)と最初の失敗(0)をそのまま使用(結果は編集していない)
