# 投稿用テキスト:saw_pendulum_0.mp4(関節つき鉄球の振り子で虹のブロックを全部けずる・成功パターン)

- 動画: assets/output/saw_pendulum_0.mp4(1080x1920 / 60fps / 44.8秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/saw_pendulum/saw_pendulum.py render --seed 0`
- 結末: 成功(はなす角度 77°/92°/110°/125°)。10.0秒で25% → 19.4秒で50% → 26.7秒で75% → 31.4秒で90% → 38.0秒で99% →
  38.02秒(残り0.08秒!)に全部けずれた!! → 大当たり演出
- 音量: 通常部分 約 -14dB
- 参考動画: ユーザー提供の「振り子で虹色のブロックをけずる」動画の形を参考に、映像と音を一から作った
- ルール: 固定した点(横には動かない)から、4本の棒が3つの関節でつながった紐(多重振り子)がたれていて、先に重い鉄球(半径47px)がついている
  (棒の長さ 150/135/125/110px、関節のおもり 1・1・1、鉄球 3)。関節には少しまさつがある。
  はじめは紐をななめにもち上げてからはなす(1本目45〜80°、先の棒ほど大きく・左右はシードごとにちがう)。
  動きは多重振り子の運動方程式(ラグランジュの式)どおり、RK4で計算。ねらい・補正なし。
  ブロックをくだくと、くだいた分だけ鉄球にだけブレーキ(力積)がかかる。重い鉄球だけが急に止められるので、紐が関節でしなって折れる。
  つり下げ点には振り子を押すモーターがあり、ブレーキや関節のまさつでへった勢い(エネルギー)の分だけ、振り子全体がゆれている向きに押して、
  はなした時の勢いを保つ(ねらって当てる制御はしない)。そのため最後まで左右に大きく振れ続ける。
  つり下げ点はまっすぐ下へ一定の速さ(15px/秒)で下がる(鉄球がちょうど床をなでる高さまで)。
  鉄球が当たった所(鉄球の円と重なった所)の虹色のブロックだけがくだける。下のほうに当たっても、その上の所はくずれない。
  ただし床とつながっていない小さなかけら(300マス以下)は、支えがないのでくずれ落ちる(大きな塊は落ちない)。
  38.1秒以内にブロックを全部(100%)けずれたら成功(大当たり演出)、けずれなければ失敗(幽霊 → 暗くなって「Failed...」+削り残した所を赤い輪で表示)
- 難易度: 80 回中 40 回成功(50%)
- 音: けずる「ジャリジャリ」(けずる量が多いほど大きく高く)。BGMなし。
  成功は どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打+鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の文字は最小限(上に「全部けずれる？」・けずれた%・残り秒数)。フォントは Zen Kaku Gothic New、「失敗したら…」は怖い筆文字 Yuji Syuku
  (鉄球が下まで来たときは重ならないようにうすく消える)、最後の「Congratulations!!」「COMPLETE」「Failed...」は Playfair Display Italic(すべて SIL OFL)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
- シードの選び方: シード0から順に計算し、最初の成功(0)と最初の失敗(1)をそのまま使用(結果は編集していない)
