# 投稿用テキスト:cradle_3.mp4(ニュートンのゆりかごで金の鐘・成功パターン)

- 動画: assets/output/cradle_3.mp4(1080x1920 / 60fps / 24.4秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/cradle/cradle.py render --seed 3`
- 結末: 成功。右はしの球の振り上がり Lv.1 で78° → Lv.3 で47° → Lv.4 で54° → Lv.5 のひと振りで一気に鐘まで!(17.69秒・残り12.8秒)→ チーン → 大当たり演出
- 音量: 通常部分 約 -14dB
- ルール: 上の棒から虹色の鉄球16個が糸で一列につり下がっている(左から 半径36px×4 → 27px×4 → 20px×4 → 14px×3 → 右はしの11px)。
  左のモーターつきハンマーが4秒ごとに左はしの球をたたく。たたくたびに少しずつ高くふり上げる(Lv.1 → Lv.2 …だんだん強くなる)。
  勢いは「カチン!」と球から球へ伝わる(ニュートンのゆりかご)。重い球が軽い球に当たると軽い球は速く飛び出すので、小さい球ほど勢いがます。
  右はしの小さな球(短い糸)が大きく振り上がって、右上の金の鐘(真下から135°の所)に当たれば成功。
  物理エンジン pymunk。糸はたるむ・のびない。球どうしの はねかえり係数 0.93。ハンマーは決まった動きをくり返すだけで、ねらい・補正なし。
  シードで変わるのは、球と球のすき間(0〜1.5px)だけ。前の揺れが残ったままたたくので、毎回の伝わり方がかわる。
  30.5秒以内に鐘を鳴らせば成功(大当たり演出)、鳴らせなければ失敗(幽霊 → 暗くなって「Failed...」)
- 難易度: 80 回中 37 回成功(46%)
- 音: 球がぶつかる「カチン」(小さい球ほど高い・ぶつかる強さで大きさがかわる)、ハンマーの「ゴン」、鐘の「チーン」。BGMなし。
  成功は 鐘 → どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の文字は最小限(上に「鐘を鳴らせる？」・ハンマーの強さ Lv.・残り秒数)。フォントは Zen Kaku Gothic New、「失敗したら…」は怖い筆文字 Yuji Syuku、
  最後の「Congratulations!!」「DING!」「Failed...」は Playfair Display Italic(すべて SIL OFL)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
- シードの選び方: シード0から順に計算し、最初の成功(3)と最初の失敗(0)をそのまま使用(結果は編集していない)
