# 投稿用テキスト:plinko_79.mp4(パチンコ盤 + 増殖ゲート回)

- 動画: `assets/output/plinko_79.mp4`(1080x1920 / 60fps / 34秒 / H.264 + AAC)
- 再生成: `python scripts/plinko/plinko.py render --seed 79`
- 展開: 最初の10秒でカップに入ったのは7個だけ → ×2ゲートで玉が増える → 8秒でドロッパー+1
  → 16秒で×3ゲート出現 → 24秒でカップが速くなる
- 結末: 失敗。98/100個で時間切れ → 幽霊が出る
- 難易度: この設定では 300 回中 168 回成功(成功率 約56%)
- 音楽: ベートーヴェン「歓喜の歌」(パブリックドメイン)の旋律を、プログラムで音を合成して使用
