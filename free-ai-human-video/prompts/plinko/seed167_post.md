# 投稿用テキスト:plinko_167.mp4(パチンコ盤 + 増殖ゲート + 縦長コップ回)

- 動画: `assets/output/plinko_167.mp4`(1080x1920 / 60fps / 34秒 / H.264 + AAC)
- 再生成: `python scripts/plinko/plinko.py render --seed 167`
- 展開: 縦長のコップに玉がどんどん溜まっていく(約100個で縁までいっぱい)。10秒時点では12個だけ
  → ×2ゲートで玉が増える → 8秒でドロッパー+1 → 16秒で×3ゲート出現 → 24秒でカップが速くなる
- 結末: 失敗。99/100個で時間切れ(縁ギリギリまで溜まった状態)→ 幽霊が出る
- 難易度: この設定では 200 回中 102 回成功(成功率 約51%)
- 音楽: ベートーヴェン「歓喜の歌」(パブリックドメイン)の旋律を、プログラムで音を合成して使用
