- 再生成: `python scripts/domino_machine/domino_machine.py render --seed 0`
- ルール: 横から見た、ドミノとボールをつないだからくり装置(右へ進む・カメラが追いかける)。段ごとにコースの形が変わる:
  1. 平らな棚のドミノ15枚 → 赤いゴムボール → 鉄のジグザグレール(右へ → かべで折り返して左へ → また右へ)
  2. 下り階段のドミノ15枚(1枚ずつ段の上)→ ガラス玉 → バネの板で跳ねて次の棚へ飛ぶ
  3. 上り階段のドミノ17枚 → サッカーボール → 深い谷(急に下って、勢いでなだらかな向こう側へのぼる)
  4. 平らな棚のドミノ15枚 → バスケットボール → 急な坂からシーソー橋へ(ボールが支点をこえると板がかたむいて次の棚へ)
  5. 下り階段のドミノ17枚 → ボウリングの玉 → ジャンプ台で穴を飛びこえる(ここが運命の分かれ目)
  6. 着地できれば、最後のドミノ15枚(1枚ごとに大きくなる・最後は金の巨大ドミノ)を倒し、鐘を鳴らせば成功
  ドミノが実際に次のドミノに当たった瞬間に「歓喜の歌」が1音ずつ進む(全94音・1音あたり約0.12秒のテンポ)。物理は重力・衝突・摩擦のまま(押すのは最初の1枚だけ・ねらい・補正なし)。
  役目を終えたボールは転がり抵抗でだんだん止まる。ドミノの間隔のばらつきで、ジャンプの飛ぶきょりが毎回少し変わる
- 結末: 失敗。ジグザグ・バネ・谷・シーソー橋をこえて79音まで演奏したが、ジャンプでボウリングの玉が向こうの台にわずかに届かず穴に落ちた(あと15音)→ 幽霊 → しょんぼりBGM
- 難易度: 40 回中 20 回成功(成功率 約50%)。失敗はほとんどジャンプ(まれに着地したあと止まる)
- 音楽: ベートーヴェン「歓喜の歌」(交響曲第9番・パブリックドメイン)をプログラムで演奏。1段目 オルゴール → 2段目 オルゴール+ピアノ → 3段目 ピアノ+低音 → 4・5段目 ストリングス・ブラスも加わる → 最後の列はさらに豪華に。成功したら鐘とジャーン
- 音: ドミノの「カチッ」、ジャンプの「シュッ」、穴に落ちる「ドン」。幽霊のあとは「ワッ・ワッ・ワッ・ワ〜ン」と下がる残念なトランペット+暗いピアノのしょんぼりBGM(`scripts/common/fail_bgm.py`・プログラムで作った音)。サッカーボール・バスケットボールはどこのメーカーにも似せていない模様

- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
