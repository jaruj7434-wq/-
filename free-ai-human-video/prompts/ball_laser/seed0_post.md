# 投稿用テキスト:ball_laser_0.mp4(レーザーで切ると2つに分かれるボール・1000個・失敗パターン)

- 動画: assets/output/ball_laser_0.mp4(1080x1920 / 60fps / 23.0秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/ball_laser/ball_laser.py render --seed 0`
- 結末: 失敗(シード0をそのまま使用・選んでいない)。スタート直後にレーザーに触れて分裂 → 1.7秒で10個 → 6.4秒で100個 → 13.4秒で500個。
  7.0秒から小さくなりすぎたボールが消えはじめ、849個で時間切れ → 幽霊 → しょんぼりBGM
- ルール: 丸いわくの中を、まん中を通る赤いレーザーがゆっくり回る(1周約7秒)。はじめは大きなボール1個(半径250px)。重力なし、ボールはいつも同じ速さで、わく・ほかのボールで跳ね返る(ねらい・補正なし)。
  レーザーの線がボールに少しでも触れたら(レーザーが回って触れても、ボールが動いて触れても)、ボールは面積が半分の2個に分かれ、レーザーの両側へはじける。
  分かれたばかりのボールは0.35秒は切られない。半径4.5pxより小さいボールが切られると、2個にならずに消える。色は分かれた回数ごとに変わる。
  17.5秒以内に1000個になれば成功(大当たり演出)、ならなければ失敗(幽霊)
- 難易度: 80 回中 42 回成功(53%)
- 音量: 通常部分 約 -13dB
- 音: レーザーの低いうなり、切れる「ジュッ」+分かれる「ポン」(小さいボールほど高い)、消える「パシュッ」。BGMなし。
  成功は ドーン!+ファンファーレ連打+キュイン+チャリンチャリン+キュインキュインの連打+ジャラジャラ鳴る鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
