# 投稿用テキスト:ball_eat_0.mp4(ヘソに入った玉が虹色の玉を食べつくす・成功パターン)

- 動画: assets/output/ball_eat_0.mp4(1080x1920 / 60fps / 42.1秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/ball_eat/ball_eat.py render --seed 0`
- 結末: 成功(打った玉117発・ヘソ13回)。3.0秒で初めてヘソ → 6.3秒で25% → 9.5秒で50% → 12.8秒で75% → 14.8秒で90% → 18.7秒で99% →
  かべぎわに光る残りを追いかけて 35.4秒(残り9.6秒)に全部食べた!! → 大当たり演出
- 音量: 通常部分 約 -14dB
- 参考動画: ユーザー提供の「balls eaten」(小さな玉を食べて大きくなるボール)の形を参考に、パチンコの要素を足して映像と音を一から作った
- ルール: 上はパチンコの盤面(釘150本)。左のレールから銀のパチンコ玉が0.3秒ごとに1発ずつ打ちこまれ、重力で釘に当たりながら落ちる。
  打ちこむ強さは毎回 ±7% だけばらつく(ハンドルのぶれ。シードで変わるのはここだけ)。ねらい・補正なし。
  下のまん中のヘソ(入賞口・はば30px)に入った玉だけが、短いパイプを通って下のへやに落ち、口をあけたキャラに変身する。外れた玉は両はしのアウト口へ消える。
  へや(角の丸い長方形)には小さな虹色の玉(半径4.5px)が6467個ぎっしりつまっている。キャラはふれた玉を食べて大きくなる(食べた面積の2%ずつ)。
  キャラは重力で落ちて、かべやほかのキャラにふつうに跳ね返る(物理エンジン pymunk・弾性衝突。食べても向きは変わらない)。
  45秒以内に全部(100%)食べたら成功(大当たり演出)、残ったら失敗(幽霊 → 暗くなって「Failed...」+ 食べのこした玉を赤い輪で表示)
- 難易度: 80 回中 40 回成功(50%)。ヘソに入る確率は打った玉の約8%
- 音: パチンコ玉を打ちこむ「カシャ」、釘に当たる「チン」、ヘソに入った「キュイン!」、食べる「ポッ」(食べた量が多いほど音階が上がる)。BGMなし。
  成功は どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打+鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- キャラは進む向きに大きな口をあけ、食べている間は口をパクパク動かす(見た目だけ。当たり判定は丸い体のまま)。ときどきまばたき
- 残りが80個以下になると、残っている玉がふわっと光って見やすくなる(見た目だけ)
- 画面の文字は最小限(上に「全部たべられる？」・食べた%・残り秒数、ヘソの上に小さく「ヘソ」)。フォントは Zen Kaku Gothic New、「失敗したら…」は怖い筆文字 Yuji Syuku、
  最後の「Congratulations!!」「COMPLETE」「Failed...」は Playfair Display Italic(すべて SIL OFL)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
- シードの選び方: シード0から順に計算し、最初の成功(0)と最初の失敗(1)をそのまま使用(結果は編集していない)
