# 投稿用テキスト:head_grow_27.mp4(女の子の頭の形の枠・当たった所で大きさが変わる玉・成功パターン)

- 動画: assets/output/head_grow_27.mp4(1080x1920 / 60fps / 27.9秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/head_grow/head_grow.py render --seed 27`
- ルール: チャンネルのサムネの女の子(おかっぱ)の頭の形をした枠が、ゆっくり回る。枠は12の区切りに分かれていて、区切りごとに効果がある:
  ×1.2(緑)・×1.5(金)・−1.5(赤)、1つはすき間(赤い点線)。玉は重力で跳ね(ねらい・補正なし)、壁から離れていた玉が新しくぶつかった瞬間に、
  その区切りの効果で大きさ(数字)が変わる(壁を転がっているあいだは変わらない)。はじめの大きさは3、玉の半径は大きさに比例。
  大きさ25(枠いっぱい)になれば成功(パチンコの当たり風の演出)。すき間から落ちる、または −1.5 で大きさが0以下になって消えたら失敗(幽霊)。
  はじめはすき間が上にある向きから始まる。当たった効果は玉の上にポンと表示、上に「大きさ ○ / 25」。玉はサムネの女の子の顔+光る輪(大きくなるほど青→赤)
- 結末: 成功。×1.2で3.6→4.3、−1.5が2回続いて1.3まで小さくなるピンチ → ×1.5や×1.2で少しずつ持ち直し、−1.5をはさみながら一進一退 →
  14秒すぎから ×1.5 → ×1.2 → ×1.5 → ×1.5 と一気に育って 7.4 → 8.8 → 13.3 → 19.9 → 23.9、−1.5で22.4に下がったあと ×1.2 で 18.4秒に枠いっぱい(24回)→ パチンコの当たり風の演出
  (フリーズ→虹ストロボ「!!」→女の子の顔の図柄のリールでリーチ→虹色が揃う→本番:「枠いっぱい!!」「COMPLETE」「24回で成功」)。80回の中で成功までいちばん時間がかかった回を選んだ(動きはそのまま)
- 難易度: 80 回中 38 回成功(約48%)
- 音量: 通常部分 約 -13dB
- 音: ×1.2・×1.5 は「ポン+ぷくっ」(大きくなるほど音階が上がる。×1.5 はキュインつき)、−1.5 は「ブッ…」と下がる音、落ちる「ヒューン」、消える「パフッ」。BGMなし。
  成功はパチンコの当たり風の演出の音(フリーズ→ドンッ→キュインキュイン→リール→ファンファーレ連打+キュインキュイン+ジャラジャラ)、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
