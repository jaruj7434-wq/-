# 投稿用テキスト:water_fill_7.mp4(虹色の水でコップを満タン・失敗パターン)

- 動画: assets/output/water_fill_7.mp4(1080x1920 / 60fps / 31.9秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/water_fill/water_fill.py render --seed 7`
- 結末: 失敗。4.2秒で最初の水がコップへ → 12秒で全開 → 14.1秒で25% → 19.1秒で50% → 22.8秒で75% → 25.1秒で90% →
  あと6粒(99.2%)のところで 26.41秒の時間切れ → 幽霊 → 「Failed...」
- 音量: 通常部分 約 -14dB
- ルール: 上の蛇口から虹色の水(小さな粒・半径6px)が流れ出る。はじめは1秒に32粒、12秒で蛇口が全開になり1秒に64粒。
  水は 斜めの板A → 水の勢いだけで回る水車(モーターなし)→ 穴が2つあいた板B → 下のコップ と流れる。
  板Bの穴から落ちた水や、水車にはねて右のかべを越えた水はこぼれてしまう。
  水は物理エンジン pymunk の粒(重力・衝突・まさつなし)。見た目は粒をぼかしてつなげ、なめらかな水にしている。
  シードで変わるのは、蛇口から出る水のほんの少しのばらつきだけ。ねらい・補正なし。
  26.41秒以内にコップの金色の点線まで水がたまれば(732粒)成功(大当たり演出)、たまらなければ失敗(幽霊 → 暗くなって「Failed...」)
- 難易度: 80 回中 42 回成功(53%)。どの回も満タンになるのは26.0〜26.8秒の間で、毎回ギリギリの勝負になる
- 音: 水の流れる「サー」(水の量に合わせて大きく)、コップにたまる「ポチャ」(たまるほど音が上がる)、全開の「キュイン!」。BGMなし。
  成功は どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打+鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の文字は最小限(上に「満タンにできる？」・満タン度%・残り秒数、全開のときだけ「全開!」)。フォントは Zen Kaku Gothic New、「失敗したら…」は怖い筆文字 Yuji Syuku、
  最後の「Congratulations!!」「FULL」「Failed...」は Playfair Display Italic(すべて SIL OFL)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
- シードの選び方: シード0から順に計算し、最初の成功(0)と最初の失敗(7)をそのまま使用(結果は編集していない)
