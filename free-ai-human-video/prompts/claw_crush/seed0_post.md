# 投稿用テキスト:claw_crush_0.mp4(つかみ腕でつぶすと3つに増えるボール・成功パターン・虹色パチンコ演出)

- 動画: assets/output/claw_crush_0.mp4(1080x1920 / 60fps / 39.4秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/claw_crush/claw_crush.py render --seed 0`
- 参考: ユーザーから受け取った「Satisfying ball crusher」(左右の歯車の腕がボールをはさんでつぶすと増える)の形式。絵・色・音・ルールの数字はすべて自作(参考動画のロゴやデザインは使っていない)
- ルール: 丸いわくの左右に歯車があり、それぞれにL字に曲がった2本の腕(つかみ腕)。腕は歯車のまわりを一定の速さでぐるぐる回りながら(左右で逆回り)、あごを開いたり閉じたりする(決まったリズム)。閉じきると2本の腕の先が合わさって四角い「かご」になる。
  はじめは白いボール1個。重力なし、ボールはいつも同じ速さでまっすぐ進み、わく・ほかのボール・腕で跳ね返る(ねらい・補正なし)。
  腕が閉じようとしているとき、2本の腕のあいだにいて腕の内側に押されたボール、または閉じきった瞬間にかごの中にいるボールが「つぶれる」。
  つぶれたボールは消えて、腕のすぐ外の空いている所に、次の色のボール3個が生まれる(重なって生まれない。腕のあいだには生まれず、閉じ始めたあとに生まれたボールはその回にはつぶれないので、「生まれてすぐまたつぶれる」連鎖はない)。
  色の順番:白 → 青 → 紫 → 緑 → 赤 → 金 → 虹(虹はそれ以上変わらない)。下に色の進化表。34.2秒以内に1000個で成功(虹色パチンコ演出)、ならなければ失敗(幽霊)
- 結末: 成功(成功パターンの依頼。シード0から順に見て最初の成功=シード0をそのまま使用)。
  0.9秒で最初につぶれて3個 → 7.8秒で10個 → 17.2秒で50個 → 20.6秒で100個 → 24.7秒で300個 → 27.5秒で500個 → 30.7秒で800個 → 30.9秒(残り3.3秒)で1007個!! →「大当たり!!」「1000個達成!!」の虹色パチンコ演出(キュインキュイン)
  色は 青 0.9秒 → 紫 3.6秒 → 緑 7.8秒 → 赤 11.1秒 → 金 13.9秒 → 虹 17.9秒 で初登場
- 難易度: 60 回中 25 回成功(約42%)
- 音: つぶれる「パキッ」+3つに分かれる「ポポポン」(色が上がるほど高い)、腕が閉じきる「カシャン」、成功は虹色パチンコ演出のキュインキュイン+ファンファーレ+ジャラジャラ鳴る鐘。BGMなし。すべてプログラムで作った音
- 音量: 通常部分 約 -15dB
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
