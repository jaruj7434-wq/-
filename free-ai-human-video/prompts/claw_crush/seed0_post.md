- 動画: assets/output/claw_crush_0.mp4(1080x1920 / 60fps / 49.5秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/claw_crush/claw_crush.py render --seed 0`
- 参考: ユーザーから受け取った「Satisfying ball crusher」。参考動画を0.125秒ごとに見て、動きをできるだけ忠実に再現した(絵・色・音・数字は自作。参考動画のロゴやデザインは使っていない):
  ・ボールは重力なしで、ふわふわ漂う(速さは一定ではなく、ほとんど減らない。わくでは跳ね返る。ボールどうしは少し吸いつくようにぶつかり、かたまりで動く)
  ・左右の歯車にL字の腕2本。腕は歯車のまわりを回りながら、V字に開く → [字 → 腕の先が合わさってひし形のかご → 腕どうしが重なるT字まで閉じきる、をくり返す(わくの外を向いているあいだは、わくの外を通る)
  ・閉じていく2本の腕の両方に同時にふれた瞬間(=はさまれた瞬間)、またはひし形のかごが閉じた瞬間にかごの中にいたボールが、その場で次の色のボール4個のかたまりに分かれて、腕に押し出されていく
  ・腕が閉じ始めたあとに生まれたボールは、その回にははさまれない(生まれてすぐまたはさまれる連鎖はない)
  色の順番:白 → 青 → 紫 → 緑 → 赤 → 金 → 虹(虹はそれ以上変わらない)。下に色の進化表。41.1秒以内に3000個で成功(虹色パチンコ演出)、ならなければ失敗(幽霊)
- 結末: 成功(成功パターンの依頼。シード0から順に見て最初の成功=シード0をそのまま使用)。
  3.4秒で最初にはさまれて4個 → 6.6秒で16個 → 19.7秒で50個 → 27.4秒で100個 → 33.8秒で500個 → 34.6秒で1000個 → 37.8秒で2000個 → 41.0秒(残り0.1秒)で3244個!! →「大当たり!!」「3000個達成!!」の虹色パチンコ演出(キュインキュイン)
  色は 青 3.4秒 → 紫 6.6秒 → 緑 10.1秒 → 赤 14.1秒 → 金 17.4秒 → 虹 19.7秒 で初登場。ボールでいっぱいのかごが閉じると、中のボールがまとめてはさまれて一気に増える(最後は1回で数百個)
- 難易度: 40 回中 約24 回成功(約60%)。3000個に届く時刻は腕のリズムにそろって41.0秒前後に集中する
- 音: はさまれる「パキッ」+4つに分かれる「ポポポポン」(色が上がるほど高い)、腕が閉じきる「カシャン」、成功は虹色パチンコ演出のキュインキュイン+ファンファーレ+ジャラジャラ鳴る鐘。BGMなし。すべてプログラムで作った音
- 音量: 通常部分 約 -15dB
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
