# 投稿用テキスト:claw_crush_3.mp4(ハサミのような役物にはさまれると2倍に増えるボール・目標3000個・成功パターン・虹色パチンコ演出)

- 動画: assets/output/claw_crush_3.mp4(1080x1920 / 60fps / 57.7秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/claw_crush/claw_crush.py render --seed 3`
- 参考: ユーザーから受け取った「Satisfying ball crusher」。参考動画を0.1秒ごとのコマ送りで分析して、役物の動きを再現した(絵・色・音・数字は自作。参考動画のロゴやデザインは使っていない):
  ・左右の役物は同じ動き。歯車を支点に、先が90度曲がったL字の刃が2本。2本の刃は上下対称で、ハサミのようにおたがい逆向きに、一定の速さで回り続ける(1周3秒)。
    形は 外向きのV字 → [字 → 刃の先が合わさってひし形 → 2本が重なるT字(ここではさむ)→ 交差して反対側へ抜ける → わくの外で開いて… をくり返す(役物の向きは固定。わくの外を通るあいだは、わくの外に見える)。
    刃の根元側と先の曲がった部分はほぼ同じ長さ(わくの直径の約26%)
  ・ボールは重力なしで、軽く漂う(速さはほとんど減らない。わく・ほかのボールではよく跳ね返る。はさまれて分かれたボールは、ぱっとはじけて飛び出す)
  ・はさまれた瞬間に増える:内側で閉じていく2本の刃の両方に同時にかかった瞬間(刃のまわりにボール約1個分の「感じとる範囲」をつけて、はさまったのに増えない、ということがないようにした)、またはひし形に囲まれていたボールが刃がT字に重なった瞬間に、その場で次の色のボール2個に分かれ(はさまった数の2倍になる)、刃に押し出されていく
    (刃が閉じ始めたあとに生まれたボールは、その回にははさまれない=生まれてすぐまたはさまれる連鎖はない)
  色の順番:白 → 青 → 紫 → 緑 → 赤 → 金 → 虹(虹はそれ以上変わらない)。51秒以内に3000個で成功(虹色パチンコ演出)、ならなければ失敗(幽霊)
- 結末: 成功(シード0から順に見て最初の成功=シード3をそのまま使用)。
  4.1秒で最初にはさまれて2個 → 10.2秒で8個 → 16.2秒で32個 → 25.0秒で100個 → 34.2秒で500個 → 40.2秒で1000個 → 46.2秒で2000個 → 49.2秒(残り1.8秒)に3057個!! →「大当たり!!」「3000個達成!!」の虹色パチンコ演出(キュインキュイン)
  色は 青 4.1秒 → 紫 7.1秒 → 緑 10.1秒 → 赤 13.1秒 → 金 16.1秒 → 虹 19.0秒 で初登場(刃が重なるたびに1段ずつ色が上がる)
- 難易度: 約3〜4割(目標5000個で16回計算したときの結果からの目安)。失敗の多くは、最初の白いボールが一度も役物に届かない回
- 画面: ボールは半径4.5px(たくさん入るよう小さめ)
- 音: 増えたボール1個ごとに「ポン」(増えた数だけ鳴る。最後に何百個も増えると「ポポポポ…」の大合唱。色が上がるほど高い)、はさまれる「パキッ」、刃が重なる「カシャン」。BGMなし。
  成功の虹色パチンコ演出は、キュインキュインの連打+ファンファーレ+ジャラジャラ鳴る鐘に、大当たりのファンファーレ連打+チャリンチャリンを重ね、演出のあいだずっと「キュイン!」を鳴らし続ける(演出部分は約 -9dB で、プレイ中より大きく派手に)。すべてプログラムで作った音
- 音量: 全体 約 -14dB
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
