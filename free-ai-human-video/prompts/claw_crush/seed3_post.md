# 投稿用テキスト:claw_crush_3.mp4(ハサミのような役物にはさまれると4つに増えるボール・目標3000個・参考動画を細かく分析した版・成功パターン・虹色パチンコ演出)

- 動画: assets/output/claw_crush_3.mp4(1080x1920 / 60fps / 42.2秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/claw_crush/claw_crush.py render --seed 3`
- 参考: ユーザーから受け取った「Satisfying ball crusher」。参考動画を0.1秒ごとのコマ送りで分析して、役物の動きを再現した(絵・色・音・数字は自作。参考動画のロゴやデザインは使っていない):
  ・左右の役物は同じ動き。歯車を支点に、先が90度曲がったL字の刃が2本。2本の刃は上下対称で、ハサミのようにおたがい逆向きに、一定の速さで回り続ける(1周4秒)。
    形は 外向きのV字 → [字 → 刃の先が合わさってひし形 → 2本が重なるT字(ここではさむ)→ 交差して反対側へ抜ける → わくの外で開いて… をくり返す(役物の向きは固定。わくの外を通るあいだは、わくの外に見える)。
    刃の根元側と先の曲がった部分はほぼ同じ長さ(わくの直径の約26%)
  ・ボールは重力なしで漂う(速さはほとんど減らない。わく・刃・ほかのボールで跳ね返る)
  ・はさまれた瞬間に増える:内側で閉じていく2本の刃の両方に同時にふれた瞬間、またはひし形に囲まれていたボールが刃がT字に重なった瞬間に、その場で次の色のボール4個のかたまりに分かれ、刃に押し出されていく
    (刃が閉じ始めたあとに生まれたボールは、その回にははさまれない=生まれてすぐまたはさまれる連鎖はない)
  色の順番:白 → 青 → 紫 → 緑 → 赤 → 金 → 虹(虹はそれ以上変わらない)。下に色の進化表。36秒以内に3000個で成功(虹色パチンコ演出)、ならなければ失敗(幽霊)
- 結末: 成功(成功パターンの依頼。シード0から順に見て最初の成功=シード3をそのまま使用)。
  5.6秒で最初にはさまれて4個 → 9.7秒で16個 → 13.7秒で64個 → 17.7秒で100個 → 25.7秒で500個 → 29.6秒で1000個 → 33.7秒(残り2.3秒)に役物が閉じて一気に3958個!! →「大当たり!!」「3000個達成!!」の虹色パチンコ演出(キュインキュイン)
  色は 青 5.6秒 → 紫 9.6秒 → 緑 13.5秒 → 赤 17.6秒 → 金 21.6秒 → 虹 24.0秒 で初登場(刃が重なるたびに1段ずつ色が上がり、数は約4倍に)
- 難易度: 40 回中 12 回成功(30%)。失敗の多くは、最初の白いボールが一度も役物に届かない回(40回中22回)。最初のボールがはさまれた回だけなら18回中12回成功
- 音: はさまれる「パキッ」+4つに分かれる「ポポポポン」(色が上がるほど高い)、刃が重なる「カシャン」、成功は虹色パチンコ演出のキュインキュイン+ファンファーレ+ジャラジャラ鳴る鐘。BGMなし。すべてプログラムで作った音
- 音量: 通常部分 約 -15dB
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
