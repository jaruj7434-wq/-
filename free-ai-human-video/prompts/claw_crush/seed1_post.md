- 動画: assets/output/claw_crush_1.mp4(1080x1920 / 60fps / 42.1秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/claw_crush/claw_crush.py render --seed 1`
- 参考: ユーザーから受け取った「Satisfying ball crusher」。参考動画を0.1秒ごとのコマ送りで分析して、役物の動きを再現した(絵・色・音・数字は自作。参考動画のロゴやデザインは使っていない):
  ・左右の役物は同じ動き。歯車を支点に、先が90度曲がったL字の刃が2本。2本の刃は上下対称で、ハサミのようにおたがい逆向きに、一定の速さで回り続ける(1周4秒)。
    形は 外向きのV字 → [字 → 刃の先が合わさってひし形 → 2本が重なるT字(ここではさむ)→ 交差して反対側へ抜ける → わくの外で開いて… をくり返す(役物の向きは固定。わくの外を通るあいだは、わくの外に見える)。
    刃の根元側と先の曲がった部分はほぼ同じ長さ(わくの直径の約26%)
  ・ボールは重力なしで、軽く漂う(速さはほとんど減らない。わく・ほかのボールではよく跳ね返る。はさまれて分かれたボールは、ぱっとはじけて飛び出す)
  ・はさまれた瞬間に増える:内側で閉じていく2本の刃の両方に同時にかかった瞬間(刃のまわりにボール約1個分の「感じとる範囲」をつけて、はさまったのに増えない、ということがないようにした)、またはひし形に囲まれていたボールが刃がT字に重なった瞬間に、その場で次の色のボール4個のかたまりに分かれ、刃に押し出されていく
    (刃が閉じ始めたあとに生まれたボールは、その回にははさまれない=生まれてすぐまたはさまれる連鎖はない)
  色の順番:白 → 青 → 紫 → 緑 → 赤 → 金 → 虹(虹はそれ以上変わらない)。下に色の進化表。36秒以内に3000個で成功(虹色パチンコ演出)、ならなければ失敗(幽霊)
- 結末: 成功(成功パターンの依頼。シード0から順に見て最初の成功=シード1をそのまま使用)。
  5.6秒で最初にはさまれて4個 → 9.6秒で16個 → 17.3秒で64個 → 25.6秒で500個 → 29.5秒で1000個 → 33.6秒(残り2.4秒)に3031個!! →「大当たり!!」「3000個達成!!」の虹色パチンコ演出(キュインキュイン)
  色は 青 5.6秒 → 紫 9.6秒 → 緑 13.3秒 → 赤 17.1秒 → 金 20.6秒 → 虹 23.7秒 で初登場(刃が重なるたびに1段ずつ色が上がり、数は約4倍に)
- 難易度: 16 回中 8 回成功(50%)。失敗の多くは、最初の白いボールが一度も役物に届かない回
- 音: 増えたボール1個ごとに「ポン」(増えた数だけ鳴る。最後に何百個も増えると「ポポポポ…」の大合唱。色が上がるほど高い)、はさまれる「パキッ」、刃が重なる「カシャン」。BGMなし。
  成功の虹色パチンコ演出は、キュインキュインの連打+ファンファーレ+ジャラジャラ鳴る鐘に、大当たりのファンファーレ連打+チャリンチャリンを重ね、演出のあいだずっと「キュイン!」を鳴らし続ける(演出部分は約 -9dB で、プレイ中より大きく派手に)。すべてプログラムで作った音
- 音量: 全体 約 -14dB(プレイ中の静かなところは約 -18dB、最後の演出は約 -9dB)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
