# 投稿用テキスト:icon_spiral_0.mp4(うずまきのガラス割り・ボールはチャンネルのサムネの光るボール・失敗パターン)

- 動画: assets/output/icon_spiral_0.mp4(1080x1920 / 60fps / 33.7秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/icon_spiral/icon_spiral.py render --seed 0`
- もと: 18本目「ガラスの板こわし(うずまき)」と同じコース・同じ物理。転がるボールを、チャンネルのサムネ(アイコン)に描いてある「光る白いボール」に変えた回
- ルール: 5重のうずまきの通路にガラスの板432枚。ボールは1個ずつ、うずまきの外側の口に落ちてきて、転がりながらガラスを割っていく。
  ボールは弱い順に6個:ブルー → ピンク → パープル → グリーン → ゴールド → レインボー(どれもアイコンと同じ、まっ白に光る芯+色の光の輪+尾を引く光の軌跡。強いほど光が大きく、ゴールドとレインボーは光のトゲと光の粒)。
  後のボールほど速く打ち出され、ガラスを割っても遅くなりにくい。転がり抵抗で少しずつ遅くなり、勢いがなくなったボールは薄くなって消える(ねらい・補正なし)。
  6個で432枚すべて割れば成功(大当たり演出)、ボールが尽きたら失敗(幽霊)
- 結末: 失敗(シード0をそのまま使用・選んでいない)。ブルー 0.5秒 → ピンク 3.8秒 → パープル 7.7秒 → グリーン 12.2秒 → ゴールド 17.5秒 → レインボー 23.5秒、
  レインボーが一気に割り進むが、残り2枚(430/432枚)で力尽きる → 幽霊 → しょんぼりBGM
- 難易度: 40 回中 21 回成功(約53%)。失敗した回はほとんどが残り1〜2枚
- 画面: TikTok などで隠れないよう、タイトルとボールの順番の表示を上の安全な範囲へ、枚数と「失敗したら・・・」を下の安全な範囲へ(うしろを暗くして読みやすく)
- 音: ガラスが割れる「チリン」(高さは場所で変わる)、ボールが落ちてくる瞬間の「キュイン」+キラキラ(強いボールほど高く・豪華に。声はなし)、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 音量: 通常部分 約 -13dB
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
