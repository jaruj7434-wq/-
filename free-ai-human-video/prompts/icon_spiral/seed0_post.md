- 動画: assets/output/icon_spiral_0.mp4(1080x1920 / 60fps / 34.7秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/icon_spiral/icon_spiral.py render --seed 0`
- もと: 18本目「ガラスの板こわし(うずまき)」と同じコース・同じ物理。ガラスを虹色にして、転がるボールをチャンネルのサムネ(アイコン)の女の子の顔に変えた回
- ルール: 5重のうずまきの通路に虹色のガラスの板432枚(うずまきに沿って赤→黄→緑→青→紫を3周、ゆっくり色が流れる。割れた破片も同じ色)。ボールは1個ずつ、うずまきの外側の口に落ちてきて、転がりながらガラスを割っていく。
  ボールは弱い順に7個:ホワイト → ブルー → パープル → グリーン → レッド → ゴールド → レインボー(ボールはサムネの女の子の顔:黒いつやつやのおかっぱ髪から青白い顔と大きな黒い目がのぞく。転がるぶんだけ回る。まわりにはアイコンと同じ色の光の輪と尾を引く光の軌跡。グリーンから光のトゲ、ゴールドとレインボーは光の粒)。
  色ごとに強さがちがい、レインボーに近づくほど強い:後のボールほど速く打ち出され(0→1450px/秒)、ガラスを1枚割ったときに失う速さが小さい(残る速さ 93.1%→99.18%)。
  1個で割る枚数の平均:ホワイト27 → ブルー34 → パープル41 → グリーン50 → レッド63 → ゴールド84 → レインボー131枚。
  転がり抵抗で少しずつ遅くなり、勢いがなくなったボールは薄くなって消える(ねらい・補正なし)。7個で432枚すべて割れば成功(大当たり演出)、ボールが尽きたら失敗(幽霊)
- 結末: 失敗(シード0をそのまま使用・選んでいない)。ホワイト27枚 → ブルー34枚 → パープル41枚 → グリーン50枚 → レッド64枚 → ゴールド84枚 → レインボー130枚と割り進むが、残り2枚(430/432枚)で力尽きる → 幽霊 → しょんぼりBGM
- 難易度: 60 回中 30 回成功(50%)。失敗した回はほとんどが残り1〜2枚
- 画面: TikTok などで隠れないよう、タイトルとボールの順番の表示を上の安全な範囲へ、枚数と「失敗したら・・・」を下の安全な範囲へ(うしろを暗くして読みやすく)
- 音: ボールが落ちてくるたびに色の名前の掛け声(「ホワイト!」「ブルー!」「パープル!」「グリーン!」「レッド!」「ゴールド!!」「レインボー!!」。強いボールほど高く元気に、レッドから上はこだまつき)+「キュイン」+キラキラ、
  ガラスが割れる「チリン」(高さは場所で変わる)、失敗は叫び声+しょんぼりBGM。
  声は無料のオープンソース音声合成 pyopenjtalk(Open JTalk)と音声「Mei」で作った(`scripts/icon_spiral/icon_ball.py`)。クレジット:HTS Voice "Mei" (c) Nagoya Institute of Technology / MMDAgent Project Team(CC BY 3.0)。ほかの音はプログラムで作った音
