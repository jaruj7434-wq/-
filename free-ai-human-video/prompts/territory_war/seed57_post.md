# 投稿用テキスト:territory_war_57.mp4(ピンクとミントの陣取り合戦・失敗パターン・いちばん接戦の版)

- 動画: assets/output/territory_war_57.mp4(1080x1920 / 60fps / 65.5秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/territory_war/territory_war.py render --seed 57`
- 参考: ユーザーから受け取った「2つのボールが相手の陣地を削っていく」動画の形式(色・アイテム・見た目・音はすべて自作)
- ルール: 24×28マスの盤を、左半分ピンク・右半分ミントで始める。ピンクのボールは自分の陣地の中を、ミントのボールも自分の陣地の中を、
  重力なし・同じ速さでまっすぐ進む。相手の色のマスにふれると、そのマスを自分の色に塗りかえて跳ね返る(かべでも跳ね返る)。ねらいなし。
  ときどき盤の上にアイテムが出て(最大3個)、ふれたほうが使える:
    ダッシュ … 5秒間 1.5倍の速さ
    巨大化   … 5秒間 2.4倍の大きさになり、跳ね返らずに相手の陣地を突き進む
    分身     … 7秒間 2個の分身が出る
    バクダン … 半径6マスのまわりをまとめて自分の色に(前の版は3.3マス)
  アイテムは中身がわかる絵(ダッシュ=速さの線つきのボール、巨大化=外向きの矢印つきのボール、分身=ボールと2つのうすい分身、バクダン=導火線つきの黒い爆弾)(アイコンに文字はつけない)。
  絵の白い丸の大きさ=当たり判定(ボールが丸にふれた瞬間に取る)
  60秒たった時点でマスが多いほうの勝ち。ピンクが勝てば成功(天使)、負ければ失敗(幽霊)。画面の上に「ピンクが勝てば成功！」、下に「ピンクが負けたら・・・」のテロップ
- 結末: 失敗(4マス差の大接戦)。最初から最後までほぼ50%対50%のまま → 38〜40秒にミントがダッシュ・分身・バクダンで少し押して 47.6%対52.4% → 43秒すぎにピンクが分身2連続で追い上げ → 49.7%対50.3%(334マス対338マス)、わずか4マス差で時間切れ → 幽霊 → しょんぼりBGM
- 選び方: ユーザーの依頼「いちばん接戦で終わる動画」に合わせて、300 シード(ピンクの勝ち 151 件・約50%)の中から、ピンクの負けでいちばん差が小さいもの(4マス差・seed 57)を選んだ。動きはそのまま
- 表示: 下の割合は小数1桁(49.7% など)、結果はマス数(334マス・338マス)で出すようにした
- 音: マスを塗りかえる「ポコッ」(ピンクは高め・ミントは低め)、アイテムを取る「キラン」+ダッシュ/巨大化の「ヒュン」・分身の「ポポポ」・バクダンの「ドーン」、最後の5秒のカウントダウン「ピッ」、失敗は叫び声+しょんぼりBGM
- 音量: 通常部分 約 -14dB
- AI生成コンテンツ: なし(すべてプログラムで描いた図形と自作の音)
