# 投稿用テキスト:shooter_333.mp4(砲台シューティング・ボス回)

- 動画: `assets/output/shooter_333.mp4`(1080x1920 / 60fps / 34秒 / H.264 + AAC)
- 再生成: `python scripts/shooter/shooter.py render --seed 333`
- 展開: 砲身1本で外しまくる → UFOが分裂して増える → ★で砲身が2本・5本、連射UP、爆発弾に強化
  → WAVE 2 → ボス出現(HP100)→ HP半分でボス激怒(赤くなって速くなり、子分を呼ぶ)
- 結末: 失敗。ボスのHPが残り1のまま時間切れ → 幽霊が出る
- 難易度: この設定では 400 回中 219 回成功(成功率 約55%)
- 音楽: ワーグナー「ワルキューレの騎行」(パブリックドメイン)の主題を、プログラムで音を合成して使用
