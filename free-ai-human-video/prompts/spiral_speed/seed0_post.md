# 投稿用テキスト:spiral_speed_0.mp4(スピード600でうずまきのガラスを全部割れる?・失敗パターン)

- 動画: assets/output/spiral_speed_0.mp4(1080x1920 / 60fps / 32.2秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/spiral_speed/spiral_speed.py render --seed 0`
- 結末: 失敗(シード0をそのまま使用・選んでいない)。スピード100で82枚 → 250で216枚 → 400で319枚 → 600で430枚、あと2枚で力尽きる → 幽霊 → しょんぼりBGM
- 音量: 通常部分 約 -14dB
- 参考動画: 「Ball breaks glass(physics simulation satisfying)」(ユーザー提供)の形を参考に、映像と音を一から作った
- ルール: 5重のうずまきの通路を、虹色のグラデーションのガラス432枚がすき間なくうめている(うずまきに沿って色がなめらかに変わる・ガラスらしい光と白いふち)。ボールを上から落とすと、うずまきの外側の口から入ってガラスを割りながら内側へ進む。
  うずまきに入るときの速さが「スピード」で、100 → 250 → 400 → 600 と上げながら4回挑戦する(毎回ガラスは元どおり)。
  ガラスを1枚割るたびにボールは少し遅くなり、転がり抵抗でも遅くなる。勢いがなくなったボールは消える。落とす位置はほんの少しずつ毎回ちがう(ねらい・補正なし)。
  最後のスピード600で432枚全部を割れたら成功(大当たり演出)、割れなければ失敗(幽霊)
- 難易度: 80 回中 44 回成功(55%)。スピード600はいつも最後の数枚の勝負になる
- 音: ボールが落ちる「ヒュッ」、ガラスが割れる「チリン」(内側へ進むほど高い・ひびきつき)。BGMなし。
  成功は どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打+鐘、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の文字は最小限(Zen Kaku Gothic New)。「失敗したら…」は怖い筆文字(Yuji Syuku)。どちらも SIL OFL
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
