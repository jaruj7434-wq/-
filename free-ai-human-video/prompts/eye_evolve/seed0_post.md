# 投稿用テキスト:eye_evolve_0.mp4(光る瞳の玉を虹の瞳まで進化・失敗パターン)

- 動画: assets/output/eye_evolve_0.mp4(1080x1920 / 60fps / 54.9秒 / H.264 + AAC・git 管理外)
- 再生成: `python scripts/eye_evolve/eye_evolve.py render --seed 0`
- 結末: 失敗(落ちた玉104個)。輪 2.3秒 → 花びら2 4.1秒 → 花びら3 8.2秒 → 星 15.4秒 → うずまき 31.7秒 →
  2つ目のうずまきが間に合わず 49.45秒の時間切れ → 幽霊 → 「Failed...」
- 音量: 通常部分 約 -14dB
- ルール: 首のついた丸いフラスコに、赤く光る「点」の瞳の玉が上から1個ずつ落ちてくる(0.9秒ごと → だんだん速く0.3秒ごと)。
  同じ段階の玉どうしが触れると合体して次の段階になり、大きくなる(1回の接触で1回)。
  進化(7段階・模様はすべてオリジナル):点 → 輪 → 花びら2 → 花びら3 → 星 → うずまき → 虹の瞳
  物理エンジン pymunk(重力・反発・摩擦)。玉が転がると瞳の模様も一緒に回る。ねらい・補正なし。
  シードで変わるのは、落ちてくる位置と速さのほんの少しのばらつきだけ。
  49.45秒以内に虹の瞳ができれば成功(大当たり演出)、首までつまってあふれるか時間切れなら失敗(幽霊 → 暗くなって「Failed...」)
- 難易度: 80 回中 40 回成功(50%)
- 音: 落ちる「カチッ」と、進化するたびに悪い笑い声「ムフッ…ハッハッハ!」だけ(進化の「キュイン/ピキーン」の効果音はなし)。笑い声は段階が上がるほど大きく(1段で約1.55倍・輪 約-25dB → うずまき 約-6dB)・長く・低く・ざらざらに・こだまが深くなる。前の笑いが鳴っている間は、それより上の段階のときだけ重ねる。声はプログラムで合成したオリジナル。BGMなし。
  成功は 虹のギュイーン → どんどん速く高くなるキュイン → ドーン!+ファンファーレ連打+キュインキュインの連打、失敗は叫び声+しょんぼりBGM。すべてプログラムで作った音
- 画面の文字は最小限(上に「虹の瞳にできる？」・残り秒数・7段階の進化表)。フォントは Zen Kaku Gothic New、「失敗したら…」は怖い筆文字 Yuji Syuku、
  最後の「Congratulations!!」「RAINBOW EYE」「Failed...」は Playfair Display Italic(すべて SIL OFL)
- 著作権: 瞳の模様は既存の作品のデザインを使わないオリジナル(勾玉や作品名は使っていない)
- AI生成コンテンツ: なし(物理計算とプログラムで作った映像・音)
- シードの選び方: シード0から順に計算し、最初の成功(1)と最初の失敗(0)をそのまま使用(結果は編集していない)
