# 台本 v2:故障したオールテレーンクレーンを犬たちが坂の上へ引き上げる

## v1 で伝わらなかった点(反省)
- **ブームが出なかった**:プロンプトに「boom retracted(ブームを縮めた状態)」と書いたため、ブームが目立たない車体になった
- **下り坂に見えた**:坂の向き・クレーンの向き・カメラ位置の関係を書いていなかった

## 企画の趣旨(1行)
**急な「登り坂」の途中で動けなくなった大型オールテレーンクレーンを、坂の上にいる約20匹の犬たちが太いワイヤーで引っ張り、坂を登らせている。**
最初はクレーンとワイヤーしか見えず、カメラが前方へ回ると、引いていたのが犬たちだったとわかるオチ。

## 絶対に守る条件(全カット共通)
| 項目 | 条件 |
|---|---|
| 坂 | **登り坂**。画面の右(奥)へ行くほど高い。クレーンも犬も**坂の上の方向へ進む** |
| クレーン | 黄色の大型オールテレーンクレーン(多軸のタイヤ付き)。**長い伸縮式ブームが車体の上に載っていて、運転席の前方まで突き出している**。ブームは画面ではっきり見える |
| 故障の表現 | ハザードランプ点滅、エンジン部から薄い煙、タイヤは自力では空転気味 |
| ワイヤー | 太い鋼鉄ワイヤー。**クレーン前部のけん引フックから、坂の上へ向かってピンと張る** |
| 犬 | 約20匹。2列(犬ぞり式)。犬種ミックス(ハスキー、マラミュート、ゴールデン、柴犬、コーギー、フレンチブルドッグ)。全員ハーネス着用。**クレーンより坂の上にいて、坂の上へ向かって引く** |
| 天気 | 曇り、自然光、ドキュメンタリー風 |
| 撮影 | 1カットの長回し、縦型 9:16、15秒 |

## カット表(15秒)

### カット1:0〜4秒「動けないクレーン」(つかみ)
- **画角**:クレーンの真横・少し下から。左が坂の下、右が坂の上。クレーンが画面いっぱい、右上がりに傾いている
- **映るもの**:黄色いクレーン全体、車体の上の長いブーム、ハザードランプ、薄い煙、前部から右上へ張ったワイヤー(先は画面外)
- **カメラ**:ほぼ固定で、ゆっくり右(坂の上)へ寄っていく
- **音**:エンジンの苦しそうなうなり、ワイヤーのきしみ

### カット2:4〜8秒「引っ張られて少しずつ登る」
- **画角**:カメラがクレーンの横を坂の上へ進む。タイヤ・車体側面のアップ、頭上にブームの底面
- **映るもの**:土の凸凹の上で空転しながら少しずつ前進するタイヤ、飛び散る土、ピンと張ったワイヤー
- **カメラ**:右(坂の上)へ並走移動
- **音**:タイヤが土をかく音

### カット3:8〜11秒「ワイヤーの先を追う」
- **画角**:クレーンの前を通り過ぎ、ワイヤーに沿って坂の上へ。左下にクレーンの運転席とブームの先端、右上へワイヤーが伸び、坂の上の盛り上がり(稜線)で先が見えない
- **カメラ**:ワイヤーに沿って右上(坂の上)へ移動しながら少し上を向く
- **音**:遠くからかすかに犬の息づかい

### カット4:11〜15秒「オチ:犬たちが引いていた」
- **画角**:犬たちの**正面・坂の上側**から、坂の下を見下ろす。手前に先頭の犬たちの顔、その後ろに2列の犬、いちばん奥(坂の下)にワイヤーでつながったクレーンとブーム
- **映るもの**:全力で坂を登ってくる犬たち(カメラに向かって前進)。舌を出し、足で土をかく。先頭の犬が得意げな顔
- **カメラ**:後ろ向きにゆっくり下がりながら、先頭の犬の顔に寄って終わる
- **音**:犬のハァハァという息、元気な鳴き声
