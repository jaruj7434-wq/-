# CLAUDE.md — ファッション雑誌表紙(画像・動画)制作

このフォルダは、Claude Code が **Higgs Field**(MCP ツール群: `mcp__higgs_field__*`)を使って
**ファッション雑誌の表紙風のおしゃれな画像**と、**その表紙に動きをつけたおしゃれな動画**を
制作するためのガイドです。リポジトリ直下の `CLAUDE.md` のルールも引き続き適用されます。

## 対話のルール

- **返答はすべて日本語**で行うこと。

## 最重要ルール:生成前に必ず許可を取る

- Higgs Field で画像・動画・音声を生成する前(`generate_image` / `generate_video` /
  `generate_audio` / `*_batch` / `execute_preset` / `upscale_*` / `reframe` /
  `outpaint_image` / `motion_control` など、クレジットや処理時間が発生するツールすべて)は、
  **必ずチャットでユーザーの許可を取ってから**作成に入ること。
- 許可を求める際は、以下を簡潔に提示する:
  1. 何を作るか(画像 / 動画、枚数・本数)
  2. 使用するモデル・アスペクト比・尺
  3. プロンプトの要約(人物像・衣装・背景・ライティング・誌面レイアウト)
  4. 想定コスト(可能なら `get_cost: true` でプレフライトした結果)
- ユーザーが明確に「OK」「作成して」等の許可を出すまで生成を実行しない。
  一度の許可はその内容の生成にのみ有効で、内容を変えて再生成する場合は改めて許可を取る。
- 可能な限り `use_unlim: true`(無制限枠)を使う。無制限枠が使えない旨が返ってきた場合は、
  「クレジットを消費する形になるがよいか」を改めて確認してから進める。
- 課金を伴わない準備作業(`get_workflow_instructions`、`models_explore`、
  `media_upload_widget`、`video_analysis_*` など)は確認なしで行ってよいが、
  判断に迷う場合は確認を取る。

## このフォルダのテーマ:AIによるリアルな人間

- このプロジェクトでは **AIでリアルな人間(フォトリアルなモデル)** の画像・動画を作る。
- 肌の質感・毛穴・髪の毛の流れ・自然な手指・目のハイライトなど、
  「AIっぽさ」を抑えた写実性を最優先する。
- 同じモデルを複数の表紙・カットで使い回す場合は一貫性を確保する:
  - `show_reference_elements`(Elements):即時利用可、他の主要モデルでも使える。
  - `show_characters`(Soul):同一人物 5〜20枚の写真が必要、`soul_2` / `soul_cinematic` 専用。
  - 架空モデルを新規に作る場合は AI Influencer(`ai_influencer_prepare` →
    `ai_influencer_generate`)やキャラクターシート(`character-sheet` ワークフロー)も検討する
    (いずれも生成を伴うため事前に許可を取る)。
- **実在の人物**(有名人・知人など)の顔や名前を使った生成は、本人の同意が取れているもの以外は
  行わない。実在の雑誌名・ロゴ(VOGUE、ELLE など)をそのまま再現した表紙も作らず、
  オリジナルの誌名・ロゴで制作する。

## 制作フロー

### 1. 企画・ブリーフ確認
- 誌名は『AURE』固定。号・特集テーマ、季節感、モデル像、衣装・スタイリング、
  トーン(ハイファッション / ストリート / ミニマル / ヴィンテージ 等)を確認する。
- 企画内容は `prompts/` 配下にテキストで残す。

### 2. 表紙画像(静止画)
- **誌名(中央上部の大きなマストヘッド)は毎回『AURE』で固定**。他の誌名は使わない。
  プロンプトには必ず `Large elegant serif masthead centered at the top reading "AURE"` を含める。
- 表紙には、モデルのファッションを紹介するおしゃれな説明文(カバーライン)をたっぷり入れる。
  案は `prompts/` に書き出し、文字崩れを防ぐため1枚に載せるのは 6〜8 本程度に絞る。
- **カバーラインのデザイン**:フォントを全部同じにしない。セリフ体イタリック・細身コンデンス体・
  手書き風スクリプトなどを混ぜ、強調ワードにはアクセントカラーを入れ、大小のジャンプ率を大きくする。
- **背景**:無地スタジオではなく、簡単には行けないおしゃれな海外の街並みを基本にする。
- まず `models_explore` でフォトリアルな人物に強い画像モデルを確認してから選ぶ。
- 雑誌表紙の構図を意識したプロンプトを作る:
  - 縦長構図、上部に誌名(マストヘッド)用の余白、左右にコピー(見出し)用の余白。
  - カメラ・レンズ・ライティング(例:85mm、ビューティーディッシュ、スタジオ背景)を具体的に書く。
  - 文字入り表紙を生成する場合は、誌名・見出しの文字列を明示する
    (文字崩れが出やすいため、文字なし版も併せて提案する)。
- アスペクト比:誌面用は `3:4` または `4:5`、SNS縦型用は `9:16`。
- 必要に応じて `upscale_image` で高解像度化する(要許可)。

### 3. 表紙に動きをつけた動画
- 完成した表紙画像を起点に `generate_video`(image-to-video)で動きをつける。
- おしゃれに見せる動きの例:
  - モデルの微細な動き(まばたき、髪のなびき、視線をカメラに向ける、軽いポーズ変化)
  - ゆっくりしたカメラのプッシュイン / ドリー、フラッシュの明滅、布の揺れ
  - 表紙全体が「動く雑誌」に見えるシネマグラフ風の演出
- 誌名・テキスト部分は崩れやすいため、**文字なしの表紙画像を動画化 → 後から文字を合成**
  する方法も検討・提案する。
- 尺は基本 5〜10秒、`aspect_ratio: "9:16"`(SNS用)を明示。誌面サイズ準拠なら `3:4` 等。
- 複数ステップの動画制作になる場合は、先に `get_workflow_instructions` を呼んで
  該当ワークフローを確認する(憶測で決めない)。

### 4. 仕上げ
- 必要に応じて `upscale_video`、`subtitles` ワークフロー(テキスト焼き込み)などを使う(要許可)。

## フォルダ構成(想定)

```
fashion-magazine-cover/
├── CLAUDE.md          # このファイル
├── prompts/           # 表紙・動画用のプロンプト、企画メモ
├── docs/              # 誌名・ロゴ・トーンなどのガイドライン
└── assets/
    ├── source/        # 参照写真・衣装写真など(git管理外)
    └── output/        # 生成された画像・動画(git管理外)
```

- 生成物(画像・動画ファイル)はコミットしない。プロンプトや企画書などのテキストのみコミットする。
