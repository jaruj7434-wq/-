## 編集でのつなぎ方

| つなぎ目 | 方法 |
|---|---|
| S1 → S2 | S1 最後のフェードアウト → 暗転 → S2 の柱時計の音から入る(現在から過去へ) |
| S2 → S3 | S2 最後のチェロの旋律を S3 の頭まで残す。セピアから80年代カラーへ |
| S3 → S4 | S3 最後の逆光のシルエットと、S4 冒頭の赤鉛筆の音をつなぐ(「書く」でつながる) |
| S4 → S5 | S4 最後の現在の谷上の目 → S5 冒頭の眼鏡のレンズの超アップ(目と眼鏡のマッチカット) |
| S5 → タイトル | 止め絵の上に筆文字タイトル → エンドカード |

- 色:時代ごとの色(現在=ティール&アンバー/70年代=セピア/80年代=緑かぶり/研究=青と暖色)はそのまま生かす。現在のパート(S1・S5)だけは色味を揃える。
