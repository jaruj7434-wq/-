# backstory.md — 谷上の半生(認知獲得用シリーズ「谷上という男」)

> 第2版(2026-10-15):ユーザー指示で改稿。牧場・競馬新聞の経歴をなくし、「厳しい父」「20代から自分の給料で少しずつ賭けて負けを知る」「徹底した研究と分析の毎日」を軸にした。
> **この半生はすべてフィクションです。** 谷上は AI で作った架空の人物で、経歴・出来事は制作上の創作です。
> 動画には必ず「この物語はフィクションです」と入れます。実在の競馬場・レース・馬・騎手の名前は出しません。

## このシリーズの目的

まず「谷上」という男を知ってもらう。
予想の宣伝はせず、**競馬にすべてを注いできた、不器用な男の半生**をショートドラマとして見せ、
「この人、何者?」「続きが見たい」「この人の予想なら見てみたい」と思わせます。

## 描き方のルール

| ルール | 理由 |
|---|---|
| 賭けるのは**働いて得た給料から少しずつ**。大勝ち・大金・札束は描かない | 「馬券で稼げる」と受け取られないようにするため(射幸心をあおらない) |
| 「負けを知る」ことをしっかり描く。勝ちより負けが多い人生として見せる | 人間味と説得力を出し、ギャンブルを美化しない |
| 強さの理由は「運」ではなく**研究と分析の積み重ね**として描く | 予想の考え方への信頼につなげる |
| 的中率・回収率・獲得金額などの数字は出さない | 実在の実績と誤解させないため |
| 父は「厳しい」が、暴力は描かない(無口・笑わない・規則に厳しい) | 視聴者に不快感を与えず、プラットフォームの規約にも配慮する |
| 語りは谷上本人のモノローグ(独り言)だけ。会話はなし | 「一言ボソッと話す男」というキャラクターを守る |
| 子どもの谷上と父は**顔をはっきり映さない**(後ろ姿・手元・シルエット・色あせた古い写真風) | AI で別人の顔が混ざるのを防ぎ、想像の余地を残す |
| 各話の最初と最後は、現在の谷上(50代)の顔のアップ | 「今の谷上」を毎回覚えてもらう |
| 賭ける場面がある回は、「馬券の購入は20歳から。無理のない範囲で。」を必ず入れる | 責任ある表現のため |

## 谷上の半生(年表・フィクション)

| 年代 | 出来事 | 谷上の中に残ったもの | 象徴する映像 |
|---|---|---|---|
| 幼少期 | 父は超がつくほど厳しい男だった。家ではほとんど笑わず、口数も少なく、門限や礼儀には一切妥協しない。谷上はいつも父の背中を怖がっていた | 父への怖さと、憧れ | 食卓で背筋を伸ばして座る父の背中、正座する小さな膝 |
| 幼少期 | ただ一つ、**競馬を見ているときだけ、父は優しかった**。テレビの競馬中継の前では声が柔らかくなり、休みの日には競馬場によく連れて行ってくれた。肩車をして「いいか、脚を見ろ」と馬の見方を教えてくれた | 「競馬場は、父が笑う場所」 | 肩車の高さから見る馬場、父の大きな手、ゴール前の土煙 |
| 中学〜高校 | 父と並んで新聞の馬柱(馬の成績表)を読む時間が、父との唯一の会話になる。父の赤鉛筆の使い方を真似し始める | 赤鉛筆と、記録する習慣 | 並んで新聞を読む二つの背中、赤鉛筆 |
| 20歳〜 | 働き始め、自分の給料で馬券が買えるようになる。毎日のように競馬場や場外に通い、少しずつ、チビチビ賭ける。**そして、負ける。何度も負ける** | 「負け」の悔しさと、その理由を知りたいという執念 | 薄い財布、外れ馬券が舞う夕暮れのスタンド、帰りの電車 |
| 20代後半〜 | 負けた理由をすべてノートに書き出すと決める。出走表、過去のレース、血統、馬場の状態、オッズの動き。仕事以外の時間はすべて競馬の研究と分析に使う、競馬尽くしの毎日 | 何十冊ものノート。分析の型 | 深夜の部屋、机に積まれたノート、ビデオで何度も巻き戻すレース |
| 30〜40代 | 「人気じゃなく、理由で買う」という自分の型ができる。周りの競馬仲間が、谷上の見立てを聞きに来るようになる | 自分の目への確信 | 喫茶店で新聞に赤丸をつける谷上、遠巻きに見る常連たち |
| 50代(現在) | 予想屋集団「king万グループ」に声をかけられる。人生で初めてスマホを持たされ、SNSに予想を出すことになる | 新しい場所での勝負 | 黒のライダース、ガム、スマホを睨む目 |

### 谷上の口ぐせ(シリーズ共通)
- 「……人気じゃねえ。理由で買う。」
- 「……負けにも、理由がある。」
- 「……脚を見ろ。」(父から受け継いだ言葉)

## シリーズ構成(全7話・各20〜30秒)

| 話 | タイトル | 冒頭のフック(0〜2秒) | 内容 | 最後の一言(谷上のモノローグ) | 次回への引き |
|---|---|---|---|---|---|
| 1 | 笑わない父だった | 現在の谷上がボソッと「……親父は、笑わねえ男だった。」 | 厳しい父。食卓の緊張、正座、怖い背中 | 「……競馬を、見てる時以外はな。」 | 競馬中継の前の、父の横顔 |
| 2 | 競馬場の父だけが、優しかった | 肩車の高さから見るゴール前 | 父に連れられて通った競馬場。肩車、「脚を見ろ」という言葉、父の笑顔(口元だけ) | 「……あの場所でだけ、親父は笑った。」 | 少年は、父の赤鉛筆を真似し始める |
| 3 | 親父の赤鉛筆 | 机に置かれた、短くなった赤鉛筆 | 並んで新聞を読む時間が、父との唯一の会話だった | 「……あれが、親父との会話だった。」 | 20歳、自分の金で馬券を買う |
| 4 | 20歳。負けを知った | 夕暮れのスタンドに舞う外れ馬券 | 給料から少しずつ、毎日のように競馬場へ。そして負け続ける | 「……負けにも、理由がある。」 | 理由を、全部書き出すと決めた |
| 5 | 負けた理由を、全部書いた | 深夜、ノートに走る赤鉛筆 | 研究と分析の毎日。出走表、過去のレース、血統、馬場、オッズの動き | 「……競馬のこと以外、何も覚えてねえ。」 | 何十冊目かのノートで、答えが見えた |
| 6 | 人気じゃねえ。理由で買う | 床一面に広げた何十冊ものノート | 自分の型ができあがる。周りが谷上の見立てを聞きに来る | 「……人気じゃねえ。理由で買う。」 | ある日、知らない番号から電話が鳴る |
| 7 | そして、スマホを持たされた | 黒ライダースの谷上が、スマホを睨んでいる | king万グループに誘われ、初めてのSNS。投稿ボタンが押せない | 「……競馬なら、話せる。」 | → 本編シリーズ(予想の考え方)へ |

- **第7話で本編につなげる**:第7話は、以前作った第1話(競馬になると目が変わる男)の前の話になります。
- **まとめ動画**:7話を出し終えたら、60〜90秒の総集編「谷上という男」を作り、プロフィールの固定投稿にします。

### 第1話の制作メモ

| 項目 | 前半A | 後半B |
|---|---|---|
| 最初の1コマ(静止画) | 現在の谷上の顔のアップ(Soul「谷上」で作る) | テレビの光に照らされた父の横顔のシルエットと、見上げる少年(`nano_banana_pro`、セピア) |
| 動画 | `seedance_2_5`・720p・15秒・音声あり(約105クレジット) | 同じ(約105クレジット) |
| 参照画像 | 確定顔(A1・A2)、白背景リファレンス(W7)など | 前半Aの茶の間の雰囲気(色・光)をそろえる |

- **費用の目安**:静止画2〜4枚(約5〜8クレジット)+動画2本(約210クレジット)=約215〜220クレジット
- **父と少年の顔は映さない**:後ろ姿・シルエット・手元だけで描きます。
- **過去の質感**:セピア色、フィルムの粒子、少し色あせた昭和の茶の間で、現在と過去をはっきり分けます。
- **厳しさの見せ方**:怒鳴る・叩くといった場面は入れず、沈黙・正座・震える手・柱時計の音で「怖さ」を伝えます。
- **つなぎ方**:A の最後(テレビがつく音と実況)と、B の最初(実況が盛り上がる)を重ねて、1本の動画に見えるようにします。

## 第4話(賭ける場面がある回)の注意

- 賭けるのは「働いて得た給料から少しずつ」。財布の中身が薄いことを映像で見せます。
- 勝ってはしゃぐ場面は入れず、外れ馬券・帰りの電車・ため息を中心にします。
- 最後に「馬券の購入は20歳から。無理のない範囲で。」を必ず入れます。

## バズらせるための工夫(全話共通)

| 工夫 | 内容 |
|---|---|
| 冒頭は必ず現在の谷上 | 強面のアップ+ボソッと一言。2秒で「この人誰?」と思わせる |
| 父との関係を軸にする | 「厳しい父が、競馬の時だけ優しかった」という感情の物語にすると、競馬に興味がない人にも届く |
| 過去は「音」で引き込む | 柱時計、蹄の地響き、実況、夕暮れのざわめき |
| 毎話、口ぐせで終える | 「……負けにも、理由がある。」などを繰り返して覚えてもらう |
| 次回予告は1行だけ | 「次回:競馬場の父だけが、優しかった」のように短く |
| コメントを誘う | 投稿文の最後に「あなたの父親との思い出の場所は?」など、答えやすい問いを置く |
| シリーズ名の固定 | 「谷上という男。第◯話」を毎回同じ位置・同じ書体で出す |
