# 調査メモ:昭和のコマーシャル(2026-11-16)

※ 検索で確認できた範囲のまとめ。吉田秀雄記念事業財団の PDF 等はこの環境から接続できず、本文は未読。

## 大前提:昭和初期にテレビCMはない
- 日本初のテレビCMは 1953年(昭和28年)8月28日、日本テレビ開局日の精工舎の時報CM。白黒・モノラルで、ごく簡素な作り
- その前の民放ラジオCMも 1951年(昭和26年)から。戦前のラジオは NHK だけで CM はない
- 昭和初期(1926〜1940年ごろ)の広告は、新聞広告・ポスター・看板と、映画館で上映された企業の宣伝紹介映画(無声)が中心
- → 「昭和CMらしいテンポ」は、**昭和30年代(1955〜1964年)のテレビCM**のもの

## 昭和30年代のテレビCMの特徴
- **機能・便利さを率直に言う**:共感やストーリーより「何ができるか」。初期CMは「動く商品カタログ」と言われる
- **生CMが多い**:番組の出演者がそのまま商品を紹介。ドラマの登場人物が劇中で店に立ち寄って紹介する例も(1955年)
- **専属タレント**:1956年ごろから、家電メーカーが生CM専属の女性タレントを起用(東芝・旗和子、三洋電機・林ひな子)
- **フリップと字幕スーパー**:一度きりの生放送なので、短い時間で伝えきるためのフリップ・字幕の作り方が工夫された
- **アニメCMが多い**:1950年代のCMの数十%がアニメ、部分的な使用も含めると約70%という見方がある
- **流行語になるコピー**:例「トリスを飲んでハワイへ行こう」(1961年ごろ)、アンクルトリス(1958年、柳原良平)
- **洗濯機の売り文句**:主婦の重労働を数字で大げさに言う。例:街頭の実演販売の口上「5人家族の奥様は、一年に象一頭分の重さの洗濯物を洗っています」
- **時代背景**:洗濯機・冷蔵庫・白黒テレビが「三種の神器」と呼ばれた。洗濯機の普及率は昭和30年で約10%
- そのほか当時の定番(一般的な知識):CMソングで社名を歌う、月賦(分割払い)の案内、最後に社名とマーク

## この企画に取り入れること
| 当時の特徴 | 取り入れ方 |
|---|---|
| ジングルで始まり社名で終わる | 頭と尾に、オリジナルのCMソングを短く入れる |
| 専属の女性タレントの実演 | 白い手袋のタレントがボタンを押して実演する |
| 数字の大げさな言い方 | 「一年でお洗濯にかける時間、なんと三百時間!」(当時の口上はそのまま使わない) |
| 字幕スーパー・フリップ | 毎カットに太い文字のスーパー。タレントが手書きのフリップを持つ |
| 機能をはっきり言う | 「洗って、すすいで、しぼって、乾かすまで」 |
| 月賦 | 「月賦販売 承ります」のスーパー |
| アニメCMが多い | 冒頭の社名ロゴを切り絵アニメ風に動かす |
