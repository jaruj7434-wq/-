# 体の悩み系アカウント 企画書(2026-11-16)

## コンセプト
病気の名前や身近な悩み(匂い・フケ・胃もたれ〜がん等の重い病気まで)をタイトルで大きく出し、
**「体の中で何が起きているか」「予兆のサイン」「公的機関がすすめる対策」「受診の目安」**を
30〜45秒の縦型ショートで発信する。男女・年代を問わず、誰にとっても役立つ内容にする。

## 見せ方(決定・2026-11-16 更新)
- **固定キャラクターは使わない**(健康博士案は不採用)
- **映像は2種類のリアル映像だけで構成する**
  1. **3D体内映像**(医療CG風):体の中で何が起きているかを見せる
  2. **リアルな日常の再現映像**:悩みや症状を感じている場面(お腹をさする、頭をかく等)を、男女・年代を変えて見せる
- 冒頭1〜2秒の「病名ドン+映像」で指を止める。進行はナレーションとテロップだけで行う
- **キャラがいない分、統一感で覚えてもらう**:
  - タイトル文字のデザインと配色を毎回固定する(例:白文字+黒フチ、アクセント1色)
  - ナレーションの声を1つに固定する(`create_voice`)
  - オープニングの効果音とエンドカード(シリーズ名+番号)を固定する

## 投稿の柱(比率の目安)
| 柱 | 比率 | 例 | 役割 |
|---|---|---|---|
| 身近な悩み | 5割 | 胃もたれ、口臭、フケ、汗の匂い、むくみ、口内炎 | 再生数・案件(日用品/食品) |
| 生活習慣と予防 | 3割 | 睡眠、腸活、食後の眠気、お酒と肝臓 | 案件(サプリ・機能性表示食品・寝具) |
| 見逃したくない重いサイン | 2割 | がん・脳卒中・糖尿病の予兆 | 保存・信頼(案件目的にしない) |

## 動画の型(30〜45秒)
1. 0〜1.5秒:病名・悩み名をドン+3D映像
2. 〜4秒:再現映像+ナレーションのフック(意外性。恐怖はあおらない)
3. 〜16秒:体の中で起きていること(3D)/原因
4. 〜30秒:予兆チェック・対策3つ(チェックリスト)
5. 〜40秒:受診の目安+エンドカード+出典表示
- シリーズ名と番号をつける(例:「体のサイン図鑑 #01」)
- 最後に「いくつ当てはまった?コメントで」でコメントを誘う

## 表現ルール(必ず守る)
- **効能を断定しない**(薬機法・景品表示法):「治る」「効く」「必ず予防できる」はNG。
  「〜と言われています」「公的機関がすすめている対策」と表現する
- **「確実」と言わない**:根拠は公的機関・学会の公開情報にそろえ、出典を画面に出す
  (厚生労働省、国立がん研究センター がん情報サービス、各学会の一般向けガイド等)
- **医師・実在の患者に見せかけない**:再現映像のAI人物は「イメージ映像」として使い、白衣の医師役や
  「患者さんの体験談」のような見せ方はしない。画面に「※イメージ映像(AI生成)」と小さく表示する
- **プロフィール/概要欄に明記**:「情報は公的機関等の公開情報をもとにしています。
  気になる症状は医療機関に相談してください」「※映像はAIで制作したイメージです」
- **怖がらせない**:重い病気の回は「早く気づいて受診につなげる」トーンに統一
- **案件は必ず「PR」「広告」表記**(ステマ規制)
- グロテスクな体内描写は避ける(プラットフォーム規約・視聴者離脱対策)

## 制作コスト(2026-11-16 時点の試算)
- プラン:Ultra/無制限枠は利用不可 → 生成はクレジット消費
- 3D映像 5秒・9:16・720p:Seedance 2.0 fast = 12.5クレジット/Seedance 2.5 = 35クレジット
- 1本あたり 3D映像+再現映像 4〜6カット ≒ 50〜75クレジット(+ナレーション)
- **節約策**:臓器ごとの3Dカットを「素材ライブラリ」として作りため、同じ臓器の回で使い回す
  → 素材一覧は今後 `prompts/health/asset_library.md` で管理

## 収益化ロードマップ(目安)
1. 0〜3か月:柱1中心に毎日〜隔日投稿、伸びる型を探す
2. 3〜6か月:シリーズ化して保存率を上げる
3. フォロワー1万前後:日用品・食品系の小規模案件、アフィリエイト
4. その後:監修医をつけ、医療・保険・検査キットなど高単価案件へ
