## この予告編の「型」(制作に使えるポイント)

1. **1カット=1〜2人**がほとんど。大人数は「食卓の引き」と「歩く後ろ姿」だけで、顔をはっきり見せない
2. **1カット=1つの動作・1つの感情**。2秒前後で次へ。セリフがあるのは一部のカットだけ
3. **最初に一番エモい場面を長めに**(ささやき+焚き火で約25秒)
4. **間のカット**(炭火、誰もいない食卓、空撮、鐘)をはさんで、テンポに緩急をつける
5. **告白インタビュー**(一人で座って語る)を何度もはさむ
6. **スタジオのコメンテーター**が涙を拭く=視聴者の感情を代弁する
7. **新メンバー登場は顔を見せない**: 暗転 → 足元だけ → 全員の驚いた顔のリアクション。正体は最後まで隠す

## 前回(v5)の生成がうまくいかなかった理由

| v5 でやったこと | 参考動画の型 |
|---|---|
| 30秒・1回の生成に10シーン、11人、9つのセリフを詰め込んだ | 1カット=1〜2人・1動作。セリフは一部だけ |
| 10人が同時に映る飲み会、もみ合いなど大人数の複雑な動き | 大人数は引きか後ろ姿だけで、細かい動きをさせない |
| 1つのプロンプトで全カットを指示 | (AI 生成では)1カットずつ短く作り、後でつなぐ方が指示どおりになりやすい |

**改善の方向**: 1回の生成ではシーンを詰め込みすぎない。1〜2人・1動作の短いカット(4〜8秒)を個別に生成し、後で編集でつなぐ。
