- **カメラ**: 緩やかなパン・ティルト、背景の流れる横移動、ズームイン/アウトは控えめ
- **文字カード**: 白〜淡いピンク・水色のグラデーション背景に、細い明朝体の黒文字(縦書き・横書き)。人物紹介は画面に縦書きで名前を重ねる
