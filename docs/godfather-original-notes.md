# 原作メモ:『ゴッドファーザー』(1972)— パロディ『ゴッドマザー』用

※ 映画の映像・音楽(テーマ曲を含む)・ロゴ・俳優の肖像や声は使わない。名シーンの構図や台詞の「型」だけを借りて、中身を町内会の日常に置き換える。

## あらすじ(要点)
- NYのマフィア、コルレオーネ家。ドン・ヴィトーは「断れない申し出」で物事を動かす。
- 末っ子マイケルは家業と距離を置く堅気の青年で、恋人ケイに「あれが僕の家族だ。僕は違う」と言う。
- 麻薬取引を断ったヴィトーが、果物屋でオレンジを買っているところを銃撃される。
- 父を守るため、マイケルはレストランで敵を撃つ(トイレに隠した銃、近づく電車の轟音)。
- シチリアへ逃亡。帰国後、父の後を継ぐ。
- 甥の洗礼式で「悪魔を拒絶します」と誓う裏で、敵対する一家のボスが次々と始末される。
- ラスト、部下がマイケルの手に口づけして「ドン・コルレオーネ」と呼び、ケイの前で扉が閉まる。

## パロディに使う名シーンと名台詞
| 原作 | ゴッドマザーでの置き換え |
|---|---|
| 冒頭「私はアメリカを信じてきた」から、ゆっくりカメラが引き、猫をなでるドンが映る | 「私は、この町内を信じてきました」→ 猫をなでるゴッドマザー |
| 「私をゴッドファーザーとも呼ばずに…」 | 「…まあ、座ー(マザー)」 |
| 「断れない申し出をする」 | 「断れない、おすそ分けを持っていきな」 |
| ベッドに馬の首 | 布団をめくると、巨大な鯛の頭(めで"たい") |
| 「ルカは魚と眠っている」(防弾チョッキに包んだ魚) | エプロンに包んだブリ「あの人は…もうLINEグループにいません」 |
| 果物屋でオレンジを落として銃撃される | 八百屋でみかんを落とし、新聞の勧誘に捕まる(スローモーション) |
| 「あれが僕の家族だ、ケイ。僕は違う」 | 慶太「あれが僕の家族だ。…僕は、ああはならない」 |
| レストランで電車の轟音が近づき、マイケルが撃つ | 公民館の会議。電車の轟音が近づき、慶太が判子を「ドン!」と押す |
| 五大ファミリーの会合 | 五丁目の婦人会長、五人の会合 |
| 「銃は置いていけ。カンノーリは持っていけ」 | 「銃は置いていけ。おはぎは持っていけ」 |
| 洗礼式と粛清のカットバック | 町内会長の就任式で「誓います」と言う裏で、ゴミ出し違反のゴミ袋が次々に返されていく |
| 部下が手に口づけ「ドン・コルレオーネ」、扉が閉まる | 婦人会員たちが慶太の手に口づけ「…ゴッドマザー」、恋人の前で公民館の扉が閉まる |
